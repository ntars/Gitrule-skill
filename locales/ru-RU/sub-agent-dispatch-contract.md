# Контракт распределения подагентов

> Какую задачу решает этот файл: определяет четыре обязательных элемента, которые должны быть явно записаны при распределении задач подагентам, а также ограничения взаимодействия, обеспечивая структурность, проверяемость выводов и отсутствие дрейфа правил.

## 1. Четыре элемента распределения

При каждом распределении должны быть явно записаны четыре элемента:

```text
TASK:    <задача в одном предложении>
INPUT:   <необходимые файлы/контекст, только нужные части>
OUTPUT:  <структурированный формат, таблица или JSON, без прозы>
FAIL:    <что вернуть, если сделать невозможно, вместо выдумывания>
```

## 2. Ограничения

- Один подагент за один раз выполняет только одну задачу; «заодно напиши и README» запрещено.
- Подагент может только читать и только предлагать решения; **запись файлов и операции git единообразно выполняет главный контроллер**.
- Вывод подагента должен сопровождаться доказательством (путь к файлу + номер строки / вывод команды); вывод без доказательств считается недействительным.
- Подагенты не общаются друг с другом напрямую; всё сводится через главный контроллер, что исключает дрейф правил.
