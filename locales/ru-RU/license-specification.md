# Спецификация LICENSE

> Какую задачу решает этот файл: определяет SPDX-маркировку лицензии проекта, требования к полному тексту LICENSE, расположение строки авторских прав и описание множественных лицензий, а также правило о недопустимости записи лицензии без подтверждения.

## Правила LICENSE

1. Лицензия проекта должна быть явно указана в README с помощью идентификатора SPDX, и должен быть предоставлен соответствующий файл LICENSE.
2. Файл LICENSE должен содержать официальный полный текст этой лицензии на английском языке; изменять или удалять условия запрещено.
3. Строка авторских прав размещается в начале файла или в разделе 19 README, формат см. в [спецификации разделов README](./readme-sections-specification.md).
4. При использовании двойного или множественного лицензирования должны быть описаны условия применения и способ выбора.
5. При отсутствии подтверждения пользователем выбор лицензии не должен напрямую записываться в документацию; предоставляются только варианты-кандидаты и описание различий.
