# Спецификация инструментов MCP

> Какую задачу решает этот файл: определяет правила проектирования интерфейсов и описаний при предоставлении набора спецификаций в виде инструментов через протокол контекста модели (MCP), обеспечивая корректное обнаружение и вызов инструментов моделью.

## 1. Принципы проектирования инструментов

1. Единственная ответственность: один инструмент выполняет одну задачу, универсальные интерфейсы «всё в одном» не применяются.
2. Ясное описание: описание инструмента поясняет назначение и сценарии применения, помогая модели определить, когда его вызывать.
3. Явные параметры: каждый параметр имеет тип, признак обязательности, диапазон значений и описание.
4. Структурированный вывод: возвращаются структурированные данные, длинная проза не применяется.

## 2. Обязательные поля

| Поле | Требование |
| --- | --- |
| name | Уникальный идентификатор, строчные буквы, kebab-case |
| description | Назначение и условия срабатывания, конкретные и определимые |
| inputSchema | Типы параметров, обязательные элементы, ограничения |
| Возвращаемое значение | Структурированный формат и описание полей |
| Ошибки | Формат ответа при сбое, выдумывать результат запрещено |

## 3. Инструменты набора спецификаций

1. Поиск документации: возвращает содержание спецификации по языковому коду + идентификатору (идентификаторы см. в [спецификации машиночитаемых метаданных](./machine-readable-metadata-specification.md)).
2. Перечисления: возвращает список доступных документов и их языковое соответствие.
3. Проверка: проверяет полноту матрицы документации (см. [матрицу документации](./document-matrix.md)) и состояние контрольных точек (см. [контрольную точку качества](./quality-gate.md)).

## 4. Абсолютные требования

1. Инструмент не должен возвращать PASS для результатов, которые невозможно проверить; необходимо указывать SKIP и причину (см. [запрещённые практики](./prohibited-practices.md)).
2. Вывод должен быть разбираемым программой и не содержать внутреннего хода рассуждений.
3. Сведения, связанные с безопасностью, не должны раскрываться через инструменты (см. [спецификацию безопасности и приватности](./security-and-privacy-specification.md)).
