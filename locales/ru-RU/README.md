## Пути чтения

- **Определить область применения**: Руководство по выбору спецификаций → Таблица соответствия жизненного цикла → файлы спецификаций соответствующей фазы.
- **Через весь жизненный цикл**: Таблица соответствия жизненного цикла → Спецификация инициации проекта и требований → Спецификация матрицы прослеживаемости требований → Спецификация документов архитектуры → Спецификация тестов → Спецификация развёртывания и отката → Спецификация наблюдаемости → Спецификация ретроспективы итерации.
- **Быстрый пуш**: Абсолютные правила → Контрольная точка качества → Спецификация пуша и публикации → Формат отчёта о ревью.
- **Создать документацию с нуля**: Роли и обязанности → Процесс выполнения → Сбор информации и шаблоны → Матрица документации → Спецификация разделов README → Спецификация соответствия открытому исходному коду → Контрольная точка качества.
- **Написать README**: Отчёт об исследовании шаблонов README → Спецификация визуальной вёрстки README → Спецификация бейджей → Руководство по адаптации README по категориям → Стандартный шаблон README.
- **Полное ревью**: Матрица измерений ревью → Контракт распределения субагентов → Абсолютные правила → Контрольная точка качества → Формат отчёта о ревью.
- **Программная интеграция**: Спецификация машиночитаемых метаданных → Спецификация написания Skill / Спецификация инструментов MCP / Спецификация вызова агентов и промптов.
- **Риски и пределы ответственности**: Отказ от ответственности → Шаблон отказа от ответственности → Шаблон SECURITY → Спецификация безопасности и конфиденциальности → Спецификация соответствия открытому исходному коду.
- **Создать файлы управления сообществом**: Шаблон руководства по участию → Шаблон кодекса поведения → Шаблон SECURITY → Шаблон отказа от ответственности.

## Языковые соглашения

- **должен / не должен**: обязательное требование.
- **следует / не следует**: рекомендация или запрет; при отклонении требуется обоснование.
- **может**: необязательно.
- **P0 / P1 / P2**: P0 блокирует пуш; P1 устраняется до пуша или обязательно фиксируется как задача; P2 — рекомендуемое улучшение.
