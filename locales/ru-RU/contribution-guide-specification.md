# Спецификация руководства по участию

> Какую задачу решает этот файл: определяет полный процесс и правила участия внешних контрибьюторов в проекте и служит основанием для написания CONTRIBUTING.md.

## 1. Обязательное содержимое

Руководство по участию должно включать следующие части:

1. **Способы участия**: обсуждение в issue, улучшение документации, вклад в код, сообщение о проблемах и другие каналы.
2. **Настройка среды разработки**: установка зависимостей, требования к окружению, команды локального запуска.
3. **Модель ветвления**: правило именования веток, исходная ветка, целевая ветка.
4. **Соглашение о коммитах**: формат сообщений коммитов (см. [спецификацию сообщений коммитов](./commit-message-specification.md)).
5. **Требования к PR**: объём изменений, пункты самопроверки, шаблон описания, критерии ревью.
6. **Требования к тестам**: команды тестов, которые должны проходить, и порог покрытия (см. [спецификацию тестов](./testing-specification.md)).
7. **Кодекс поведения**: ссылка на CODE_OF_CONDUCT.md (см. [спецификацию кодекса поведения](./code-of-conduct-specification.md)).
8. **Соглашение об Issue**: требования к заполнению при вопросах и отчётах о дефектах.
9. **Заявление о лицензии**: вклад по умолчанию распространяется по лицензии проекта (см. [спецификацию LICENSE](./license-specification.md)).

## 2. Требования к написанию

1. Команды должны выполняться напрямую и содержать указание необходимого рабочего каталога.
2. Для каждого шага процесса указываются условие запуска и ожидаемый результат.
3. Не допускается писать только «PR приветствуются» без содержательного процесса (соответствует проверке управления сообществом в [контрольной точке качества](./quality-gate.md)).
