# Спецификация продвижения открытого исходного кода

> Какую задачу решает этот файл: определяет каналы продвижения открытого проекта до и после релиза, ритм публикаций, материалы главной страницы и правила работы с сообществом, чтобы проект с пригодной документацией получал охват, соответствующий его целевой аудитории.

Перечень каналов и принципы настоящего файла опираются на главу о продвижении из книги phodal «Путеводитель по GitHub»; этот проект с 11,362 звёздами подтвердил применимость данных практик в китайском сообществе открытого исходного кода.

## 1. Основные принципы

1. **Качество предшествует продвижению**: продвижение лишь усиливает уже имеющееся качество и не устраняет его отсутствие. До готовности README, примеров, документации и тестов начинать продвижение запрещено.
2. **Сам проект — не всё продвижение**: помимо кода и README необходимо подготовить подробную документацию, примеры программ и механизм реагирования на проблемы.
3. **Ясная мотивация**: продвижение служит конкретной цели (получение ранних пользователей, привлечение контрибьюторов, сбор обратной связи); продвигать ради количества звёзд запрещено.
4. **Соответствие каналов**: каналы выбираются по технологическому стеку проекта и целевой аудитории; неизбирательное размещение не допускается.
5. **Честная подача**: запрещается выдумывать число звёзд, число загрузок или случаи использования; сравнение характеристик должно опираться на проверяемые факты.

## 4. Ритм публикаций

1. **Подготовительный период**: выполнить контрольный список раздела 2, подготовить однострочный текст, скриншоты, демонстрационную анимацию и прочие материалы.
2. **Период первого запуска**: публикация в 1–2 наиболее подходящих каналах; многократное дублирование одного материала на разных платформах не допускается.
3. **Период реагирования**: в течение 72 часов после первого запуска поддерживается высокая частота ответов, обрабатываются Issue и обратная связь.
4. **Период итераций**: содержимое непрерывно обновляется в ритме выпуска версий, каждый релиз сопровождается описанием изменений.
5. **Период накопления**: частые вопросы оформляются в FAQ и возвращаются в документацию.

## 5. Требования к материалам главной страницы

| Материал | Спецификация | Назначение |
| --- | --- | --- |
| Однострочный текст | На китайском не более 60 иероглифов / на английском не более 25 слов; в Description репозитория используется двуязычный объединённый формат «национальный язык \| английский», см. раздел 5 [спецификации именования проектов](./project-naming-specification.md) | Description репозитория, аннотация в социальных сетях |
| Скриншот | Две версии для тёмной и светлой темы, контролируемая ширина | Первый экран README |
| Демонстрационная анимация | Контролируемый объём после сжатия, показ основного сценария | Раздел демонстрации README |
| Логотип | Формат SVG, версии для тёмной и светлой темы | Первый экран и карточки в социальных сетях |
| Таблица сравнения характеристик | На основе проверяемых фактов, с указанием неприменимых сценариев | README или сайт документации |

Материалы должны обновляться вместе с версиями, чтобы не демонстрировать устаревший интерфейс.

## 6. Работа с сообществом

1. Для впервые участвующих предоставляется явный вход, например метка `good first issue`.
2. Реагирование на проблемы должно фиксироваться, чтобы повторяющиеся вопросы не возникали снова и снова.
3. Кодекс поведения действует во всех каналах сообщества, см. [спецификацию кодекса поведения](./code-of-conduct-specification.md).
4. Благодарности контрибьюторам размещаются централизованно, а не разбросаны по тексту.
5. Получать искусственное внимание через побуждение к звёздам, взаимные лайки и подобные приёмы запрещается.

## 7. Запрещённые практики

1. Запрещается продвижение при невыполненном контрольном списке качества.
2. Запрещается выдумывать или преувеличивать данные проекта и случаи использования.
3. Запрещается многократно дублировать один и тот же материал в разных каналах.
4. Запрещается принижать аналогичные проекты ради улучшения собственного имиджа.
5. Запрещается использовать приёмы побуждения для получения звёзд.
