# Спецификация NOTICE

> Какую задачу решает этот файл: определяет семь обязательных частей файла NOTICE и требования согласованности с README, обеспечивая выделение деклараций третьих сторон в отдельный файл и точность сведений.

## 1. Отдельный файл

NOTICE оформляется отдельным файлом, не должен объединяться с README и не должен заменяться списком в README. Файл должен содержать следующие части:

1. **Декларация самого проекта**: название проекта, правообладатель, год, лицензия, идентификатор SPDX.
2. **Перечень сторонних компонентов**: по пунктам перечисляются согласно полям перечня зависимостей из [спецификации соответствия открытому исходному коду](./open-source-compliance-specification.md).
3. **Приложение с оригинальными текстами лицензий**: если лицензия требует приложения полного текста, полный текст прилагается для каждой лицензии; оригинальный текст сохраняется на английском языке и не переводится.
4. **Декларация об изменениях**: места и содержание изменений в стороннем коде.
5. **Декларация об источниках материалов и данных**.
6. **Отказ от ответственности**: сохраняется оригинальный английский текст, допускается приложение перевода на китайский язык.
7. **Вопросы, требующие подтверждения**: пункты, в которых невозможно установить лицензию или принадлежность авторских прав, явно помечаются «требует подтверждения».

## 2. Требования согласованности

Сведения о компонентах и лицензиях в NOTICE и в разделе 6 README (технологический стек и перечень зависимостей), разделе 19 (авторские права и лицензирование), разделе 20 (декларация соответствия NOTICE) должны полностью совпадать; расхождения в версиях, идентификаторах лицензий и правообладателях недопустимы.

## Связанные файлы
