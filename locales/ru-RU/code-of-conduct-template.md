# Шаблон кодекса поведения

> Какую задачу решает этот файл: предоставляет готовый к копированию шаблон кодекса поведения, по которому проект создаёт CODE_OF_CONDUCT.md с обязательствами участников, ожидаемым поведением, неприемлемым поведением, обязанностями по исполнению и каналами сообщения о нарушениях; сопутствующие указания по заполнению охватывают источник адаптации и заявление о версии.

## 1. Указания по использованию

1. Скопировать всё содержимое раздела 3 «Текст шаблона» и создать в корне проекта файл `CODE_OF_CONDUCT.md`.
2. Заменить заполнители согласно разделу 4; канал сообщения о нарушениях должен быть реально доступным адресом.
3. При принятии или адаптации версионированного кодекса поведения следует в разделе 5 заявить версию и лицензию согласно требованиям источника; основание см. в разделе 1 пункте 8 [спецификации кодекса поведения](./code-of-conduct-specification.md).
4. Сослаться на этот файл в [шаблоне руководства по участию](./contribution-guide-template.md) и в разделе о вкладе в README, обеспечив двустороннюю доступность.

## 2. Принципы настройки

- **Независимость от технологий**: кодекс не содержит технического содержания и регулирует только поведение при участии; границы см. в [матрице документации](./document-matrix.md).
- **Исполнимость**: для градуированных мер следует указывать условия срабатывания и сами меры; излагать только принципы без последствий запрещено.
- **Достижимость**: каналы сообщения о нарушениях должны быть реально действующими; оставлять примерные адреса запрещено.
- **Соответствие требованиям к источнику**: при адаптации стороннего кодекса следует сохранять требования к атрибуции и лицензии, см. [спецификацию соответствия требованиям открытого исходного кода](./open-source-compliance-specification.md).

## 3. Текст шаблона

```markdown
# Кодекс поведения

## Наши обязательства

Мы как участники, контрибьюторы и мейнтейнеры {{项目名称}} обязуемся совместно создавать открытую, доброжелательную среду участия без домогательств независимо от возраста, телосложения, состояния здоровья, расы, гендерной идентичности и самовыражения, уровня опыта, образования, социально-экономического статуса, гражданства, внешности или сексуальной ориентации.

## Область применения

Настоящий кодекс применяется в пространствах проекта, issue, pull request, ревью кода, социальных каналах, а также в публичных ситуациях, когда человек выступает как представитель проекта.

## Ожидаемое поведение

- Уважать иные мнения и опыт, общаться доброжелательно.
- Принимать конструктивную обратную связь, сосредоточиваясь на проблеме, а не на личности.
- Заботиться об общих интересах сообщества, не допускать ущерба проекту и его участникам.
- Проявлять терпение к новичкам и давать выполнимые предложения по улучшению.

## Неприемлемое поведение

- Личные нападки, оскорбительные или уничижительные высказывания.
- Дискриминационные высказывания и домогательства по любому защищаемому признаку.
- Публичные или приватные домогательства, преследование, навязчивые контакты без согласия.
- Публикация приватной информации других лиц без разрешения.
- Иное поведение, обоснованно признаваемое неподобающим в профессиональной среде.

## Обязанности по исполнению

Мейнтейнеры проекта разъясняют применение настоящего кодекса, выносят решения о нарушениях и вправе удалять, редактировать или отклонять содержимое, не соответствующее настоящему кодексу. Мейнтейнеры должны исполнять свои обязанности последовательно и беспристрастно, а при спорах, затрагивающих их самих, — самоустраняться.

## Меры реагирования

Нарушения рассматриваются с градуированными мерами по степени тяжести:

| Уровень | Применимая ситуация | Мера |
| --- | --- | --- |
| Первый | Непреднамеренное оскорбление, незначительная некорректность | Частное напоминание и разъяснение |
| Второй | Повторяющееся или явное нарушение | Публичное предупреждение, срок на исправление |
| Третий | Серьёзные домогательства, злонамеренные нападки | Временная блокировка права участия |
| Четвёртый | Продолжительное или необратимое серьёзное поведение | Постоянная блокировка с сохранением записей |

## Каналы сообщения о нарушениях

При столкновении с нарушением настоящего кодекса или его обнаружении следует связаться с командой мейнтейнеров по адресу {{真实可达的举报邮箱或渠道}}. Все сообщения рассматриваются конфиденциально; мейнтейнеры не должны раскрывать личность заявителя лицу, на которое поступила жалоба, кроме случаев явного согласия заявителя.

## Атрибуция и источник

{{准则来源声明}}
```

## 5. Указания по заполнению и варианты сценариев

| Сценарий | Ключевые моменты настройки |
| --- | --- |
| Личный проект | Мейнтейнером указывается сам автор; в качестве канала сообщения используется долгосрочный почтовый ящик |
| Корпоративный проект | В качестве исполнителя явно указывается юридическая служба или команда сообщества; меры реагирования должны соответствовать внутренним регламентам |
| Использование известного кодекса | Сохраняется полный исходный текст и версия, добавляются только каналы сообщения и атрибуция |
| Многоязычный проект | Положения языковых версий должны соответствовать друг другу пункт за пунктом; английская или китайская версия объявляется авторитетной с соответствующей пометкой |

Типичные ошибки:

| Ошибочная формулировка | Последствие | Правильная формулировка |
| --- | --- | --- |
| Написано только «добро пожаловать в доброжелательное общение» | Нет оснований для исполнения, при споре невозможно вынести решение | Перечислены ожидаемое поведение, неприемлемое поведение и градуированные меры |
| В канале сообщения оставлен примерный почтовый ящик | Недостижим, механизм сообщения не работает | Указан реальный и долгосрочно действующий адрес |
| Кодекс адаптирован без атрибуции | Нарушены требования лицензии источника | Заявлены источник, версия и лицензия |

## 6. Полный пример

Ниже приведён фрагмент сценария адаптации, только как образец формата.

```markdown
## Каналы сообщения о нарушениях

При столкновении с нарушением настоящего кодекса или его обнаружении следует связаться с командой мейнтейнеров по адресу conduct@example.com. Все сообщения рассматриваются конфиденциально.

## Атрибуция и источник

Настоящий кодекс адаптирован из Contributor Covenant 2.1 и распространяется по лицензии (CC BY 4.0).
```
