# Отчёт об исследовании шаблонов README

> Какую задачу решает этот файл: фиксирует методику исследования, размер выборки и количественные находки по данному стандартному шаблону README, предоставляя данные для [стандартного шаблона README](./readme-standard-template.md) и профильных спецификаций, а также явно обозначает границы и ограничения методики.

## 1. Цели и методика исследования

### 1.1 Цели

Исследовать ведущие открытые проекты с наибольшим числом звёзд, обобщить закономерности структуры их README и связанной документации, организации разделов, визуального представления и использования бейджей, чтобы сформировать пригодные для повторного применения общие правила и шаблоны.

### 1.2 Источники данных

- Метаданные репозиториев: GitHub GraphQL Search API, по убыванию числа звёзд, с фильтром `is:public archived:false fork:false`.
- Исходный текст README: GitHub REST Contents API (эндпоинт `readme`), получение в формате base64 или raw с последующим разбором.
- Параметры бейджей: официальная документация Shields.io (страницы Static Badge, Logos) и описание формата badge-maker.
- Практика китайского сообщества: проектная документация, сообщения коммитов и разделы о продвижении phodal/github («Путеводитель по GitHub», 11,362 star) — для дополнения принципов написания и опыта продвижения, которые машинная статистика не охватывает.

### 1.3 Методика сбора

1. **Метаданные**: один запрос GitHub Search API возвращает не более 1000 записей. Для расширения выборки применено разбиение по звёздным интервалам — методом деления пополам определялся порог числа звёзд для каждых 1000 позиций, всего 11 последовательных пакетов со смещением вниз, в результате получены метаданные 10,995 ведущих репозиториев.
2. **Выборка README**: внутри первых 1000 репозиториев выполнена стратифицированная выборка по основному языку с охватом Python, TypeScript, JavaScript, Rust, Go, C++ и других основных языков; отобрано 120 репозиториев, исходный текст README получен для всех.
3. **Единицы статистики**: частота появления разделов и частота использования элементов считаются в разрезе репозитория; стили бейджей и параметры logo считаются по числу вхождений в URL.

### 1.4 Ограничения методики (должны быть указаны явно)

- GitHub Search API имеет лимит 1000 записей на один запрос; в данном отчёте масштаб расширен последовательным разбиением, однако границы разбиения зависят от совпадающих значений звёзд, поэтому выборка представляет собой приближённое множество ведущих проектов, а не строго непрерывный рейтинг.
- Размер выборки README составляет 120; выводы отражают тенденции и общие черты и не являются статистически значимым распределением всех ведущих проектов.
- Идентификация разделов основана на сопоставлении ключевых слов заголовков, что даёт отклонения из-за различий в формулировках.
- Статистика параметров бейджей охватывает параметры, явно присутствующие в URL; параметры по умолчанию динамических бейджей не учитываются.

## 2. Распределение ведущих репозиториев (метаданные)

### 2.1 Размер выборки

- Один запрос стабильно возвращает первые 1000 репозиториев, звёздный интервал примерно от 563,574 до 30,857.
- После 11 пакетов разбиения выборка расширена до 10,995 ведущих репозиториев, нижняя граница числа звёзд — 5,452.

## 6. Обобщённые выводы

1. Универсальный шаблон должен строиться на основном стержне «позиционирование → установка → быстрый старт → документация → вклад → лицензия».
2. Бейджи по умолчанию — `flat-square` или `for-the-badge`, единообразные во всём тексте, в количестве 4–6.
3. Изображения и блоки кода — ядро привлекательной главной страницы, они должны сопровождаться `alt` и языковой разметкой.
4. Тип проекта определяет состав разделов, см. [руководство по адаптации README к категориям](./readme-category-adaptation-guide.md).
5. Соответствие требованиям и управление сообществом (лицензия, руководство по вкладу) — общая практика ведущих проектов, эти разделы отнесены к обязательным.

## 7. Пояснение о масштабе данных

Итог последовательного разбиения метаданных ведущих репозиториев: 10,995 репозиториев, звёздный интервал от 563,575 до 5,452. Распределение лицензий и языков в этой выборке порядка десяти тысяч приведено ниже и согласуется с выводами по выборке первых 1000:

| Измерение | Распределение |
| --- | --- |
| Язык | Python 1,995, TypeScript 1,529, JavaScript 1,279, без основного языка 888, Go 847, C++ 531, Java 528, Rust 507 |
| Лицензия | MIT 4,160 (37.8%), Apache-2.0 2,073 (18.9%), не идентифицирована 1,463, без лицензии 1,106, GPL-3.0 747 |

Выборка углублённой статистики README — 120 репозиториев, исходный текст получен для всех. При разбиении использовались приближённые звёздные пороги, поэтому множество является приближённым набором ведущих проектов, а не строго непрерывным рейтингом.
