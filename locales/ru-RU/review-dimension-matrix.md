# Матрица измерений проверки

> Какую задачу решает этот файл: определяет 14 измерений параллельной проверки фазы 2, ключевые пункты проверки каждого из них, рекомендуемых агентов и уровень сбоя, служа основой для распределения задач и вынесения решений.

## Матрица измерений проверки

| # | Измерение | Ключевые пункты проверки (ключевые слова, детали раскрывает подагент) | Рекомендуемый агент | Уровень сбоя |
|---|---|---|---|---|
| D1 | Безопасность и приватность | Сканирование ключей, `.env`, закрытые ключи, внутренние домены/IP, персональные данные, остатки в журналах | security-auditor | P0 |
| D2 | Лицензии и право | Наличие и тип LICENSE, совместимость лицензий зависимостей, NOTICE, заявления о третьих сторонах | license-checker | P0 |
| D3 | Гигиена репозитория | Полнота `.gitignore`, артефакты и каталоги зависимостей, `.gitattributes`, переводы строк LF, бит исполняемости, конфликты регистра в именах файлов | repo-hygienist | P0/P1 |
| D4 | Объём и двоичные файлы | Файлы >50MB, сжатие изображений, настройка LFS, разбухание истории | repo-hygienist | P1 |
| D5 | Воспроизводимость сборки | Коммит lockfile, объявление версии движка, скрипты сборки, успешная сборка в чистом окружении | build-verifier | P0 |
| D6 | Тесты и статический анализ | Прохождение модульных тестов, покрытие, lint, format, проверка типов | ci-runner | P0/P1 |
| D7 | История коммитов | Conventional Commits, атомарность, отсутствие WIP, сведения об авторе, отсутствие чувствительных commit message | commit-reviewer | P1 |
| D8 | Ветки и релиз | Защита main, именование веток, тег SemVer, annotated tag, Release Notes | release-manager | P1 |
| D9 | Автоматизация | Работоспособность рабочего процесса CI, бейджи состояния, dependabot, CODEOWNERS, шаблоны issue/PR | ci-runner | P1 |
| D10 | Метаданные репозитория | description (двуязычный объединённый формат `национальный язык \| английский`, не более 120 символов на каждый язык), topics (заполнены все 20, только английский, только строчные буквы), ветка по умолчанию, ссылки в About, social preview | metadata-agent | P1 |
| D11 | Полнота документации | Постатейная проверка наличия по матрице документации | docs-orchestrator | P0/P1 |
| D12 | Качество документации | Уровни заголовков, языковые идентификаторы блоков кода, работоспособность ссылок, alt изображений, пробелы между китайским и английским текстом, отсутствие заполнителей | docs-orchestrator | P1/P2 |
| D13 | Главная страница README | Однострочное позиционирование, установка, быстрый старт, бейджи ≤4, скриншоты, отсутствие локальных абсолютных путей | readme-writer | P1 |
| D14 | Управление сообществом | CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, шаблоны Issue, каналы поддержки | docs-orchestrator | P2 |

## Значение уровней

- **P0**: блокирует пуш.
- **P1**: следует исправить до пуша или обязательно зарегистрировать как задачу.
- **P2**: рекомендация по улучшению.
