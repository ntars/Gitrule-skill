# Спецификация написания Skill

> Какую задачу решает этот файл: определяет структуру, условия срабатывания и способ прогрессивной загрузки при упаковке набора спецификаций в Skill, гарантируя, что Skill обнаруживаем, сопровождаем и не дублирует содержание.

## 1. Структура каталогов

Skill использует структуру «точка входа + ресурсы по требованию»:

```text
skill-name/
├── SKILL.md          обязательно: метаданные + основной процесс
├── references/       текст спецификации, загружается по требованию
└── assets/           шаблоны и материалы (необязательно)
```

## 2. Требования к SKILL.md

1. Метаданные содержат `name` и `description`; в описании следует указывать «что делает + когда применяется», чтобы обеспечивать срабатывание.
2. В основном тексте остаются только постоянно актуальные ключевые правила и процессы, подробное справочное содержание помещается в `references/`.
3. Используется повелительное или неопределённая форма глагола, второе лицо не применяется.
4. При ссылке на ресурсы указываются явный путь и условие «когда читать».

## 3. Абсолютные правила

1. Основной текст спецификации сопровождается только в одном месте: Skill ссылается на файлы данного набора спецификаций и не копирует полный текст, чтобы избежать расхождения двух копий.
2. Один Skill решает одну задачу; помещать несколько обязанностей в один Skill запрещено.
3. В условиях срабатывания указываются конкретные фразы, чтобы избежать слишком широкого срабатывания.
4. Версия обновляется синхронно с версией набора спецификаций.
