# Спецификация машиночитаемых метаданных

> Какую задачу решает этот файл: определяет структуру перечня метаданных для программного потребления экспертами, Skill, MCP, командной строкой и другими программами, обеспечивая стабильность и обнаруживаемость машинного доступа.

## 1. Цели проектирования

1. Стабильный идентификатор: каждый документ имеет уникальный неизменный идентификатор для программных ссылок.
2. Независимость от языка: идентификатор не меняется вместе с языком, язык отражается только в пути.
3. Обнаруживаемость: перечень содержит тип, путь, язык и краткое описание каждого документа.

## 2. Структура перечня

Машинный перечень (manifest) должен содержать:

| Поле | Требование |
| --- | --- |
| id | Стабильный уникальный идентификатор, kebab-case в нижнем регистре, без языка и версии |
| title | Заголовок документа |
| summary | Одно предложение о решаемой задаче |
| domain | Принадлежность к области (одна из семи областей) |
| paths | Сопоставление языкового кода с относительным путём, например `zh-CN`: `./locales/zh-CN/角色与职责.md` |
| version | Версия набора спецификаций |

## 3. Обязательные правила

1. Новый язык только добавляет сопоставление в `paths`, не изменяя `id` и пути других языков.
2. При переименовании документа `id` должен сохраняться, обновляется только `paths`.
3. Идентификаторы и пути должны соответствовать фактическим файлам; CI проверяет валидность перечня.
4. Данная спецификация предоставляет копируемый пример перечня; целевой проект должен создать реальный экземпляр перечня по полям раздела 2 и обеспечить соответствие `paths` файлам на диске.

## 4. Пример перечня (копируемый)

Приведённый пример содержит три записи о документах. Фактический перечень должен охватывать все спецификации целевых языковых каталогов; `id` не меняется вместе с языком, `paths` дополняется сопоставлениями по языковым кодам.

```json
{
  "version": "1.0.0",
  "entries": [
    {
      "id": "role-and-responsibility",
      "title": "角色与职责",
      "summary": "定义执行者身份、职责边界、触发条件、适用范围与硬性约束",
      "domain": "总纲与治理",
      "paths": {
        "zh-CN": "./locales/zh-CN/角色与职责.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "readme-standard-template",
      "title": "README标准模板",
      "summary": "提供可直接套用的通用 README 模板与占位符对照表",
      "domain": "命名与文档",
      "paths": {
        "zh-CN": "./locales/zh-CN/README标准模板.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "machine-readable-metadata",
      "title": "机器可读元数据规范",
      "summary": "定义供专家、Skill、MCP、命令行消费的元数据清单结构",
      "domain": "AI 与机器适配",
      "paths": {
        "zh-CN": "./locales/zh-CN/机器可读元数据规范.md"
      },
      "version": "1.0.0"
    }
  ]
}
```

При добавлении языка в `paths` соответствующей записи только добавляется сопоставление, например `"en-US": "./locales/en-US/role-and-responsibility.md"`; изменять `id` запрещено.
