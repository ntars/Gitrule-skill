# 多言語規範

> このファイルが解決する問題：言語コード別にディレクトリを分けるファイル配置、言語切り替え、翻訳の一貫性、コードの一貫性、および片側修正の同期ルールを定義する。

## 1. ディレクトリ配置

1. リポジトリルートの `README.md` はプロジェクトのホームページと言語ナビゲーションのみを担い、具体的な規範本文を載せない。
2. 具体的な規範は言語コード別に `locales/<language-code>/` ディレクトリへフラットに配置する。例えば `locales/zh-CN/角色与职责.md`。
3. 言語コードは BCP 47 形式を用いる。例えば `zh-CN`、`en-US`、`ja-JP`、`ko-KR`。言語コードはディレクトリ名にのみ現れ、ファイル名には書かない。
4. **ファイル名はその言語自体を使用しなければならない**：中国語ディレクトリでは中国語のファイル名（`角色与职责.md`）、英語ディレクトリでは英語の小文字ハイフン区切りファイル名（`roles-and-responsibilities.md`）、他の言語も同様とする。非中国語ディレクトリで中国語のファイル名を踏襲することは禁止する。
5. 各言語ディレクトリのファイル名は逐語的に対応する必要はないが、一対一のマッピングを必須とする。同一の規範は各言語ディレクトリで内容と責務が同じであり、マッピング関係は一覧ファイルの `paths` フィールドに登録する（[機械可読メタデータ規範](./機械可読メタデータ規範.md) を参照）。
6. 簡体字中国語と英語を最初の完成版とする。その他の言語はルート `README.md` の言語表に「未定」または「完成済み」と記載し、ディレクトリを設けていない言語に空のリンクを提供してはならない。
7. 言語を追加する場合は対応する言語ディレクトリを新設して 1 篇ずつ翻訳するのみとし、既存の言語ファイルは変更しない。ソース言語の改訂で同期が必要な場合に限り、他の完成済み言語を更新する。

## 2. 言語切り替え

1. 各言語ディレクトリの `README.md` の冒頭に言語切り替えリンクを提供しなければならない。
2. リンクは現在の言語ディレクトリからの相対パスを用いる。例えば簡体字中国語ディレクトリでの記述：
   `[English](../en-US/README.md) | [简体中文](./README.md)`。
3. リンクテキストは対象言語の自称を用いる。例えば `English`、`简体中文`、`日本語`。`CN`、`EN` などの略称は書かない。
4. 切り替えリンクは既に設置済みの言語ディレクトリのみを指す。未設置の言語ディレクトリはルート `README.md` の言語表で一括して記載し、本文中にリンク切れを残さない。

## 3. 翻訳の一貫性

1. 訳文は完全な翻訳でなければならず、セクション数、セクション順序、表の列数、コードブロック数がソース言語と一致すること。要約的なものや校正されていない機械翻訳的な成果物を提供してはならない。
2. コードブロック内のコマンド、パス、設定キー名、プレースホルダー名、パラメータ値は変更せず、コメントと説明文のみを翻訳する。 例えばディレクトリツリーのフェンス `├── SKILL.md   必須：メタデータ + コアフロー` では、分岐記号とパスはそのままにし、後続の説明文は翻訳する。
3. **利用者に表示されるテンプレート項目はローカライズする**：Issue フォームの `yaml` 設定では、`name`、`label`、`description`、`placeholder` およびドロップダウンの選択肢が GitHub の画面上に直接表示されるため、対象言語に翻訳する。`type`、`id`、`labels`、`required`、`render` などの構造化項目は英語のままとする。判断基準は「その項目が人に見せるものかどうか」であり、「コードフェンス内にあるかどうか」ではない。同様に、`markdown` フェンス内のコピー用テンプレート本文は必ず翻訳する。
4. 用語は [情報収集とテンプレート](./情報収集とテンプレート.md) の中英対訳表に従って統一する。同一の概念はすべての言語で同一の対応関係を用いる。
5. いずれかの片側修正は、完成済みのすべての言語に同期しなければならず、更新ログに同期した言語コードとバージョンを記録する。同期が完了していない改訂は完了と判定してはならない。
6. 一貫性の検証はゲート G10 に属する。[品質ゲート](./品質ゲート.md) を参照。

## 4. 法的テキスト

1. NOTICE は既定で中国語版を提供する。ライセンス原文、著作権表示、免責事項に関わる法的テキストは英語原文を保持し、翻訳・改変しない。
2. 中英対照が必要な法的テキストは原文と訳文を併記し、「訳文は参考用であり、原文を正とする」と明記する。
3. 法的テキストの言語処理は [NOTICE規範](./NOTICE規範.md) と [免責事項](./免責事項.md) を参照。
