# 用語集

> このファイルが解決する問題：プロジェクト全体で使用する専門用語と略語を集中的に定義し、中国語版と英語版の用語が一対一で対応し、全文で表現が一貫することを保証します。

## 1. 保守ルール

1. 用語が初めて出現する時点で定義を示さなければならず、形式は「中文术语（English Term，缩写）」とします。
2. 同一の概念は全文で 1 つの表現のみを使用します；中国語版と英語版の用語は一対一で対応し、本表を共有します。
3. 新しい用語を追加する場合は本表に同期して記載し、英語版の対応箇所にも同期します。
4. 略語が初めて出現する場合は完全な名称を展開しなければならず、その後は略語を直接使用できます。

## 2. 用語対照表

| 中文 | English | 缩写 | 説明 |
| --- | --- | --- | --- |
| 软件物料清单 | Software Bill of Materials | SBOM | プロジェクトの依存関係とコンポーネントの完全な一覧 |
| 语义化版本 | Semantic Versioning | SemVer | バージョン番号の形式 `MAJOR.MINOR.PATCH` |
| 架构决策记录 | Architecture Decision Record | ADR | 重要なアーキテクチャ決定とその背景・結果を記録するもの |
| 行为准则 | Code of Conduct | CoC | コミュニティ参加者の行動規範 |
| 持续集成 / 持续交付 | Continuous Integration / Continuous Delivery | CI/CD | 自動化されたビルド、テスト、デリバリーのプロセス |
| 软件许可证标识符 | Software Package Data Exchange | SPDX | ライセンスの標準識別子体系 |
| 最小可行产品 | Minimum Viable Product | MVP | 中核仮説を検証できる最小のバージョン |
| 自然语言处理 | Natural Language Processing | NLP | テキスト処理に関連する技術 |
| 大模型 | Large Language Model | LLM | 大規模に事前学習された言語モデル |
| 模型上下文协议 | Model Context Protocol | MCP | モデルと外部ツールを接続するプロトコル |
| 待补充 | To Be Determined | TBD | 情報が未確認であることを示すプレースホルダー |

> 表中の項目は汎用的な例であり、使用前にプロジェクトの実際の用語に合わせて追加・削除しなければなりません。

- **共通略語**: 各言語の本文でそのまま用いられ、言語によって変わらない：SBOM、SPDX、ADR、SemVer、CoC、CI/CD、MVP、NLP、LLM、MCP、TBD。

本表は各言語における用語の固定訳を示し、新しい言語の追加や全文置換の際に直接参照できるようにするものである。用語は引用形（主格または不定形）で示す。ロシア語とドイツ語の本文では格変化するため、検索は語幹で行う。

収録方針：本文に実際の用例がある用語のみを収録し、下表の各セルは該当する言語ディレクトリ内で検索できる。SBOM、MVP、NLP、LLM の四語は十二言語の本文での出現回数が 0 であり、前節の対照表に例として存在するのみのためマトリクスには含めない。SPDX は各言語の本文で常に略語のまま用いられ全称が現れないため、他の略語とともに上記の略語行に示し、訳語の列は設けない。

言語を追加する際は、まず本表に従って訳語を補い、そのうえで `python3 cli/gitrule.py xcheck --path . --reference zh-CN` を実行して構造の一貫性を検証すること。
