# アクセシビリティ規範

> このファイルが解決する問題：プロジェクトのドキュメント、README、ユーザーインターフェースのアクセシビリティ要件を定義し、スクリーンリーダー、キーボード操作、さまざまな視覚条件の読者にも同様に利用できるようにします。

## 1. 適用範囲

1. ドキュメントのアクセシビリティ：README、ドキュメントサイト、サンプルコード、表、画像。
2. インターフェースのアクセシビリティ：アプリケーションおよび Web プロジェクトのユーザーインターフェース。
3. コマンドラインのアクセシビリティ：ヘルプテキスト、エラーメッセージ、出力形式。

## 2. ドキュメントのアクセシビリティ

### 2.1 画像とメディア

1. すべての画像には `alt` テキストを提供し、画面の内容と役割を説明しなければなりません；装飾的な画像には空の `alt` を使用します。
2. 「图片」「截图」「image」など情報のないテキストを `alt` として使用してはなりません。
3. GIF アニメーションは隣接するテキストでその内容を説明しなければならず、アニメーションのみで情報を伝えることは避けます。
4. グラフは同時にテキストによる説明またはデータ表を提供しなければならず、色のみでデータ系列を区別してはなりません。

### 2.2 見出しと構造

1. 見出しの階層は連続させ、飛ばしてはなりません（[READMEビジュアルレイアウト規範](./READMEビジュアルレイアウト規範.md) を参照）。
2. 全文で第一レベル見出しは 1 つのみとします。
3. リストは正規の Markdown 構文を使用し、スクリーンリーダーがリストとして認識できるようにします。
4. 表にはヘッダー行が必要で、ヘッダーのない表でページをレイアウトしてはなりません。

### 2.3 リンクとテキスト

1. リンクテキストは単独で対象を説明できなければならず、「ここをクリック」「もっと見る」の使用は禁止です。
2. 色を情報伝達の唯一の手段としてはならず、テキストやアイコンを併用します。
3. 中国語と外国語を混在させる場合は空白を保持し、単語分割と読み上げが正しく行われるようにします。
4. 略語が初めて出現する時点で完全な名称を示します。

### 2.4 コードと表

1. コードブロックには言語を明記し、支援ツールが識別しやすいようにします（[READMEビジュアルレイアウト規範](./READMEビジュアルレイアウト規範.md) を参照）。
2. 表のセルの内容は簡潔にし、行の結合によってリーダーの解析が困難になることを避けます。
3. 長いコマンドは分割した記法を示し、横スクロールに依存しません。

## 3. インターフェースのアクセシビリティ

### 3.1 キーボード操作

1. すべてのインタラクティブ要素はキーボードで到達し操作できるようにします。
2. フォーカスの順序は視覚的な順序と一致し、フォーカス状態は明確に視認できるようにします。
3. 繰り返しコンテンツをスキップするショートカット（メインコンテンツへのジャンプなど）を提供します。

### 3.2 セマンティクスとラベル

1. 構造と役割を表すためにセマンティックなタグを使用し、セマンティクスのない要素でコントロールを模倣することを避けます。
2. フォームコントロールには関連付けられたラベルが必要で、エラーメッセージは対応するフィールドに結び付けます。
3. 動的な状態の変化はアクセシビリティ通知を通じて支援技術に伝えます。

### 3.3 視覚条件

1. テキストと背景のコントラストは可読性の要件を満たします；本文のコントラストは 4.5:1 以上、大きな文字は 3:1 以上とします。
2. システムのライト・ダークテーマをサポートし、テーマの切り替えで情報構造を変えません（[READMEビジュアルレイアウト規範](./READMEビジュアルレイアウト規範.md) を参照）。
3. アニメーションには低減オプションを提供し、自動再生される高頻度の点滅コンテンツを避けます。
4. テキストを 200% に拡大してもレイアウトが使用可能で、内容の切れが生じないようにします。

## 4. コマンドラインのアクセシビリティ

1. エラーメッセージは原因と実行可能な修正動作を説明し、エラーコードのみを出力してはなりません。
2. `--help` の出力は分類が明確で、必須パラメータと既定値を列挙します。
3. カラー出力を無効化する環境変数をサポートし、スクリーンリーダーやログ処理に配慮します。
4. 対話的なプロンプトには非対話の等価なパラメータを提供し、自動化シナリオをサポートします。

## 5. 検証チェックリスト

- [ ] すべての画像に情報が明確な `alt` テキストがある。
- [ ] 見出しの階層が連続し、全文で第一レベル見出しが 1 つである。
- [ ] リンクテキストが単独で理解できる。
- [ ] 表にヘッダーがあり、色が唯一の情報伝達手段ではない。
- [ ] コードブロックに言語が明記されている。
- [ ] インターフェース要素がキーボードで操作でき、フォーカスが視認できる。
- [ ] コントラストが最低要件を満たし、ライト・ダーク両テーマで読める。
- [ ] ヘルプテキストとエラーメッセージが次の操作を導ける。

## 6. 禁止事項

1. テキストによる代替を提供せず、純粋な画像のみで重要な情報を伝えることは禁止です。
2. 色のみで状態やエラーを表すことは禁止です。
3. 意味のないリンクテキストを使用することは禁止です。
4. 代替を提供せずにフォーカス表示のスタイルを削除することは禁止です。
