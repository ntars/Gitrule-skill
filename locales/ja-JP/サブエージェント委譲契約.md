# サブエージェント委譲契約

> このファイルが解決する問題：サブエージェントへタスクを委譲する際に必ず明記しなければならない四要素と協働の制約を定義し、結論が構造化され、検証可能で、ルールの逸脱がないことを保証します。

## 1. 委譲の四要素

委譲のたびに四要素を必ず明記します：

```text
TASK:    <一句话任务>
INPUT:   <需要的文件/上下文，只给必要部分>
OUTPUT:  <结构化格式，表格或 JSON，禁止散文>
FAIL:    <做不了时返回什么，而不是瞎编>
```

## 2. 制約

- 1 つのサブエージェントは一度に 1 つのことだけを行い、「ついでに README も書いておく」ことは禁止です。
- サブエージェントは読み取りと方案の提示のみが可能です；**ファイルの書き込みと git 操作は統一的に主制御側が実行します**。
- サブエージェントの結論には必ず根拠（ファイルパス + 行番号 / コマンド出力）を付けなければならず、根拠のない結論は無効とみなします。
- サブエージェント同士は直接通信せず、すべて主制御側が集約し、ルールの逸脱を避けます。
