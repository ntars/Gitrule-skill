# LICENSE規範

> このファイルが解決する問題：プロジェクトライセンスの SPDX 表記、LICENSE 全文の要件、著作権表示行の位置と複数ライセンスの説明、および確認なしに記載してはならないルールを定義します。

## LICENSE ルール

1. プロジェクトのライセンスは SPDX 識別子で README に明記しなければならず、対応する LICENSE ファイルを提供します。
2. LICENSE ファイルは当該ライセンスの公式な英語全文でなければならず、条項を削除・改変してはなりません。
3. 著作権表示行はファイルの先頭または README の第 19 章に配置し、形式は [READMEセクション規範](./READMEセクション規範.md) を参照します。
4. デュアルライセンスまたはマルチライセンスを採用する場合は、適用条件と選択方法を説明しなければなりません。
5. ライセンスの選択がユーザーに確認されていない場合、ドキュメントに直接記載してはならず、候補方案と差異の説明のみを提示します。
