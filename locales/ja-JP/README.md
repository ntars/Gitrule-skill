## リーディングパス

- **適用範囲の決定**：規範選定ガイド → ライフサイクルマッピング表 → 該当段階の規範ファイル。
- **ライフサイクル全体**：ライフサイクルマッピング表 → プロジェクト立ち上げと要求規範 → 要求トレーサビリティマトリクス規範 → アーキテクチャ設計書規範 → テスト規範 → デプロイとロールバック規範 → 可観測性規範 → イテレーション振り返り規範。
- **迅速なプッシュ**：ハードルール → 品質ゲート → プッシュとリリース規範 → 監査レポート形式。
- **ゼロからドキュメントを生成**：役割と責任 → 実行プロセス → 情報収集とテンプレート → ドキュメントマトリクス → READMEセクション規範 → オープンソースコンプライアンス規範 → 品質ゲート。
- **README の作成**：READMEテンプレート調査報告 → READMEビジュアルレイアウト規範 → バッジ規範 → README分類適応ガイド → README標準テンプレート。
- **完全な監査**：監査次元マトリクス → サブエージェント委譲契約 → ハードルール → 品質ゲート → 監査レポート形式。
- **プログラムからの接続**：機械可読メタデータ規範 → Skill作成規範 / MCPツール規範 / エージェント呼び出しとプロンプト規範。
- **リスクと責任の境界**：免責事項 → 免責事項テンプレート → SECURITYテンプレート → セキュリティとプライバシー規範 → オープンソースコンプライアンス規範。
- **コミュニティガバナンス文書の生成**：コントリビューションガイドテンプレート → 行動規範テンプレート → SECURITYテンプレート → 免責事項テンプレート。

## 用語の取り決め

- **必須 / 不可**：強制要求。
- **べき / べきでない**：推奨または禁止、逸脱する場合は理由を説明すること。
- **任意**：選択可能。
- **P0 / P1 / P2**：P0 はプッシュをブロックする。P1 はプッシュ前に修正するか、必ず TODO として登録する。P2 は改善を提案する。
