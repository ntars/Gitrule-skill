# プロジェクト命名規範

> このファイルが解決する問題：リポジトリ名の文字種、大文字小文字、語の分割、長さ、意味性などのハードルール、および命名公式、慣例的な接尾辞、検索フロー、付随するメタデータ要件を定義する。

## 1. ハードルール

| ルール | 要件 | 反例 |
|---|---|---|
| 文字種 | `a-z`、`0-9`、`-` のみ | `My_Proj`、`我的项目` |
| 大文字小文字 | すべて小文字 | `MyProject` |
| 語の分割 | kebab-case。`-` で連結 | `myproject`、`my_project` |
| 長さ | 2–25 文字 | 長すぎる連結名 |
| 末尾 | 名詞、または形態を表す接尾辞で終わる | `-project`、`-test` で終わる |
| バージョン | バージョン番号、年、日付を含まない | `tool-v2`、`app2024` |
| 無情報語 | `my`/`demo`/`test`/`new`/`tmp` は禁止 | `my-new-demo` |
| 一意性 | GitHub / npm / PyPI でそれぞれ 1 回検索する | 著名なライブラリとの重複 |
| 意味性 | 名前自体から「何をするか」が読み取れる | `xyz`、`abc123` |

## 2. 命名公式（4 つから 1 つ選択）

```text
<技术>-<对象>          vue-virtual-table      go-ratelimit
<对象>-<形态>          note-cli   image-api   config-loader
<动词>-<对象>          parse-markdown   sync-dotfiles
<领域>-<子领域>        web-ui-kit   data-pipeline
```

## 3. 慣例的な接尾辞

`-cli` コマンドライン / `-sdk` クライアントライブラリ / `-api` `-server` サーバーサイド / `-template` `-boilerplate` スキャフォールド / `-loader` `-parser` ミドルウェア / `-kit` コンポーネント集 / `-notes` `-guide` ドキュメント / `dotfiles` 設定リポジトリ / `awesome-xxx` リソース集。

## 4. 命名フロー

1. 「そのプロジェクトが誰のどんな問題を解決するか」を一文で書く。
2. その文から中核となる名詞 + 形態を取り出し、第 2 節のいずれかの公式に当てはめる。
3. 候補を 3 つ生成し、1 つずつ重複検索を行う。
4. README を見なくても最も理解できるものを選ぶ。
5. 中国語名はリポジトリ名に書かず、README の先頭行のタイトルの後に書く。

## 5. 付随するメタデータ

### 5.1 リポジトリ概要（description）

- リポジトリ名と同源であり、文型は `<何をするか> for <誰に>`。
- 二言語併記の形式：`国家言語 | 英語`。まず国家言語版を書き、半角縦線（両側に半角スペースを 1 つずつ）を挟み、その後に英語版を書く。中国語プロジェクトの例：

```text
轻量级 Go 命令行 JSON 处理工具 | A lightweight Go CLI for JSON processing
```

- 長さ：国家言語と英語はそれぞれ 120 文字以内、二言語合計で 350 文字以内（GitHub の上限）。
- 二言語合計が上限を超える場合の取捨選択：国家言語版ではなく英語版を優先的に圧縮する。中国語は情報密度が高く、中国語を圧縮すると失われる情報が多いためである。圧縮時はまず修飾語と重複する限定語を削除し、次に同義表現を統合し、最後に両言語版それぞれの完全な主述構造を保持する。
- 改行、Markdown 記法、絵文字を含まない。両言語の末尾の句読点のスタイルを揃える（統一して句点を付ける、または統一して付けない）。

### 5.2 トピック（topics）

- 20 個まで埋める（GitHub の上限）。完全に網羅し、空きを残さない。
- すべて英語を使用し、中国語その他の言語を使用してはならない。すべて小文字で `-` により連結し、スペースと特殊文字を含まない。
- 言語、領域、形態、エコシステム、シナリオの 5 分類を完全に網羅し、さらに documentation、open-source などの汎用語を追加してよい。
- リポジトリ作成時に設定し、空にしてはならない。リポジトリ名の変更や再位置づけの後にもう一度見直す。
