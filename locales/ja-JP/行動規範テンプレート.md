# 行動規範テンプレート

> このファイルが解決する問題：そのまま複製できる行動規範テンプレートを提供し、プロジェクトが CODE_OF_CONDUCT.md を生成するために用いる。参加への約束、期待される行動、受け入れられない行動、執行の責務、通報窓口を明確にし、あわせて改変元とバージョンの宣言を網羅する記入説明を添える。

## 1. 使用説明

1. 第 3 節「テンプレート本文」の内容をすべて複製し、プロジェクトのルートディレクトリに `CODE_OF_CONDUCT.md` として新規作成する。
2. 第 4 節に従ってプレースホルダーを置き換える。通報窓口は実際に到達可能なアドレスでなければならない。
3. バージョン管理された行動規範を採用または改変した場合は、第 5 節に従って出典の要件に沿ってバージョンとライセンスを宣言しなければならない。根拠は [行動規範](./行動規範.md) 第 1 節第 8 項を参照。
4. [コントリビューションガイドテンプレート](./コントリビューションガイドテンプレート.md) と README のコントリビューションのセクションから本ファイルへリンクし、双方向に到達できるようにする。

## 2. カスタマイズの原則

- **技術非依存**：規範は技術的な内容を含まず、参加行動の規範のみを定める。境界は [ドキュメントマトリクス](./ドキュメントマトリクス.md) を参照。
- **実行可能**：段階的な処置にはトリガー条件と措置を明記しなければならず、原則だけを書いて帰結を書かないことは禁止する。
- **到達可能性**：通報窓口は実際に有効でなければならず、例示用のアドレスを残すことは禁止する。
- **コンプライアンス上の出典**：サードパーティの規範を改変する場合は、その表示とライセンスの要件を保持しなければならない。[オープンソースコンプライアンス規範](./オープンソースコンプライアンス規範.md) を参照。

## 3. テンプレート本文

```markdown
# 行動規範

## 私たちの約束

私たちは {{项目名称}} の参加者、コントリビューター、メンテナーとして、年齢、体格、障がいの状況、人種、性自認と性表現、経験の程度、教育歴、社会経済的地位、国籍、外見、性的指向にかかわらず、オープンで親しみやすく、ハラスメントのない参加環境を共に築くことを約束します。

## 適用範囲

本規範は、プロジェクトの空間、イシュー、プルリクエスト、コードレビュー、ソーシャルチャネル、および個人がプロジェクトの代表として関わる公開の場に適用されます。

## 期待される行動

- 異なる意見と経験を尊重し、善意をもって対話する。
- 建設的なフィードバックを受け入れ、個人ではなく問題そのものに焦点を当てる。
- コミュニティ全体の利益に関心を向け、プロジェクトとその参加者を損なうことを避ける。
- 新規参加者に根気よく接し、実行可能な改善提案を示す。

## 受け入れられない行動

- 人格攻撃、侮辱的または貶める発言。
- 保護される特性に基づく差別的な発言とハラスメント。
- 公開または非公開でのハラスメント、つきまとい、同意のない継続的な連絡。
- 許可なく他者のプライバシー情報を公開すること。
- その他、専門的な環境において合理的に不適切と認められる行為。

## 執行の責務

プロジェクトのメンテナーは本規範の適用を明確にし、違反行為を裁定する責務を負い、本規範に適合しないコンテンツを削除、編集、または拒否する権限を持ちます。メンテナーは一貫した公正な方法で責務を行使しなければならず、自らが関わる紛争からは進んで身を退かなければなりません。

## 処置措置

違反行為は情状の軽重に応じて段階的に処置します：

| 等級 | 適用される状況 | 措置 |
| --- | --- | --- |
| 一級 | 意図しない無礼、軽微な不適切さ | 非公開での注意と説明 |
| 二級 | 繰り返しの発生、または明確な違反 | 公開の警告、期限を定めた是正 |
| 三級 | 深刻なハラスメント、悪意ある攻撃 | 参加権限の一時停止 |
| 四級 | 継続的または取り返しのつかない重大な行為 | 永久停止と記録の保持 |

## 通報窓口

本規範に違反する行為に遭遇した、または発見した場合は、{{真实可达的举报邮箱或渠道}} からメンテナンスチームにご連絡ください。すべての通報は秘密裏に扱われ、メンテナーは通報者が明確に同意した場合を除き、通報者の身元を通報対象者に開示してはなりません。

## 表示と出典

{{准则来源声明}}
```

## 4. プレースホルダー対照表とフィールド定義

| プレースホルダー | 必須 | フィールド定義 | 記入例 |
| --- | --- | --- | --- |
| `{{项目名称}}` | はい | プロジェクトの対外的な名称。README の先頭行と一致させる | `FooBar` |
| `{{真实可达的举报邮箱或渠道}}` | はい | メンテナーに直接連絡できる実際のアドレス | `conduct@example.com` |
| `{{准则来源声明}}` | はい | オリジナルならオリジナルと書く。改変した場合は出典の名称、バージョン、ライセンスを書く | `Contributor Covenant 2.1（CC BY 4.0）を改変` |

## 5. 記入説明と場面別のバリエーション

| 場面 | 調整の要点 |
| --- | --- |
| 個人プロジェクト | メンテナーは本人と書き、通報窓口は長期にわたり保有するメールアドレスを用いる |
| 企業プロジェクト | 法務またはコミュニティチームを執行の主体として明確にし、処置措置は社内制度と一致させなければならない |
| 著名な規範を採用 | その原文とバージョンを完全に保持し、通報窓口と表示のみを補う |
| 多言語プロジェクト | 各言語版の条項を一対一で対応させる。英語版または中国語版を権威ある版として明記する |

よくある誤りの対照：

| 誤った書き方 | 帰結 | 正しい書き方 |
| --- | --- | --- |
| 「親しみやすい対話を歓迎します」とだけ書く | 執行の根拠がなく、紛争時に裁定できない | 期待される行動、受け入れられない行動、段階的な処置を列挙する |
| 通報窓口に例示用のメールアドレスを残す | 到達できず、通報の仕組みが機能しない | 実際に有効で長期にわたって使えるアドレスを記入する |
| 改変した規範に表示がない | 出典のライセンス要件に違反する | 出典、バージョン、ライセンスを宣言する |

## 6. 完全な例

以下は改変した場面の抜粋であり、書式の参考にのみ供する。

```markdown
## 通報窓口

本規範に違反する行為に遭遇した、または発見した場合は、conduct@example.com からメンテナンスチームにご連絡ください。すべての通報は秘密裏に扱われます。

## 表示と出典

本規範は Contributor Covenant 2.1 を改変したものであり、CC BY 4.0 ライセンスに従います。
```
