# NOTICE規範

> このファイルが解決する問題：NOTICE ファイルに必ず含めるべき 7 つの部分と README との一致要件を定義し、サードパーティの声明を独立したファイルとし、情報を正確にすることを保証する。

## 1. 独立したファイルとする

NOTICE は独立したファイルとし、README と統合してはならず、README のリストで代替してもなりません。以下の部分を含めなければなりません：

1. **プロジェクト自身の声明**：プロジェクト名、著作権者、年、ライセンス、SPDX 識別子。
2. **サードパーティコンポーネントの一覧**：[オープンソースコンプライアンス規範](./オープンソースコンプライアンス規範.md) の依存関係リストのフィールドに従って項目ごとに列挙する。
3. **ライセンス原文の付録**：全文の添付を要するライセンスは、1 部ずつ原文を添付しなければならない。原文は英語のまま保持し、翻訳しない。
4. **変更の声明**：サードパーティコードの変更箇所と内容。
5. **素材とデータの出典の声明**。
6. **免責事項**：英語原文を保持し、中国語の対訳を付してよい。
7. **未確認事項**：ライセンスや著作権の帰属を確認できない項目は、「未確認」と明記する。

## 2. 一貫性の要件

NOTICE と README の第 6 章（技術スタックと依存関係リスト）、第 19 章（著作権とライセンス）、第 20 章（NOTICE コンプライアンス声明）のコンポーネントとライセンスの情報は完全に一致しなければならず、バージョン、ライセンス識別子、著作権者に差異が生じてはなりません。
