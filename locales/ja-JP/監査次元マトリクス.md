# 監査次元マトリクス

> このファイルが解決する問題：Phase 2 の並列監査における 14 の次元、それぞれのチェック要点、推奨エージェント、失敗レベルを定義し、割り当てと判定の根拠とします。

## 監査次元マトリクス

| # | 次元 | チェック要点（キーワード。詳細はサブエージェントが展開する） | 推奨エージェント | 失敗レベル |
|---|---|---|---|---|
| D1 | セキュリティとプライバシー | シークレットスキャン、`.env`、秘密鍵、内部ドメイン/IP、個人情報、ログの残留 | security-auditor | P0 |
| D2 | ライセンスと法務 | LICENSE の有無と種類、依存関係の license の互換性、NOTICE、第三者声明 | license-checker | P0 |
| D3 | リポジトリの衛生 | .gitignore の網羅性、成果物と依存ディレクトリ、.gitattributes、改行 LF、実行可能ビット、ファイル名の大文字小文字衝突 | repo-hygienist | P0/P1 |
| D4 | サイズとバイナリ | 50MB 超のファイル、画像の圧縮、LFS の設定、履歴の肥大化 | repo-hygienist | P1 |
| D5 | 再現可能なビルド | lockfile のコミット、エンジンのバージョン宣言、ビルドスクリプト、クリーンな環境でのビルド成功 | build-verifier | P0 |
| D6 | テストと静的解析 | 単体テストの成功、カバレッジ、lint、format、型チェック | ci-runner | P0/P1 |
| D7 | コミット履歴 | Conventional Commits、原子性、WIP がないこと、作者情報、機密を含む commit message がないこと | commit-reviewer | P1 |
| D8 | ブランチとリリース | main の保護、ブランチ命名、tag の SemVer、annotated tag、Release Notes | release-manager | P1 |
| D9 | 自動化 | CI ワークフローが実行可能、ステータスバッジ、dependabot、CODEOWNERS、issue/PR テンプレート | ci-runner | P1 |
| D10 | リポジトリのメタデータ | description（`国家语言 \| 英语` の二言語併記形式、両言語とも 120 文字以内）、topics（最大 20 個まで埋め、英語のみ、すべて小文字）、既定ブランチ、About リンク、social preview | metadata-agent | P1 |
| D11 | ドキュメントの完全性 | ドキュメントマトリクスの項目ごとの存在確認 | docs-orchestrator | P0/P1 |
| D12 | ドキュメントの品質 | 見出しの階層、コードブロックの言語指定、リンクの有効性、画像の alt、日中英間の空白、プレースホルダーがないこと | docs-orchestrator | P1/P2 |
| D13 | README のトップページ | 一言の位置づけ、インストール、クイックスタート、バッジ ≤4、スクリーンショット、ローカルの絶対パスがないこと | readme-writer | P1 |
| D14 | コミュニティガバナンス | CONTRIBUTING、CODE_OF_CONDUCT、SECURITY、Issue テンプレート、サポート窓口 | docs-orchestrator | P2 |

## レベルの意味

- **P0**：プッシュを阻害する。
- **P1**：プッシュ前に修正するか、必ず TODO として登録する。
- **P2**：改善を推奨する。
