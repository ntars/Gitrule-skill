# LICENSE規範

> 本檔案解決什麼問題：定義專案許可證的 SPDX 標註、LICENSE 全文要求、版權行位置與多許可證說明，以及未經確認不得寫入的規則。

## LICENSE 規則

1. 專案許可證須以 SPDX 識別符號在 README 中明確寫出，並提供對應 LICENSE 檔案。
2. LICENSE 檔案須為該許可證官方英文全文，不得刪改條款。
3. 版權行置於檔案頭部或 README 第 19 章，格式見 [README章節規範](./README章節規範.md)。
4. 採用雙許可證或多許可證時，須說明適用條件與選擇方式。
5. 許可證選擇未經使用者確認時，不得直接寫入文件，僅提供候選方案與差異說明。
