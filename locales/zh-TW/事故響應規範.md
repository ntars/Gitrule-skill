# 事故響應規範

> 本檔案解決什麼問題：定義事故報告模板、時間線記錄、溝通模板與覆盤欄位，保證故障可控、資訊同步、經驗可沉澱。

## 1. 規範條文

1. 事故分級：P0 核心功能不可用或資料損壞；P1 嚴重功能受損影響多數使用者；P2 區域性問題、影響有限。
2. 響應流程：發現 → 定級 → 止血 → 定位 → 修復 → 公告；止血優先於定位。
3. 每次 P0/P1 事故須覆盤，記錄時間線、根因、影響、處置與改進項。
4. 改進項須納入 [路線圖規範](./路線圖規範.md) 跟蹤閉環。
5. 覆盤聚焦系統改進，不追究個人責任。
6. 金鑰洩漏：立即輪換 → 清理歷史 → 公告，不得只做刪除提交（見 [安全與隱私規範](./安全與隱私規範.md)）。
7. 誤推大檔案：LFS 遷移或歷史重寫（見 [推送與釋出規範](./推送與釋出規範.md)）。

## 3. 溝通模板

```markdown
## 事故通報（首次）

- 時間：{{YYYY-MM-DD HH:MM}}
- 級別：{{P0 / P1 / P2}}
- 現象：{{用户可感知的现象，不写内部细节}}
- 影響：{{受影响范围}}
- 當前措施：{{正在做什么}}
- 下次更新時間：{{HH:MM}}

## 事故通報（恢復）

- 恢復時間：{{HH:MM}}
- 恢復確認：{{验证方式与结果}}
- 剩餘影響：{{无 / 描述}}
- 後續：{{复盘安排}}
```

## 4. 欄位定義

| 欄位 | 必填 | 型別 | 填寫要點 | 示例 |
| --- | --- | --- | --- | --- |
| 事故編號 | 是 | `INC-YYYYMMDD-NN` | 當日序號，連續不復用 | `INC-20261118-01` |
| 事故級別 | 是 | 列舉 | P0 / P1 / P2 | `P1` |
| 持續時長 | 是 | 時長 | 發現到恢復的分鐘數 | `42 分钟` |
| 指揮人 | 是 | 文字 | 唯一，負責決策與同步 | `李四` |
| 受影響使用者比例 | 是 | 文字 | 須給估算依據 | `约 8%，依据错误日志计数` |
| 時間線 | 是 | 表格 | 每節點含時間與來源 | 見模板 |
| 根本原因 | 是 | 文字 | 區分直接原因與根本原因 | `缺少回滚演练` |
| 改進項.驗證方式 | 是 | 文字 | 可判定，含閾值 | `下次演练回滚 <5 分钟` |
| 下次更新時間 | 是 | 時刻 | 處理中必填，禁止「隨時更新」 | `18:30` |

## 5. 填寫說明

1. **定級**：按影響範圍與嚴重程度定級；不確定時從高定級，後續調整並記錄原因。
2. **止血優先**：先恢復服務（回滾、降級、限流），再定位根因；定位不得延誤止血。
3. **時間線**：按發生時間順序記錄，來源須可查（告警 ID、命令、日誌片段）；禁止事後憑記憶補寫。
4. **根因**：直接原因是觸發事件，根本原因是體系缺陷；兩者均須填寫。
5. **溝通**：首次通報須給出下次更新時間；恢復通報須說明驗證方式與剩餘影響。
6. **改進項**：最多三條，納入路線圖跟蹤；無負責人的改進項不得進入報告。
7. **覆盤**：聚焦系統與流程改進，不評價個人；不追究責任與寫「某人不慎」類表述。
8. **特殊事故**：金鑰洩漏按 H12 處理；誤推大檔案按 LFS 遷移處理，均須單獨留痕。

常見錯誤：

| 錯誤寫法 | 問題 | 修正方式 |
| --- | --- | --- |
| 先定位根因再止血 | 延長故障時長 | 先回滾恢復 |
| 時間線事後補寫 | 事實不可信 | 處理中即時記錄 |
| 根因寫「某人不小心」 | 歸責個人、無改進價值 | 追問到流程或工具層面 |
| 通報寫「儘快修復」 | 無下次更新時間 | 給具體時刻 |
| 改進項無驗證方式 | 閉環不可判定 | 補閾值與檢查時機 |

## 6. 完整示例

```markdown
# 事故報告：INC-20261118-01

- 事故級別：P1
- 發現時間：2026-11-18 10:12
- 恢復時間：2026-11-18 10:54
- 持續時長：42 分鐘
- 指揮人：李四
- 當前狀態：已覆盤

## 影響範圍
| 維度 | 說明 |
| --- | --- |
| 受影響功能 | 規則檢查介面返回 5xx |
| 受影響使用者比例 | 約 8%，依據 5xx 日誌計數 |
| 資料影響 | 無 |
| 業務影響 | 42 分鐘內無法提交檢查任務 |

## 根因
- 直接原因：規則外掛載入路徑被新配置覆蓋，導致啟動失敗。
- 根本原因：配置變更未納入預釋出驗證。

## 改進項
| 編號 | 動作 | 負責人 | 截止日期 | 驗證方式 | 狀態 |
| --- | --- | --- | --- | --- | --- |
| A-01 | 將配置變更納入預釋出檢查清單 | 王五 | 2026-11-25 | 下輪 5 次變更均含檢查記錄 | 待開始 |
```
