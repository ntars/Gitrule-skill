# 多語言規範

> 本檔案解決什麼問題：定義按語言碼分目錄的檔案佈局、語言切換、翻譯一致性、程式碼一致性與單側修改同步規則。

## 1. 目錄佈局

1. 倉庫根目錄的 `README.md` 僅承擔專案首頁與語言導航，不承載具體規範正文。
2. 具體規範按語言碼平鋪在 `locales/<language-code>/` 目錄，例如 `locales/zh-CN/角色与职责.md`。
3. 語言碼採用 BCP 47 風格，例如 `zh-CN`、`en-US`、`ja-JP`、`ko-KR`；語言碼只出現在目錄名，不寫在檔名裡。
4. **檔名須使用該語言本身**：中文目錄用中文檔名（`角色与职责.md`），英文目錄用英文小寫連字元檔名（`roles-and-responsibilities.md`），其他語言同理，禁止在非中文目錄沿用中文檔名。
5. 各語言目錄的檔名互不要求逐字對應，但必須做到一一對映：同一篇規範在各語言目錄中內容職責相同，對映關係登記在清單檔案的 `paths` 欄位（見 [機器可讀後設資料規範](./機器可讀後設資料規範.md)）。
6. 簡體中文與英語為首批完成版本；其他語言在根 `README.md` 的語言表中標註「待補充」或「已完成」，未建立目錄的語言不得提供空連結。
7. 新增語言只新建對應語言目錄並逐篇翻譯，不改動已有語言檔案；僅在源語言修訂需要同步時更新其他已完成語言。

## 2. 語言切換

1. 每個語言目錄的 `README.md` 頂部須提供語言切換連結。
2. 連結使用相對於當前語言目錄的路徑，例如簡體中文目錄中的寫法：
   `[English](../en-US/README.md) | [简体中文](./README.md)`。
3. 連結文字使用目標語言的自稱，例如 `English`、`简体中文`、`日本語`，不寫 `CN`、`EN` 等縮寫。
4. 切換連結只指向已建立的語言目錄；未建立的語言目錄由根 `README.md` 的語言表統一標註，不在正文中留下斷鏈。

## 3. 翻譯一致性

1. 譯文須為完整翻譯，章節數量、章節順序、表格列數、程式碼塊數量與源語言一致；不得提供摘要式或未經校對的機翻式產出。
2. 程式碼塊內的命令、路徑、配置鍵名、佔位符名稱與引數值保持不變，僅註釋與說明文字翻譯。
3. 術語按 [資訊採集與模板](./資訊採集與模板.md) 的中英術語對照表統一；同一概念在所有語言中使用同一組對應關係。
4. 任何單側修改須同步全部已完成語言，並在更新日誌中記錄同步的語言碼與版本；未完成同步不得判定該次修訂完成。
5. 一致性校驗屬於門禁 G10，見 [質量門禁](./質量門禁.md)。

## 4. 法律文字

1. NOTICE 預設提供中文版本；涉及許可證原文、版權宣告與免責宣告的法律文字保留英文原文，不翻譯、不改寫。
2. 需要中英對照的法律文字須並列展示原文與譯文，並標明「譯文僅供參考，以原文為準」。
3. 法律文字的語種處理見 [NOTICE規範](./NOTICE規範.md) 與 [免責宣告](./免責宣告.md)。
