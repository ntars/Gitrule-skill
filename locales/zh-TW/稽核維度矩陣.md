# 稽核維度矩陣

> 本檔案解決什麼問題：定義 Phase 2 並行稽核的 14 個維度、各自檢查要點、建議 agent 與失敗等級，作為分派與判定的依據。

## 稽核維度矩陣

| # | 維度 | 檢查要點（關鍵詞，細節由子 agent 展開） | 建議 agent | 失敗等級 |
|---|---|---|---|---|
| D1 | 安全與隱私 | 金鑰掃描、`.env`、私鑰、內部域名/IP、個人資訊、日誌殘留 | security-auditor | P0 |
| D2 | 許可證與法律 | LICENSE 存在與型別、依賴 license 相容性、NOTICE、第三方宣告 | license-checker | P0 |
| D3 | 倉庫衛生 | .gitignore 覆蓋度、產物與依賴目錄、.gitattributes、行尾 LF、可執行位、檔名大小寫衝突 | repo-hygienist | P0/P1 |
| D4 | 體積與二進位制 | >50MB 檔案、圖片壓縮、LFS 配置、歷史膨脹 | repo-hygienist | P1 |
| D5 | 可復現構建 | lockfile 提交、引擎版本宣告、構建指令碼、乾淨環境可構建透過 | build-verifier | P0 |
| D6 | 測試與靜態檢查 | 單測透過、覆蓋率、lint、format、型別檢查 | ci-runner | P0/P1 |
| D7 | 提交歷史 | Conventional Commits、原子性、無 WIP、作者資訊、無敏感 commit message | commit-reviewer | P1 |
| D8 | 分支與釋出 | main 保護、分支命名、tag SemVer、annotated tag、Release Notes | release-manager | P1 |
| D9 | 自動化 | CI 工作流可跑、狀態徽章、dependabot、CODEOWNERS、issue/PR 模板 | ci-runner | P1 |
| D10 | 倉庫後設資料 | description（`國家語言 \| 英語` 雙語合併格式，兩種語言各 ≤120 字元）、topics（拉滿 20 個，僅英文，全小寫）、預設分支、About 連結、social preview | metadata-agent | P1 |
| D11 | 文件完整性 | 文件矩陣逐項存在性校驗 | docs-orchestrator | P0/P1 |
| D12 | 文件質量 | 標題層級、程式碼塊語言標註、連結有效性、圖片 alt、中英文空格、無佔位符 | docs-orchestrator | P1/P2 |
| D13 | README 首頁 | 一句話定位、安裝、快速開始、徽章 ≤4、截圖、無本地絕對路徑 | readme-writer | P1 |
| D14 | 社群治理 | CONTRIBUTING、CODE_OF_CONDUCT、SECURITY、Issue 模板、支援渠道 | docs-orchestrator | P2 |

## 等級含義

- **P0**：阻斷推送。
- **P1**：推送前應修或必須登記待辦。
- **P2**：建議最佳化。
