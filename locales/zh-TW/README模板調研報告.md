# README模板調研報告

> 本檔案解決什麼問題：記錄本次標準 README 模板的調研方法、樣本規模與量化發現，為 [README標準模板](./README標準模板.md) 及各專項規範提供資料依據，並明確方法的邊界與侷限。

## 1. 調研目標與方法

### 1.1 目標

調研 star 數排名靠前的頭部開源專案，歸納其 README 及相關文件的結構、章節組織、視覺呈現與徽章使用規律，形成可複用的通用規範與模板。

### 1.2 資料來源

- 倉庫後設資料：GitHub GraphQL Search API，按 star 降序，篩選 `is:public archived:false fork:false`。
- README 原文：GitHub REST Contents API（`readme` 端點），以 base64 或 raw 形式獲取後解析。
- 徽章引數：Shields.io 官方文件（Static Badge、Logos 頁面）與 badge-maker 格式說明。
- 中文社群實踐：phodal/github（《GitHub 漫遊指南》，11,362 star）的專案文件、提交資訊、推廣章節，用於補充機讀統計無法覆蓋的寫作原則與運營經驗。

### 1.3 採集方法

1. **後設資料**：GitHub Search API 單次查詢最多返回 1000 條。為擴大樣本，採用 star 區間分片——以二分法定位每 1000 名對應的 star 閾值，逐批下移累計 11 批，最終取得 10,995 個頭部倉庫的後設資料。
2. **README 抽樣**：在頭部 1000 倉庫內按主語言分層抽樣，覆蓋 Python、TypeScript、JavaScript、Rust、Go、C++ 等主要語言，抽樣 120 個倉庫，全部成功獲取 README 原文。
3. **統計口徑**：以倉庫為單位統計章節出現率與元素使用率；徽章樣式、logo 引數按 URL 中的出現次數統計。

### 1.4 方法侷限（須明確）

- GitHub Search API 對單次查詢設有 1000 條上限，本報告透過分片累計擴充套件規模，但分片邊界受 star 並列影響，樣本為近似頭部集合，非嚴格連續排名。
- README 抽樣規模為 120，結論反映趨勢與共性，不代表全部頭部專案的統計顯著分佈。
- 章節識別基於標題關鍵詞匹配，存在措辭差異導致的統計偏差。
- 徽章引數統計針對 URL 顯式出現的引數，動態徽章的預設引數未被計入。

## 2. 頭部倉庫分佈（後設資料）

### 2.1 樣本規模

- 單次查詢可穩定取得頭部 1000 倉庫，star 區間約 563,574 至 30,857。
- 經 11 批分片累計，擴充套件至 10,995 個頭部倉庫，star 下界 5,452。

### 2.2 語言分佈（基於頭部 1000）

| 語言 | 數量 | 佔比 |
| --- | --- | --- |
| Python | 223 | 22.3% |
| TypeScript | 178 | 17.8% |
| JavaScript | 112 | 11.2% |
| Rust | 80 | 8.0% |
| 無主語言 | 74 | 7.4% |
| Go | 68 | 6.8% |
| C++ | 55 | 5.5% |
| Java | 27 | 2.7% |

頭部專案以 Python、TypeScript、JavaScript 為主，三者合計超過 50%；Rust、Go 等系統語言佔比顯著。這決定了模板須覆蓋多語言的包管理安裝命令與多執行時徽章。

| 許可證 | 數量 | 佔比 |

MIT 佔據主導，是通用模板的預設推薦；同時須保留 Apache-2.0、GPL 等選項的 SPDX 標識佔位。

## 6. 歸納結論

1. 通用模板須以「定位 → 安裝 → 快速開始 → 文件 → 貢獻 → 許可證」為主幹。
2. 徽章預設 `flat-square` 或 `for-the-badge`，全篇統一，數量 4–6 枚。
3. 圖片與程式碼塊是高吸引力首頁的核心，須配 `alt` 與語言標註。
4. 專案型別決定章節取捨，見 [README分類適配指南](./README分類適配指南.md)。
5. 合規與社群治理（許可證、貢獻指南）是頭部專案共識，列為必填。

| 維度 | 分佈 |

| 語言 | Python 1,995、TypeScript 1,529、JavaScript 1,279、無主語言 888、Go 847、C++ 531、Java 528、Rust 507 |

README 深度統計樣本 120 個，全部獲取成功。分片採用近似 star 閾值，規模為頭部近似集合，非嚴格連續排名。
