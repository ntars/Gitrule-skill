# Agent呼叫與提示詞規範

> 本檔案解決什麼問題：定義 Agent 呼叫規範集時的分派契約與提示詞寫法，保證呼叫可驗證、不越權、不漂移。

## 1. 呼叫原則

1. 職責單一：一次呼叫只完成一件事，禁止「順便」做其他任務。
2. 讀寫分離：子 agent 只讀取與分析，寫檔案與 git 操作由主控統一執行（見 [子Agent分派契約](./子Agent分派契約.md)）。
3. 證據要求：結論須帶證據（路徑 + 行號 / 命令輸出），無證據視為無效。
4. 不通訊：子 agent 之間不直接通訊，全部經主控彙總。

## 2. 提示詞結構

呼叫提示詞須包含四要素：

```text
TASK:    <一句话任务>
INPUT:   <必要上下文，只给所需部分>
OUTPUT:  <结构化输出格式，表格或 JSON，禁止散文>
FAIL:    <无法完成时的返回约定，不得瞎编>
```

## 3. 提示詞寫法

1. 使用書面語與祈使句，資訊完整，不依賴上下文推測（見 [通用寫作規範](./通用寫作規範.md)）。
2. 明確輸出格式與失敗返回，避免模型自由發揮。
3. 涉及規範引用時給出檔案路徑（見 [機器可讀後設資料規範](./機器可讀後設資料規範.md)）。
4. 模板與佔位符統一格式（見 [資訊採集與模板](./資訊採集與模板.md)）。

## 4. 強制規則

1. 不得要求 Agent 編造檢查結果；不可檢查項標註 SKIP + 原因。
2. 不得把內部思考過程寫入交付物（見 [禁止事項](./禁止事項.md)）。
3. 安全相關內容按 [安全與隱私規範](./安全與隱私規範.md) 處理。
