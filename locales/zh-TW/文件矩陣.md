# 文件矩陣

> 本檔案解決什麼問題：定義每個交付文件的唯一職責、嚴禁放入的內容與拆分約束，確保一檔案一職責、禁止合併。

## 1. 檔案與職責

| 檔案 | 唯一職責 | 嚴禁放入 |
|---|---|---|
| `README.md` | 首頁：這是什麼、如何安裝、如何執行、詳情查閱位置 | 全量 API、貢獻流程、更新日誌 |
| `LICENSE` | 許可證全文 | 任何說明文字 |
| `CHANGELOG.md` | 面向使用者的版本變更 | 內部重構細節、開發計劃 |
| `CONTRIBUTING.md` | 外部貢獻者的流程與規範 | 專案功能說明 |
| `CODE_OF_CONDUCT.md` | 行為準則 | 技術內容 |
| `SECURITY.md` | 漏洞上報渠道與響應策略 | 已知漏洞列表 |
| `docs/api.md` | 完整 API 參考 | 教程 |
| `docs/architecture.md` | 架構與模組邊界 | 使用示例 |
| `docs/naming.md` | 命名規範 | 其他規範 |
| `docs/release.md` | 釋出流程與版本策略 | 變更記錄 |
| `.github/PULL_REQUEST_TEMPLATE.md` | PR 自查清單 | 專案介紹 |
| `.github/ISSUE_TEMPLATE/*.yml` | 結構化 issue 表單 | 自由文字 |
| `.github/workflows/*.yml` | CI/CD | 說明文件 |

> 說明：`docs/naming.md` 的規範正文見 [專案命名規範](./專案命名規範.md)；`docs/release.md` 的規範正文見 [推送與釋出規範](./推送與釋出規範.md)。

## 2. 約束

- 單檔案超過 300 行必須拆分到 `docs/`，README 只留摘要 + 連結。
- 檔名固定大寫，路徑固定，不得自創目錄層級。
- 每個文件開頭一句話說明「本檔案解決什麼問題」，結尾給出相關檔案交叉連結。
