# 質量度量指標規範

> 本檔案解決什麼問題：定義可跟蹤的質量指標及其口徑，避免用無依據的數字評價專案質量。

## 1. 指標原則

1. 指標須可測量、可復現，寫明採集方式與統計口徑。
2. 指標用於改進，不用於簡單排名或製造壓力。
3. 每個指標須標註目標值與當前值，並定期回顧。

## 2. 建議指標

| 類別 | 指標 | 口徑說明 |
| --- | --- | --- |
| 測試 | 測試覆蓋率 | 被測程式碼行佔比，註明統計工具 |
| 測試 | 測試透過率 | 透過用例數 / 總用例數 |
| 構建 | 構建成功率 | 成功構建次數 / 總構建次數 |
| 缺陷 | 缺陷密度 | 單位規模程式碼發現的缺陷數 |
| 缺陷 | 平均修復時長 | 從發現到修復完成的平均耗時 |
| 效能 | 響應時間 | 明確場景與分位值（如 P95） |
| 依賴 | 高危漏洞數 | 未修復的高危依賴漏洞數量 |

## 3. 強制規則

1. 效能指標須註明測試環境與方法，禁止無條件的數字（對應 [通用寫作規範](./通用寫作規範.md)）。
2. 指標資料採集須自動化，減少人工統計偏差。
3. 指標異常須有跟進記錄，納入 [路線圖規範](./路線圖規範.md) 或問題跟蹤。
