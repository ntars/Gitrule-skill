## 閱讀路徑

- **確定選用範圍**：規範選用指南 → 生命週期對映表 → 對應階段的規範檔案。
- **貫穿生命週期**：生命週期對映表 → 專案立項與需求規範 → 需求追蹤矩陣規範 → 架構設計文件規範 → 測試規範 → 部署與回滾規範 → 可觀測性規範 → 迭代回顧規範。
- **快速推送**：硬規則 → 質量門禁 → 推送與釋出規範 → 稽核報告格式。
- **從零生成文件**：角色與職責 → 執行流程 → 資訊採集與模板 → 文件矩陣 → README章節規範 → 開源合規規範 → 質量門禁。
- **編寫 README**：README模板調研報告 → README視覺排版規範 → 徽章規範 → README分類適配指南 → README標準模板。
- **完整稽核**：稽核維度矩陣 → 子Agent分派契約 → 硬規則 → 質量門禁 → 稽核報告格式。
- **程式化接入**：機器可讀後設資料規範 → Skill編寫規範 / MCP工具規範 / Agent呼叫與提示詞規範。
- **風險與責任邊界**：免責宣告 → 免責宣告模板 → SECURITY模板 → 安全與隱私規範 → 開源合規規範。
- **生成社群治理檔案**：貢獻指南模板 → 行為準則模板 → SECURITY模板 → 免責宣告模板。

## 用語約定

- **必須 / 不得**：強制要求。
- **應當 / 不應**：推薦或禁止，偏離時須說明理由。
- **可以**：可選。
- **P0 / P1 / P2**：P0 阻斷推送；P1 推送前應修或必須登記待辦；P2 建議最佳化。
