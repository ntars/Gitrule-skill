# 機器可讀後設資料規範

> 本檔案解決什麼問題：定義供專家、Skill、MCP、命令列等程式化消費的後設資料清單結構，保證機器取用穩定、可發現。

## 1. 設計目標

1. 穩定標識：每份文件有唯一、不變的標識，供程式引用。
2. 語言無關：標識不隨語言變化，語言僅體現在路徑上。
3. 可發現：清單列出全部文件的型別、路徑、語言與摘要。

## 2. 清單結構

機器清單（manifest）須包含：

| 欄位 | 要求 |
| --- | --- |
| id | 穩定唯一標識，小寫 kebab-case，不含語言與版本 |
| title | 文件標題 |
| summary | 一句話說明解決什麼問題 |
| domain | 所屬域（七大域之一） |
| paths | 語言碼到相對路徑的對映，如 `zh-CN`: `./locales/zh-CN/角色与职责.md` |
| version | 規範集版本 |

## 3. 強制規則

1. 新增語言只在 `paths` 中追加對映，不改動 `id` 與其他語言路徑。
2. 文件改名須保留 `id` 不變，僅更新 `paths`。
3. 標識與路徑須與實際檔案一致，CI 校驗清單有效性。
4. 本規範提供可複製清單示例；目標專案應按第 2 節欄位建立實際清單例項，並確保 `paths` 與磁碟檔案一致。

## 4. 清單示例（可複製）

以下示例列出三個文件條目。實際清單須覆蓋目標語言目錄的全部規範；`id` 不隨語言變化，`paths` 按語言碼追加對映。

```json
{
  "version": "1.0.0",
  "entries": [
    {
      "id": "role-and-responsibility",
      "title": "角色与职责",
      "summary": "定义执行者身份、职责边界、触发条件、适用范围与硬性约束",
      "domain": "总纲与治理",
      "paths": {
        "zh-CN": "./locales/zh-CN/角色与职责.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "readme-standard-template",
      "title": "README标准模板",
      "summary": "提供可直接套用的通用 README 模板与占位符对照表",
      "domain": "命名与文档",
      "paths": {
        "zh-CN": "./locales/zh-CN/README标准模板.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "machine-readable-metadata",
      "title": "机器可读元数据规范",
      "summary": "定义供专家、Skill、MCP、命令行消费的元数据清单结构",
      "domain": "AI 与机器适配",
      "paths": {
        "zh-CN": "./locales/zh-CN/机器可读元数据规范.md"
      },
      "version": "1.0.0"
    }
  ]
}
```

新增語言時，只在對應條目的 `paths` 中追加對映，例如增加 `"en-US": "./locales/en-US/role-and-responsibility.md"`；不得修改 `id`。
