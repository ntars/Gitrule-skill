# Skill編寫規範

> 本檔案解決什麼問題：定義將規範集封裝為 Skill 時的結構、觸發條件與漸進載入方式，保證 Skill 可發現、可維護、不重複內容。

## 1. 目錄結構

Skill 採用「入口 + 按需資源」結構：

```text
skill-name/
├── SKILL.md          必需：元数据 + 核心流程
├── references/       规范正文，按需加载
└── assets/           模板与素材（可选）
```

## 2. SKILL.md 要求

1. 後設資料含 `name` 與 `description`，描述須寫明「做什麼 + 何時用」，以便觸發。
2. 正文只保留常駐的核心規則與流程，詳細查表類內容放入 `references/`。
3. 採用祈使/不定式寫法，避免第二人稱。
4. 引用資源時給出明確路徑與「何時讀取」的條件。

## 3. 強制規則

1. 規範正文只在一處維護：Skill 引用本規範集檔案，不復制全文，避免雙份漂移。
2. 一個 Skill 只做一件事，禁止把多個職責塞進同一 Skill。
3. 觸發條件寫明具體短語，避免過寬觸發。
4. 版本隨規範集版本同步更新。
