# 行為準則模板

> 本檔案解決什麼問題：提供一份可直接複製的行為準則模板，供專案生成 CODE_OF_CONDUCT.md，明確參與承諾、期望行為、不可接受行為、執行職責與舉報渠道；配套的填寫說明覆蓋改編來源與版本宣告。

## 1. 使用說明

1. 複製第 3 節「模板正文」全部內容，新建為專案根目錄的 `CODE_OF_CONDUCT.md`。
2. 按第 4 節替換佔位符，舉報渠道必須為真實可達地址。
3. 若採用或改編自有版本的行為準則，須在第 5 節按來源要求宣告版本與許可證，依據見 [行為準則規範](./行為準則規範.md) 第 1 節第 8 項。
4. 在 [貢獻指南模板](./貢獻指南模板.md) 與 README 的貢獻章節中連結本檔案，保持雙向可達。

## 2. 定製原則

- **技術無關**：準則不含技術內容，僅規定參與行為規範，邊界見 [文件矩陣](./文件矩陣.md)。
- **可執行**：分級處置須寫明觸發條件與措施，禁止只寫原則不寫後果。
- **可達性**：舉報渠道必須真實有效，禁止留示例地址。
- **合規來源**：改編第三方準則須保留其署名與許可要求，見 [開源合規規範](./開源合規規範.md)。

## 3. 模板正文

```markdown
# 行為準則

## 我們的承諾

我們作為 {{项目名称}} 的參與者、貢獻者與維護者，承諾共同營造開放、友善、無騷擾的參與環境，不論年齡、體型、殘障狀況、種族、性別認同與表達、經驗水平、教育程度、社會經濟地位、國籍、外貌或性取向。

## 適用範圍

本準則適用於專案空間、議題、拉取請求、程式碼評審、社交渠道，以及個人以專案代表身份出現的公開場合。

## 期望行為

- 尊重不同觀點與經驗，善意溝通。
- 接受建設性反饋，聚焦問題本身而非個人。
- 關注社群整體利益，避免損害專案與其參與者。
- 對新人保持耐心，提供可操作的改進建議。

## 不可接受行為

- 人身攻擊、侮辱性或貶損性言論。
- 基於任何受保護特徵的歧視性言論與騷擾。
- 公開或私下騷擾、跟蹤、未經同意的持續聯絡。
- 未經授權釋出他人隱私資訊。
- 其他在專業環境中被合理認定為不當的行為。

## 執行職責

專案維護者負責澄清本準則的適用、裁定違規行為，並有權刪除、編輯或拒絕不符合本準則的內容。維護者須以一致、公正的方式行使職責，並對涉及自身的爭議主動迴避。

## 處置措施

違規行為按情節輕重分級處置：

| 等級 | 適用情形 | 措施 |
| --- | --- | --- |
| 一級 | 無意冒犯、輕微失當 | 私下提醒與說明 |
| 二級 | 重複發生或明確違規 | 公開警告、限期改正 |
| 三級 | 嚴重騷擾、惡意攻擊 | 臨時封禁參與許可權 |
| 四級 | 持續或不可挽回的嚴重行為 | 永久封禁並保留記錄 |

## 舉報渠道

如遭遇或發現違反本準則的行為，請透過 {{真实可达的举报邮箱或渠道}} 聯絡維護團隊。所有舉報將被保密處理，維護者不得向被舉報人披露舉報人身份，除非舉報人明確同意。

## 署名與來源

{{准则来源声明}}
```

## 4. 佔位符對照表與欄位定義

| 佔位符 | 必填 | 欄位定義 | 填寫示例 |
| --- | --- | --- | --- |
| `{{项目名称}}` | 是 | 專案對外名稱，與 README 首行一致 | `FooBar` |
| `{{真实可达的举报邮箱或渠道}}` | 是 | 可直接聯絡到維護者的真實地址 | `conduct@example.com` |
| `{{准则来源声明}}` | 是 | 原創寫原創；改編須寫來源名稱、版本與許可證 | `改编自 Contributor Covenant 2.1（CC BY 4.0）` |

## 5. 填寫說明與場景變體

| 場景 | 調整要點 |
| --- | --- |
| 個人專案 | 維護者寫本人；舉報渠道用長期持有的郵箱 |
| 企業專案 | 明確法務或社群團隊為執行主體；處置措施須與內部制度一致 |
| 採用知名準則 | 保留其完整原文與版本，僅補充舉報渠道與署名 |
| 多語言專案 | 各語言版本條款逐一對應；以英文或中文版為權威版本並註明 |

常見錯誤對照：

| 錯誤寫法 | 後果 | 正確寫法 |
| --- | --- | --- |
| 只寫「歡迎友善交流」 | 無執行依據，爭議時無法裁定 | 列明期望行為、不可接受行為與分級處置 |
| 舉報渠道留佔位郵箱 | 不可達，舉報機制失效 | 填寫真實且長期有效的地址 |
| 改編準則未署名 | 違反來源許可要求 | 宣告來源、版本與許可證 |

## 6. 完整示例

以下為改編場景的節選，僅作格式參考。

```markdown
## 舉報渠道

如遭遇或發現違反本準則的行為，請透過 conduct@example.com 聯絡維護團隊。所有舉報將被保密處理。

## 署名與來源

本準則改編自 Contributor Covenant 2.1，遵循 CC BY 4.0 許可。
```
