# README標準模板

> 本檔案解決什麼問題：提供一份可直接複製、按佔位符替換即可套用的通用 README 模板，覆蓋專案完整生命週期的首頁呈現，附佔位符對照表、可選章節說明與交付自檢清單，使任何開發者均可據自身專案快速定製。

## 1. 使用說明

1. 複製第 3 節「模板正文」全部內容，新建為專案根目錄的 `README.md`。
2. 按第 4 節佔位符對照表逐個替換 `{{...}}`；未使用項連同所在整行或整節刪除。
3. 第 3 節各小節對應 [README章節規範](./README章節規範.md) 的 20 章，按由內到外的生命週期順序排列；刪除某章時須同步刪除首屏導航中對應連結。
4. 依據 [徽章規範](./徽章規範.md) 統一徽章樣式、顏色與數量；依據 [README視覺排版規範](./README視覺排版規範.md) 檢查截圖、表格與程式碼塊擺放。
5. 依據 [README分類適配指南](./README分類適配指南.md) 按專案型別取捨章節。
6. 提交前執行第 6 節自檢清單，確認無殘留佔位符。

## 2. 定製原則

- **必填項**：專案名稱、倉庫描述、一句話定位、安裝、快速開始、許可證。
- **順序固定**：章節順序與 [README章節規範](./README章節規範.md) 一致，中英文版本逐章對應。
- **證據優先**：核心特性、效能表現、工程取捨須給出可複核的證據，禁止定性誇讚。
- **透明披露**：不適用場景、侷限、已知問題、未實現功能須顯式列出，不得隱瞞。
- **非承諾**：路線圖示註「非承諾」，不寫具體交付日期。
- **真實性**：所有命令、示例、連結、徽章須實際可用；聯絡方式與上報渠道須真實可達。

## 3. 模板正文

本節按專案生命週期「由內到外」組織，共 20 節，與 [README章節規範](./README章節規範.md) 的 20 章一一對應。每節程式碼塊內的文字即為可複製正文。

章節與生命週期階段的對映如下，便於按需定位：

| 生命週期階段 | 對應小節 | 呈現重點 |
| --- | --- | --- |
| 專案啟動 | 3.1–3.2 | 定位、背景、適用場景與侷限 |
| 需求分析 | 3.2–3.3 | 功能邊界、適用場景、不適用場景 |
| 架構設計 | 3.5–3.6、3.11 | 工程取捨、技術棧、目錄結構 |
| 開發實現 | 3.3–3.4、3.9–3.10 | 功能、特性、配置、API |
| 測試驗證 | 3.8、3.12 | 快速開始示例、效能表現證據 |
| 部署上線 | 3.7、3.14 | 安裝部署、相容性矩陣 |
| 運維監控 | 3.13、3.15 | 安全隱私、已知問題與限制 |
| 迭代維護 | 3.15–3.17 | 未實現功能、更新日誌、後續路線圖 |

說明：README 是專案首頁，各階段的過程文件（需求、設計、測試、部署、運維的完整記錄）由對應規範承載，見 [文件矩陣](./文件矩陣.md)；本章節僅呈現對使用者可見的結論。

## 6. 交付前自檢清單

- [ ] 無殘留 `{{...}}` 佔位符。
- [ ] 首屏含倉庫描述【中文 | 英文】與話題標籤，兩者與倉庫後設資料一致。
- [ ] 倉庫描述中文與英文各不超過 120 字元。
- [ ] 話題標籤拉滿 20 個，全小寫英文，用 `-` 連線。
- [ ] 一句話定位含品類詞，中文不超過 60 字、英文不超過 25 詞。
- [ ] 核心特性每條含五段結構且有可複核證據。
