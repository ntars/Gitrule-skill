# MCP工具規範

> 本檔案解決什麼問題：定義將規範集透過模型上下文協議（MCP）暴露為工具時的介面設計與描述規則，保證工具可被模型正確發現與呼叫。

## 1. 工具設計原則

1. 單一職責：一個工具做一件事，避免大而全的介面。
2. 描述清晰：工具描述說明用途與適用場景，便於模型判斷何時呼叫。
3. 引數明確：每個引數有型別、是否必填、取值範圍與說明。
4. 輸出結構化：返回結構化資料，避免長篇散文。

## 2. 必含欄位

| 欄位 | 要求 |
| --- | --- |
| name | 唯一標識，小寫 kebab-case |
| description | 用途與觸發條件，具體可判斷 |
| inputSchema | 引數型別、必填項、約束 |
| 返回值 | 結構化格式與欄位說明 |
| 錯誤 | 失敗時的返回格式，不得編造結果 |

## 3. 規範集相關工具

1. 文件檢索類：按語言碼 + 標識返回規範內容（標識見 [機器可讀後設資料規範](./機器可讀後設資料規範.md)）。
2. 清單類：返回可用文件列表及其語言對映。
3. 校驗類：檢查文件矩陣完整性（見 [文件矩陣](./文件矩陣.md)）與門禁狀態（見 [質量門禁](./質量門禁.md)）。

## 4. 強制規則

1. 工具不得返回無法檢查的結果為 PASS，須標註 SKIP 與原因（見 [禁止事項](./禁止事項.md)）。
2. 輸出須可被程式解析，不含內部思考過程。
3. 安全相關內容不得透過工具洩露（見 [安全與隱私規範](./安全與隱私規範.md)）。
