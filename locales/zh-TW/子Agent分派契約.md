# 子Agent分派契約

> 本檔案解決什麼問題：定義向子 agent 分派任務時必須寫清的四要素與協作約束，確保結論結構化、可驗證、無規則漂移。

## 1. 分派四要素

每次分派必須寫清四要素：

```text
TASK:    <一句话任务>
INPUT:   <需要的文件/上下文，只给必要部分>
OUTPUT:  <结构化格式，表格或 JSON，禁止散文>
FAIL:    <做不了时返回什么，而不是瞎编>
```

## 2. 約束

- 一個子 agent 一次只幹一件事，禁止「順便把 README 也寫了」。
- 子 agent 只能讀、只能出方案；**寫檔案與 git 操作統一由主控執行**。
- 子 agent 結論必須帶證據（檔案路徑 + 行號 / 命令輸出），無證據的結論視為無效。
- 子 agent 之間不直接通訊，全部經主控彙總，避免規則漂移。
