# LICENSE 규범

> 이 파일이 해결하는 문제：프로젝트 라이선스의 SPDX 표기, LICENSE 전문 요구사항, 저작권 행 위치와 다중 라이선스 설명, 그리고 확인 없이 기재해서는 안 되는 규칙을 정의한다.

## LICENSE 규칙

1. 프로젝트 라이선스는 SPDX 식별자로 README에 명확히 기재하고, 해당 LICENSE 파일을 제공해야 한다.
2. LICENSE 파일은 해당 라이선스의 공식 영문 전문이어야 하며, 조항을 삭제하거나 변경해서는 안 된다.
3. 저작권 행은 파일 머리말 또는 README 제19장에 두며, 형식은 [README 섹션 규범](./README-섹션-규범.md)을 참고한다.
4. 듀얼 라이선스 또는 다중 라이선스를 채택할 때는 적용 조건과 선택 방식을 설명해야 한다.
5. 라이선스 선택이 사용자 확인을 거치지 않은 경우 문서에 직접 기재해서는 안 되며, 후보 방안과 차이 설명만 제공한다.

## 관련 파일

- LICENSE가 없으면 푸시가 차단되며, 하드 룰 H2에 속한다. [하드 룰](./하드-룰.md)을 참고한다
- 의존성 라이선스 호환성 판단은 [오픈소스 컴플라이언스 규범](./오픈소스-컴플라이언스-규범.md)을 참고한다
- 제3자 고지는 독립 파일로, [NOTICE 규범](./NOTICE-규범.md)을 참고한다
- 라이선스 정확성은 품질 게이트 G7/G8에 속하며, [품질 게이트](./품질-게이트.md)를 참고한다
