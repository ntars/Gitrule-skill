# 서브 에이전트 위임 계약

> 이 파일이 해결하는 문제：서브 에이전트에 작업을 위임할 때 반드시 명시해야 하는 4요소와 협업 제약을 정의하여, 결론이 구조화되고 검증 가능하며 규칙이 흔들리지 않도록 보장한다.

## 1. 위임 4요소

매번 위임할 때 다음 4요소를 반드시 명시한다:

```text
TASK:    <一句话任务>
INPUT:   <需要的文件/上下文，只给必要部分>
OUTPUT:  <结构化格式，表格或 JSON，禁止散文>
FAIL:    <做不了时返回什么，而不是瞎编>
```

## 2. 제약

- 하나의 서브 에이전트는 한 번에 한 가지 일만 하며, 「겸사겸사 README도 작성」하는 것은 금지한다.
- 서브 에이전트는 읽기와 방안 제시만 할 수 있으며, **파일 쓰기와 git 작업은 일괄적으로 주 컨트롤러가 수행한다**.
- 서브 에이전트의 결론에는 반드시 근거(파일 경로 + 행 번호 / 명령 출력)가 있어야 하며, 근거가 없는 결론은 무효로 간주한다.
- 서브 에이전트 간에는 직접 통신하지 않으며, 모두 주 컨트롤러를 거쳐 종합하여 규칙이 흔들리는 것을 방지한다.
