# 용어집

> 이 파일이 해결하는 문제：프로젝트 전체에서 사용하는 전문 용어와 약어를 집중 정의하여, 중국어·영어 버전의 용어가 일대일로 대응되고 문서 전체의 표현이 일관되도록 보장합니다.

## 1. 유지 관리 규칙

1. 용어가 처음 등장할 때는 정의를 제시해야 하며, 형식은 「중국어 용어（English Term，약어）」입니다.
2. 동일한 개념은 문서 전체에서 하나의 표현만 사용합니다. 중국어·영어 버전의 용어는 일대일로 대응하며 본 표를 공유합니다.
3. 새 용어는 반드시 본 표에 동기화하여 기록하고, 영어 버전의 해당 위치에도 동기화합니다.
4. 약어가 처음 등장할 때는 전체 이름을 풀어 써야 하며, 이후에는 약어를 바로 사용할 수 있습니다.

## 2. 용어 대조표

| 중국어 | English | 약어 | 설명 |
| --- | --- | --- | --- |
| 软件物料清单 | Software Bill of Materials | SBOM | 프로젝트 의존성과 컴포넌트의 전체 목록입니다 |
| 语义化版本 | Semantic Versioning | SemVer | 버전 번호 형식 `MAJOR.MINOR.PATCH`입니다 |
| 架构决策记录 | Architecture Decision Record | ADR | 중요한 아키텍처 결정과 그 배경 및 결과를 기록합니다 |
| 行为准则 | Code of Conduct | CoC | 커뮤니티 참여자의 행동 규범입니다 |
| 持续集成 / 持续交付 | Continuous Integration / Continuous Delivery | CI/CD | 자동화된 빌드, 테스트 및 전달 프로세스입니다 |
| 软件许可证标识符 | Software Package Data Exchange | SPDX | 라이선스의 표준 식별자 체계입니다 |
| 最小可行产品 | Minimum Viable Product | MVP | 핵심 가설을 검증할 수 있는 최소 버전입니다 |
| 自然语言处理器 | Natural Language Processing | NLP | 텍스트 처리 관련 기술입니다 |
| 大模型 | Large Language Model | LLM | 대규모 사전 학습 언어 모델입니다 |
| 模型上下文协议 | Model Context Protocol | MCP | 모델과 외부 도구를 연결하는 프로토콜입니다 |
| 待补充 | To Be Determined | TBD | 정보가 아직 확인되지 않았음을 나타내는 자리표시자입니다 |

> 표의 항목은 범용 예시이며, 사용 전에 프로젝트의 실제 용어에 따라 추가·삭제해야 합니다.
