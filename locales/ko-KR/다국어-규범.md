# 다국어 규범

> 이 파일이 해결하는 문제：언어 코드별 디렉터리 파일 레이아웃, 언어 전환, 번역 일관성, 코드 일관성 및 단측 수정 동기화 규칙을 정의합니다.

## 1. 디렉터리 레이아웃

1. 리포지터리 루트의 `README.md`는 프로젝트 첫 화면과 언어 내비게이션만 담당하며, 구체적인 규범 본문은 담지 않습니다.
2. 구체적인 규범은 언어 코드별로 `locales/<language-code>/` 디렉터리에 평면 배치합니다. 예: `locales/zh-CN/角色与职责.md`.
3. 언어 코드는 BCP 47 스타일을 사용합니다. 예: `zh-CN`, `en-US`, `ja-JP`, `ko-KR`. 언어 코드는 디렉터리 이름에만 나타나며 파일 이름에는 쓰지 않습니다.
4. **파일 이름은 해당 언어 자체를 사용해야 합니다**：중국어 디렉터리는 중국어 파일 이름(`角色与职责.md`), 영어 디렉터리는 소문자 하이픈 영어 파일 이름(`roles-and-responsibilities.md`)을 사용하며, 다른 언어도 마찬가지입니다. 비중국어 디렉터리에서 중국어 파일 이름을 그대로 쓰는 것은 금지됩니다.
5. 각 언어 디렉터리의 파일 이름이 글자 단위로 대응할 필요는 없지만, 반드시 일대일 매핑이어야 합니다. 동일한 규범은 각 언어 디렉터리에서 내용 책임이 같으며, 매핑 관계는 목록 파일의 `paths` 필드에 등록합니다([기계 판독 메타데이터 규범](./기계-판독-메타데이터-규범.md) 참조).
6. 중국어 간체와 영어가 첫 번째 완료 버전입니다. 다른 언어는 루트 `README.md`의 언어 표에 「미정」 또는 「완료」로 표시하며, 디렉터리가 없는 언어에는 빈 링크를 제공해서는 안 됩니다.
7. 새 언어를 추가할 때는 해당 언어 디렉터리를 새로 만들고 편집별로 번역만 하며, 기존 언어 파일은 수정하지 않습니다. 소스 언어 개정을 동기화해야 할 때만 다른 완료 언어를 업데이트합니다.

## 2. 언어 전환

1. 각 언어 디렉터리의 `README.md` 상단에는 언어 전환 링크를 제공해야 합니다.
2. 링크는 현재 언어 디렉터리 기준 상대 경로를 사용합니다. 예를 들어 중국어 간체 디렉터리의 표기는 다음과 같습니다.
   `[English](../en-US/README.md) | [简体中文](./README.md)`.
3. 링크 텍스트는 대상 언어의 자기 명칭을 사용합니다. 예: `English`, `简体中文`, `日本語`. `CN`, `EN` 같은 약어는 쓰지 않습니다.
4. 전환 링크는 이미 만들어진 언어 디렉터리만 가리킵니다. 만들어지지 않은 언어 디렉터리는 루트 `README.md`의 언어 표에서 일괄 표시하며, 본문에 끊어진 링크를 남기지 않습니다.

## 3. 번역 일관성

1. 번역문은 완전한 번역이어야 하며, 섹션 수, 섹션 순서, 표 열 수, 코드 블록 수가 소스 언어와 일치해야 합니다. 요약식 또는 교정되지 않은 기계 번역식 산출물을 제공해서는 안 됩니다.
2. 코드 블록 내부의 명령, 경로, 설정 키 이름, 자리표시자 이름 및 매개변수 값은 그대로 유지하며, 주석과 설명 텍스트만 번역합니다.
3. 용어는 [정보 수집 및 템플릿](./정보-수집-및-템플릿.md)의 중영 용어 대조표에 따라 통일합니다. 동일한 개념은 모든 언어에서 동일한 대응 관계를 사용합니다.
4. 모든 단측 수정은 전체 완료 언어에 동기화해야 하며, 변경 이력에 동기화한 언어 코드와 버전을 기록합니다. 동기화가 완료되지 않으면 해당 개정을 완료로 판정해서는 안 됩니다.
5. 일관성 검사는 게이트 G10에 속하며, [품질 게이트](./품질-게이트.md)를 참조하십시오.

## 4. 법률 텍스트

1. NOTICE는 기본적으로 중국어 버전을 제공합니다. 라이선스 원문, 저작권 표기 및 면책 조항과 관련된 법률 텍스트는 영어 원문을 유지하며, 번역하거나 개작하지 않습니다.
2. 중영 대조가 필요한 법률 텍스트는 원문과 번역문을 나란히 표시하고, 「번역문은 참고용이며 원문이 우선합니다」를 명시해야 합니다.
3. 법률 텍스트의 언어 처리 방식은 [NOTICE 규범](./NOTICE-규범.md)과 [면책 조항](./면책-조항.md)을 참조하십시오.
