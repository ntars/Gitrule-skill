# 감사 차원 매트릭스

> 이 파일이 해결하는 문제：Phase 2 병렬 감사의 14개 차원, 각 차원의 점검 요점, 권장 agent 및 실패 등급을 정의하여 위임과 판정의 근거로 삼습니다.

## 감사 차원 매트릭스

| # | 차원 | 점검 요점(키워드, 세부 사항은 서브 agent 가 전개) | 권장 agent | 실패 등급 |
|---|---|---|---|---|
| D1 | 보안 및 개인정보 | 시크릿 스캔, `.env`, 개인 키, 내부 도메인/IP, 개인정보, 로그 잔여물 | security-auditor | P0 |
| D2 | 라이선스 및 법률 | LICENSE 존재와 유형, 의존성 license 호환성, NOTICE, 제3자 고지 | license-checker | P0 |
| D3 | 리포지터리 위생 | .gitignore 포괄도, 산출물과 의존성 디렉터리, .gitattributes, 줄바꿈 LF, 실행 권한 비트, 파일명 대소문자 충돌 | repo-hygienist | P0/P1 |
| D4 | 용량과 바이너리 | >50MB 파일, 이미지 압축, LFS 설정, 이력 비대화 | repo-hygienist | P1 |
| D5 | 재현 가능한 빌드 | lockfile 커밋, 엔진 버전 선언, 빌드 스크립트, 깨끗한 환경에서 빌드 통과 | build-verifier | P0 |
| D6 | 테스트와 정적 분석 | 단위 테스트 통과, 커버리지, lint, format, 타입 검사 | ci-runner | P0/P1 |
| D7 | 커밋 이력 | Conventional Commits, 원자성, WIP 없음, 작성자 정보, 민감한 commit message 없음 | commit-reviewer | P1 |
| D8 | 브랜치와 릴리스 | main 보호, 브랜치 명명, tag SemVer, annotated tag, Release Notes | release-manager | P1 |
| D9 | 자동화 | CI 워크플로 실행 가능, 상태 배지, dependabot, CODEOWNERS, issue/PR 템플릿 | ci-runner | P1 |
| D10 | 리포지터리 메타데이터 | description(`국가 언어 \| 영어` 이중 언어 병합 형식, 두 언어 각각 ≤120자), topics(20개를 모두 채우고 영어만, 전부 소문자), 기본 브랜치, About 링크, social preview | metadata-agent | P1 |
| D11 | 문서 완전성 | 문서 매트릭스 항목별 존재 여부 검증 | docs-orchestrator | P0/P1 |
| D12 | 문서 품질 | 제목 계층, 코드 블록 언어 표기, 링크 유효성, 이미지 alt, 중영문 공백, 자리표시자 없음 | docs-orchestrator | P1/P2 |
| D13 | README 홈페이지 | 한 문장 포지셔닝, 설치, 빠른 시작, 배지 ≤4, 스크린샷, 로컬 절대 경로 없음 | readme-writer | P1 |
| D14 | 커뮤니티 거버넌스 | CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, Issue 템플릿, 지원 채널 | docs-orchestrator | P2 |

## 등급 의미

- **P0**: 푸시를 차단합니다.
- **P1**: 푸시 전에 수정해야 하거나 반드시 할 일로 등록해야 합니다.
- **P2**: 개선을 권장합니다.

## 위임과 집계

- 각 차원의 위임 방식은 [서브 에이전트 위임 계약](./서브-에이전트-위임-계약.md)을 참조합니다.
- 판정 결과는 [감사 보고서 형식](./감사-보고서-형식.md)의 문제 목록에 집계하며, 각 항목에는 근거가 있어야 합니다.
- D11/D12 의 검증 근거는 [문서 매트릭스](./문서-매트릭스.md)와 [품질 게이트](./품질-게이트.md)를 참조합니다.

## 관련 파일

- 수행 시점은 [실행 프로세스](./실행-프로세스.md)의 Phase 2 참조
- 게이트 통과 조건은 [품질 게이트](./품질-게이트.md) 참조
