# 通用写作规范

> 本文件解决什么问题：定义所有交付文档的语体、准确性、术语一致性、格式细则与禁止内容，保证表述精确、无歧义、可复现。

## 1. 语体

1. 使用书面语，采用陈述句与祈使句。
2. 不得使用口语化表达，例如「咱们」「超简单」「搞定」「贼快」「一键起飞」。
3. 不得使用感叹号、省略号、网络缩略语、表情符号。
4. 不得使用反问句、设问句作为章节开头。

## 2. 准确性

1. 每个句子须表达完整语义，不得依赖上下文推测。
2. 不得使用「它」「这个」「相关」「一些」「若干」等模糊指代；确需指代时使用完整名词。
3. 时间、版本号、路径、命令、函数名、配置键名须精确，且与项目实际情况一致。
4. 命令须可直接执行，包含必要的当前工作目录说明。
5. 涉及版本号时须写明版本约束语义，例如 `>=1.2.0 <2.0.0`。

## 3. 术语一致性

1. 术语首次出现时给出定义，格式为「中文术语（English Term，缩写）」。
2. 同一概念在全文中只使用一种表述，中英文版本术语一一对应。
3. 须维护中英术语对照表，置于 README 附录或独立文件，双语版本共用同一份对照表（模板见 [信息采集与模板](./信息采集与模板.md)）。

## 4. 格式规范

1. 标题层级从 `##` 开始（`#` 保留给项目名称），层级不得跳级。
2. 每个二级标题对应 [README章节规范](./README章节规范.md) 规定的一个章节，顺序不得调整。
3. 表格须有表头，列数一致；命令、路径、代码、配置键名使用行内代码标记。
4. 代码块须标注语言标识，多行命令须可整段复制执行。
5. 外部链接使用完整 URL，不使用短链接；内部跳转使用相对路径锚点。
6. 中文与英文、数字之间加空格；中英文标点不混用。

## 5. 占位符约定

1. 可复制模板中的正式占位符统一写成 `{{纯名}}`，例如 `{{仓库地址}}`；名称不得包含「或」「，」等表示多选取一的连接词，也不得写成一句说明文字。
2. 正式占位符须在所属模板的占位符对照表中登记，登记项包含含义、示例与是否必填。
3. 规范示例或填写提示中的自然语言花括号内容仅作示例，不属于正式占位符，不纳入对照表；生成最终文档时须全部替换为实际内容。
4. 不得使用嵌套花括号、反引号或第二个占位符作为占位符名称。
5. 多语言翻译时，占位符名称须与源语言逐字一致，不得本地化、音译或意译；仅占位符之外的说明文字可翻译。占位符是模板替换的锚点，一旦译名，跨语言对照与批量替换即失效。

## 6. 禁止清单

不得出现：未经验证的性能数字、无出处的对比结论、承诺性表述（如「保证兼容所有环境」「永久免费」）、对第三方项目的贬损性描述、与项目无关的推广内容。
