# README模板调研报告

> 本文件解决什么问题：记录本次标准 README 模板的调研方法、样本规模与量化发现，为 [README标准模板](./README标准模板.md) 及各专项规范提供数据依据，并明确方法的边界与局限。

## 1. 调研目标与方法

### 1.1 目标

调研 star 数排名靠前的头部开源项目，归纳其 README 及相关文档的结构、章节组织、视觉呈现与徽章使用规律，形成可复用的通用规范与模板。

### 1.2 数据来源

- 仓库元数据：GitHub GraphQL Search API，按 star 降序，筛选 `is:public archived:false fork:false`。
- README 原文：GitHub REST Contents API（`readme` 端点），以 base64 或 raw 形式获取后解析。
- 徽章参数：Shields.io 官方文档（Static Badge、Logos 页面）与 badge-maker 格式说明。
- 中文社区实践：phodal/github（《GitHub 漫游指南》，11,362 star）的项目文档、提交信息、推广章节，用于补充机读统计无法覆盖的写作原则与运营经验。

### 1.3 采集方法

1. **元数据**：GitHub Search API 单次查询最多返回 1000 条。为扩大样本，采用 star 区间分片——以二分法定位每 1000 名对应的 star 阈值，逐批下移累计 11 批，最终取得 10,995 个头部仓库的元数据。
2. **README 抽样**：在头部 1000 仓库内按主语言分层抽样，覆盖 Python、TypeScript、JavaScript、Rust、Go、C++ 等主要语言，抽样 120 个仓库，全部成功获取 README 原文。
3. **统计口径**：以仓库为单位统计章节出现率与元素使用率；徽章样式、logo 参数按 URL 中的出现次数统计。

### 1.4 方法局限（须明确）

- GitHub Search API 对单次查询设有 1000 条上限，本报告通过分片累计扩展规模，但分片边界受 star 并列影响，样本为近似头部集合，非严格连续排名。
- README 抽样规模为 120，结论反映趋势与共性，不代表全部头部项目的统计显著分布。
- 章节识别基于标题关键词匹配，存在措辞差异导致的统计偏差。
- 徽章参数统计针对 URL 显式出现的参数，动态徽章的默认参数未被计入。

## 2. 头部仓库分布（元数据）

### 2.1 样本规模

- 单次查询可稳定取得头部 1000 仓库，star 区间约 563,574 至 30,857。
- 经 11 批分片累计，扩展至 10,995 个头部仓库，star 下界 5,452。

### 2.2 语言分布（基于头部 1000）

| 语言 | 数量 | 占比 |
| --- | --- | --- |
| Python | 223 | 22.3% |
| TypeScript | 178 | 17.8% |
| JavaScript | 112 | 11.2% |
| Rust | 80 | 8.0% |
| 无主语言 | 74 | 7.4% |
| Go | 68 | 6.8% |
| C++ | 55 | 5.5% |
| Java | 27 | 2.7% |

头部项目以 Python、TypeScript、JavaScript 为主，三者合计超过 50%；Rust、Go 等系统语言占比显著。这决定了模板须覆盖多语言的包管理安装命令与多运行时徽章。

### 2.3 许可证分布（基于头部 1000）

| 许可证 | 数量 | 占比 |
| --- | --- | --- |
| MIT | 399 | 39.9% |
| Apache-2.0 | 197 | 19.7% |
| 未识别（NOASSERTION） | 148 | 14.8% |
| 无许可证（NONE） | 65 | 6.5% |
| GPL-3.0 | 51 | 5.1% |
| AGPL-3.0 | 50 | 5.0% |
| BSD-3-Clause | 17 | 1.7% |

MIT 占据主导，是通用模板的默认推荐；同时须保留 Apache-2.0、GPL 等选项的 SPDX 标识占位。

## 3. README 结构发现（N=120）

### 3.1 章节出现率

| 章节关键词 | 出现仓库数 | 出现率 |
| --- | --- | --- |
| Contributing / 贡献 | 66 | 55.0% |
| License / 许可证 | 52 | 43.3% |
| Install / 安装 | 49 | 40.8% |
| Quick Start / 快速开始 | 28 | 23.3% |
| Documentation / 文档 | 25 | 20.8% |
| Development / 开发 | 22 | 18.3% |
| Configuration / 配置 | 19 | 15.8% |
| Features / 功能 | 19 | 15.8% |
| Security / 安全 | 15 | 12.5% |
| Usage / 用法 | 12 | 10.0% |
| Requirements / 依赖环境 | 11 | 9.2% |
| API | 10 | 8.3% |
| Examples / 示例 | 10 | 8.3% |

发现：贡献指南与许可证是头部项目的标配，反映社区治理与合规的优先级；安装与快速开始紧随其后。模板因而将二者列为必填。

### 3.2 视觉元素使用率

| 元素 | 出现仓库数 | 出现率 | 中位数（每仓库） |
| --- | --- | --- | --- |
| 代码块 | 80 | 66.7% | 2 |
| 图片 | 76 | 63.3% | 2 |
| 徽章（Shields.io） | 61 | 50.8% | 1 |
| 表格 | 44 | 36.7% | 0 |

标题层级中位数：二级标题 7 个，文件长度中位数 171 行。这说明头部 README 普遍控制在中等长度，以 6–12 个二级标题组织。

### 3.3 主题适配（前 40 样本）

| 特征 | 出现仓库数 |
| --- | --- |
| 居中容器（`align="center"`） | 27 |
| `<picture>` 元素 | 12 |
| 明暗主题切换（`prefers-color-scheme`） | 12 |
| `for-the-badge` 搭配 `labelColor` | 2 |

居中容器是主流首页手法；约三成项目提供深浅主题双版本图片。

## 4. 徽章发现

### 4.1 样式参数（按 URL 出现次数，N=120）

| style | 次数 |

| `for-the-badge` | 65 |
| `flat-square` | 60 |

`for-the-badge` 与 `flat-square` 最流行；`plastic` 已基本弃用。详见 [徽章规范](./徽章规范.md)。

### 4.2 logo 参数（按出现次数，N=120）

| logo slug | 次数 |
| --- | --- |
| `github` | 35 |
| `discord` | 20 |
| `npm` | 4 |
| `apple` / `docker` / `linkedin` / `x` | 各 2–3 |

GitHub 与 Discord 是最常见的图标，对应「源码仓库」与「社区渠道」两类信息。

## 5. 标杆项目首屏取证

| 项目 | 类型 | 首页特征 |
| --- | --- | --- |
| `sindresorhus/awesome` | 资源合集 | 居中 Logo、赞助区、主题分类目录 |
| `axios/axios` | 类库 | 重要提示、赞助表格、多语言 |
| `sharkdp/fd` | CLI | 徽章 + 多语言链接、章节导航、Demo 动图 |
| `BurntSushi/ripgrep` | CLI | 徽章、快速链接、搜索截图、性能对比 |
| `vercel/next.js` | 框架 | 居中 Logo、`for-the-badge` 徽章、文档与社区入口 |
| `microsoft/vscode` | 应用 | 徽章、仓库说明、产品截图、贡献与反馈入口 |
| `rust-lang/rust` | 语言 | 居中横幅、导航行、Why Rust 价值点 |
| `phodal/github` | 中文电子书 | 首页四问、一句话文案范例、安装简化原则、推广渠道清单 |

共性：首屏回答「是什么、如何使用、详情在哪里」；徽章紧贴标题；截图或 Demo 紧随定位；贡献与社区入口下沉但必备。

## 6. 归纳结论

1. 通用模板须以「定位 → 安装 → 快速开始 → 文档 → 贡献 → 许可证」为主干。
2. 徽章默认 `flat-square` 或 `for-the-badge`，全篇统一，数量 4–6 枚。
3. 图片与代码块是高吸引力首页的核心，须配 `alt` 与语言标注。
4. 项目类型决定章节取舍，见 [README分类适配指南](./README分类适配指南.md)。
5. 合规与社区治理（许可证、贡献指南）是头部项目共识，列为必填。

头部仓库元数据分片累计结果：10,995 个仓库，star 区间为 563,575 至 5,452。该一万级样本的许可与语言分布如下，与头部 1000 样本结论一致：

| 维度 | 分布 |
| --- | --- |
| 语言 | Python 1,995、TypeScript 1,529、JavaScript 1,279、无主语言 888、Go 847、C++ 531、Java 528、Rust 507 |
| 许可证 | MIT 4,160（37.8%）、Apache-2.0 2,073（18.9%）、未识别 1,463、无许可证 1,106、GPL-3.0 747 |

README 深度统计样本 120 个，全部获取成功。分片采用近似 star 阈值，规模为头部近似集合，非严格连续排名。
