# 行为准则模板

> 本文件解决什么问题：提供一份可直接复制的行为准则模板，供项目生成 CODE_OF_CONDUCT.md，明确参与承诺、期望行为、不可接受行为、执行职责与举报渠道；配套的填写说明覆盖改编来源与版本声明。

## 1. 使用说明

1. 复制第 3 节「模板正文」全部内容，新建为项目根目录的 `CODE_OF_CONDUCT.md`。
2. 按第 4 节替换占位符，举报渠道必须为真实可达地址。
3. 若采用或改编自有版本的行为准则，须在第 5 节按来源要求声明版本与许可证，依据见 [行为准则规范](./行为准则规范.md) 第 1 节第 8 项。
4. 在 [贡献指南模板](./贡献指南模板.md) 与 README 的贡献章节中链接本文件，保持双向可达。

## 2. 定制原则

- **技术无关**：准则不含技术内容，仅规定参与行为规范，边界见 [文档矩阵](./文档矩阵.md)。
- **可执行**：分级处置须写明触发条件与措施，禁止只写原则不写后果。
- **可达性**：举报渠道必须真实有效，禁止留示例地址。
- **合规来源**：改编第三方准则须保留其署名与许可要求，见 [开源合规规范](./开源合规规范.md)。

## 3. 模板正文

```markdown
# 行为准则

## 我们的承诺

我们作为 {{项目名称}} 的参与者、贡献者与维护者，承诺共同营造开放、友善、无骚扰的参与环境，不论年龄、体型、残障状况、种族、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌或性取向。

## 适用范围

本准则适用于项目空间、议题、拉取请求、代码评审、社交渠道，以及个人以项目代表身份出现的公开场合。

## 期望行为

- 尊重不同观点与经验，善意沟通。
- 接受建设性反馈，聚焦问题本身而非个人。
- 关注社区整体利益，避免损害项目与其参与者。
- 对新人保持耐心，提供可操作的改进建议。

## 不可接受行为

- 人身攻击、侮辱性或贬损性言论。
- 基于任何受保护特征的歧视性言论与骚扰。
- 公开或私下骚扰、跟踪、未经同意的持续联系。
- 未经授权发布他人隐私信息。
- 其他在专业环境中被合理认定为不当的行为。

## 执行职责

项目维护者负责澄清本准则的适用、裁定违规行为，并有权删除、编辑或拒绝不符合本准则的内容。维护者须以一致、公正的方式行使职责，并对涉及自身的争议主动回避。

## 处置措施

违规行为按情节轻重分级处置：

| 等级 | 适用情形 | 措施 |
| --- | --- | --- |
| 一级 | 无意冒犯、轻微失当 | 私下提醒与说明 |
| 二级 | 重复发生或明确违规 | 公开警告、限期改正 |
| 三级 | 严重骚扰、恶意攻击 | 临时封禁参与权限 |
| 四级 | 持续或不可挽回的严重行为 | 永久封禁并保留记录 |

## 举报渠道

如遭遇或发现违反本准则的行为，请通过 {{真实可达的举报邮箱或渠道}} 联系维护团队。所有举报将被保密处理，维护者不得向被举报人披露举报人身份，除非举报人明确同意。

## 署名与来源

{{准则来源声明}}
```

## 4. 占位符对照表与字段定义

| 占位符 | 必填 | 字段定义 | 填写示例 |
| --- | --- | --- | --- |
| `{{项目名称}}` | 是 | 项目对外名称，与 README 首行一致 | `FooBar` |
| `{{真实可达的举报邮箱或渠道}}` | 是 | 可直接联系到维护者的真实地址 | `conduct@example.com` |
| `{{准则来源声明}}` | 是 | 原创写原创；改编须写来源名称、版本与许可证 | `改编自 Contributor Covenant 2.1（CC BY 4.0）` |

## 5. 填写说明与场景变体

| 场景 | 调整要点 |
| --- | --- |
| 个人项目 | 维护者写本人；举报渠道用长期持有的邮箱 |
| 企业项目 | 明确法务或社区团队为执行主体；处置措施须与内部制度一致 |
| 采用知名准则 | 保留其完整原文与版本，仅补充举报渠道与署名 |
| 多语言项目 | 各语言版本条款逐一对应；以英文或中文版为权威版本并注明 |

常见错误对照：

| 错误写法 | 后果 | 正确写法 |
| --- | --- | --- |
| 只写「欢迎友善交流」 | 无执行依据，争议时无法裁定 | 列明期望行为、不可接受行为与分级处置 |
| 举报渠道留占位邮箱 | 不可达，举报机制失效 | 填写真实且长期有效的地址 |
| 改编准则未署名 | 违反来源许可要求 | 声明来源、版本与许可证 |

## 6. 完整示例

以下为改编场景的节选，仅作格式参考。

```markdown
## 举报渠道

如遭遇或发现违反本准则的行为，请通过 conduct@example.com 联系维护团队。所有举报将被保密处理。

## 署名与来源

本准则改编自 Contributor Covenant 2.1，遵循 CC BY 4.0 许可。
```
