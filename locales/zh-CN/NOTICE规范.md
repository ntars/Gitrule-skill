# NOTICE规范

> 本文件解决什么问题：定义 NOTICE 文件必须包含的七部分、与 README 的一致性要求，确保第三方声明独立成文件且信息准确。

## 1. 独立成文件

NOTICE 独立成文件，不得与 README 合并，也不得以 README 列表替代。须包含以下部分：

1. **项目自身声明**：项目名称、著作权人、年份、许可证、SPDX 标识符。
2. **第三方组件清单**：按 [开源合规规范](./开源合规规范.md) 的依赖清单字段逐项列出。
3. **许可证原文附录**：许可证要求附全文的，须逐份附上原文；原文保持英文，不翻译。
4. **修改声明**：对第三方代码的修改位置与内容。
5. **素材与数据来源声明**。
6. **免责声明**：保留英文原文，可以附中文对照。
7. **待确认事项**：无法核实许可证或版权归属的条目，显式标注「待确认」。

## 2. 一致性要求

NOTICE 与 README 第 6 章（技术栈与依赖清单）、第 19 章（版权与许可）、第 20 章（NOTICE 合规声明）的组件与许可证信息须完全一致，版本、许可证标识、版权方不得出现差异。
