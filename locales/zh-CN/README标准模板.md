# README标准模板

> 本文件解决什么问题：提供一份可直接复制、按占位符替换即可套用的通用 README 模板，覆盖项目完整生命周期的首页呈现，附占位符对照表、可选章节说明与交付自检清单，使任何开发者均可据自身项目快速定制。

## 1. 使用说明

1. 复制第 3 节「模板正文」全部内容，新建为项目根目录的 `README.md`。
2. 按第 4 节占位符对照表逐个替换 `{{...}}`；未使用项连同所在整行或整节删除。
3. 第 3 节各小节对应 [README章节规范](./README章节规范.md) 的 20 章，按由内到外的生命周期顺序排列；删除某章时须同步删除首屏导航中对应链接。
4. 依据 [徽章规范](./徽章规范.md) 统一徽章样式、颜色与数量；依据 [README视觉排版规范](./README视觉排版规范.md) 检查截图、表格与代码块摆放。
5. 依据 [README分类适配指南](./README分类适配指南.md) 按项目类型取舍章节。
6. 提交前执行第 6 节自检清单，确认无残留占位符。

## 2. 定制原则

- **必填项**：项目名称、仓库描述、一句话定位、安装、快速开始、许可证。
- **顺序固定**：章节顺序与 [README章节规范](./README章节规范.md) 一致，中英文版本逐章对应。
- **证据优先**：核心特性、性能表现、工程取舍须给出可复核的证据，禁止定性夸赞。
- **透明披露**：不适用场景、局限、已知问题、未实现功能须显式列出，不得隐瞒。
- **非承诺**：路线图标注「非承诺」，不写具体交付日期。
- **真实性**：所有命令、示例、链接、徽章须实际可用；联系方式与上报渠道须真实可达。

## 3. 模板正文

本节按项目生命周期「由内到外」组织，共 20 节，与 [README章节规范](./README章节规范.md) 的 20 章一一对应。每节代码块内的文字即为可复制正文。

章节与生命周期阶段的映射如下，便于按需定位：

| 生命周期阶段 | 对应小节 | 呈现重点 |
| --- | --- | --- |
| 项目启动 | 3.1–3.2 | 定位、背景、适用场景与局限 |
| 需求分析 | 3.2–3.3 | 功能边界、适用场景、不适用场景 |
| 架构设计 | 3.5–3.6、3.11 | 工程取舍、技术栈、目录结构 |
| 开发实现 | 3.3–3.4、3.9–3.10 | 功能、特性、配置、API |
| 测试验证 | 3.8、3.12 | 快速开始示例、性能表现证据 |
| 部署上线 | 3.7、3.14 | 安装部署、兼容性矩阵 |
| 运维监控 | 3.13、3.15 | 安全隐私、已知问题与限制 |
| 迭代维护 | 3.15–3.17 | 未实现功能、更新日志、后续路线图 |

说明：README 是项目首页，各阶段的过程文档（需求、设计、测试、部署、运维的完整记录）由对应规范承载，见 [文档矩阵](./文档矩阵.md)；本章节仅呈现对使用者可见的结论。
