# 子Agent分派契约

> 本文件解决什么问题：定义向子 agent 分派任务时必须写清的四要素与协作约束，确保结论结构化、可验证、无规则漂移。

## 1. 分派四要素

每次分派必须写清四要素：

```text
TASK:    <一句话任务>
INPUT:   <需要的文件/上下文，只给必要部分>
OUTPUT:  <结构化格式，表格或 JSON，禁止散文>
FAIL:    <做不了时返回什么，而不是瞎编>
```

## 2. 约束

- 一个子 agent 一次只干一件事，禁止「顺便把 README 也写了」。
- 子 agent 只能读、只能出方案；**写文件与 git 操作统一由主控执行**。
- 子 agent 结论必须带证据（文件路径 + 行号 / 命令输出），无证据的结论视为无效。
- 子 agent 之间不直接通信，全部经主控汇总，避免规则漂移。
