# 机器可读元数据规范

> 本文件解决什么问题：定义供专家、Skill、MCP、命令行等程序化消费的元数据清单结构，保证机器取用稳定、可发现。

## 1. 设计目标

1. 稳定标识：每份文档有唯一、不变的标识，供程序引用。
2. 语言无关：标识不随语言变化，语言仅体现在路径上。
3. 可发现：清单列出全部文档的类型、路径、语言与摘要。

## 2. 清单结构

机器清单（manifest）须包含：

| 字段 | 要求 |
| --- | --- |
| id | 稳定唯一标识，小写 kebab-case，不含语言与版本 |
| title | 文档标题 |
| summary | 一句话说明解决什么问题 |
| domain | 所属域（七大域之一） |
| paths | 语言码到相对路径的映射，如 `zh-CN`: `./locales/zh-CN/角色与职责.md` |
| version | 规范集版本 |

## 3. 强制规则

1. 新增语言只在 `paths` 中追加映射，不改动 `id` 与其他语言路径。
2. 文档改名须保留 `id` 不变，仅更新 `paths`。
3. 标识与路径须与实际文件一致，CI 校验清单有效性。
4. 本规范提供可复制清单示例；目标项目应按第 2 节字段创建实际清单实例，并确保 `paths` 与磁盘文件一致。

## 4. 清单示例（可复制）

以下示例列出三个文档条目。实际清单须覆盖目标语言目录的全部规范；`id` 不随语言变化，`paths` 按语言码追加映射。

```json
{
  "version": "1.0.0",
  "entries": [
    {
      "id": "role-and-responsibility",
      "title": "角色与职责",
      "summary": "定义执行者身份、职责边界、触发条件、适用范围与硬性约束",
      "domain": "总纲与治理",
      "paths": {
        "zh-CN": "./locales/zh-CN/角色与职责.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "readme-standard-template",
      "title": "README标准模板",
      "summary": "提供可直接套用的通用 README 模板与占位符对照表",
      "domain": "命名与文档",
      "paths": {
        "zh-CN": "./locales/zh-CN/README标准模板.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "machine-readable-metadata",
      "title": "机器可读元数据规范",
      "summary": "定义供专家、Skill、MCP、命令行消费的元数据清单结构",
      "domain": "AI 与机器适配",
      "paths": {
        "zh-CN": "./locales/zh-CN/机器可读元数据规范.md"
      },
      "version": "1.0.0"
    }
  ]
}
```

新增语言时，只在对应条目的 `paths` 中追加映射，例如增加 `"en-US": "./locales/en-US/role-and-responsibility.md"`；不得修改 `id`。
