# Skill编写规范

> 本文件解决什么问题：定义将规范集封装为 Skill 时的结构、触发条件与渐进加载方式，保证 Skill 可发现、可维护、不重复内容。

## 1. 目录结构

Skill 采用「入口 + 按需资源」结构：

```text
skill-name/
├── SKILL.md          必需：元数据 + 核心流程
├── references/       规范正文，按需加载
└── assets/           模板与素材（可选）
```

## 2. SKILL.md 要求

1. 元数据含 `name` 与 `description`，描述须写明「做什么 + 何时用」，以便触发。
2. 正文只保留常驻的核心规则与流程，详细查表类内容放入 `references/`。
3. 采用祈使/不定式写法，避免第二人称。
4. 引用资源时给出明确路径与「何时读取」的条件。

## 3. 强制规则

1. 规范正文只在一处维护：Skill 引用本规范集文件，不复制全文，避免双份漂移。
2. 一个 Skill 只做一件事，禁止把多个职责塞进同一 Skill。
3. 触发条件写明具体短语，避免过宽触发。
4. 版本随规范集版本同步更新。
