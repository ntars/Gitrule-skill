# 需求追踪矩阵规范

> 本文件解决什么问题：定义需求到设计、实现、测试、发布的双向追踪矩阵模板与字段，保证生命周期各阶段的产物相互引用一致、变更影响可评估、覆盖缺口可发现。

## 1. 规范条文

1. 每条「必须」级需求须在追踪矩阵中占一行，并记录从立项到发布的全链路产物。
2. 追踪关系须双向可查：正向由需求查到下游产物，反向由产物查到上游需求。
3. 一条需求对应多个产物时，使用逗号分隔的编号列表；编号须与对应文档中的定义完全一致。
4. 需求变更须在矩阵中留痕，记录变更原因、影响范围与决策人，不得直接覆盖原值。
5. 矩阵须在每次版本发布前核对，未闭环的「必须」级需求不得发布。
6. 覆盖率统计口径：需求覆盖率 = 已发布「必须」级需求数 / 「必须」级需求总数。

```markdown

| 需求 ID | 需求标题 | 优先级 | 立项目标 | 架构决策 | 设计文档 | 实现 PR | 测试用例 | 发布版本 | 状态 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| REQ-001 | {{标题}} | 必须 | G1 | ADR-0002 | docs/api.md#check | #12 | TC-001, TC-002 | v1.0.0 | 已验证 |
| REQ-002 | {{标题}} | 应当 | G2 | — | — | #15 | TC-005 | — | 已实现 |
| REQ-003 | {{标题}} | 必须 | G1 | ADR-0003 | docs/architecture.md#flow | — | — | — | 待实现 |

状态：待确认 / 已确认 / 待实现 / 已实现 / 已验证 / 已发布 / 已废弃
```

```markdown
## 变更记录

| 日期 | 需求 ID | 变更内容 | 原因 | 影响范围 | 决策人 |
| --- | --- | --- | --- | --- | --- |
| {{YYYY-MM-DD}} | {{REQ-NNN}} | {{字段：原值 → 新值}} | {{依据}} | {{受影响的下游产物}} | {{姓名}} |
```

## 5. 字段定义

| 字段 | 必填 | 类型 | 填写要点 | 示例 |
| --- | --- | --- | --- | --- |
| 需求 ID | 是 | `REQ-NNN` | 与 [项目立项与需求规范](./项目立项与需求规范.md) 编号一致 | `REQ-001` |
| 优先级 | 是 | 枚举 | 必须 / 应当 / 可以 | `必须` |
| 立项目标 | 是 | `G-N` | 对应立项书的目标编号 | `G1` |
| 架构决策 | 否 | `ADR-NNNN` | 无架构决策写「—」，不得留空 | `ADR-0002` |
| 设计文档 | 否 | `路径#锚点` | 精确到章节锚点 | `docs/api.md#check` |
| 实现 PR | 否 | `#数字` | PR 编号，不是提交哈希 | `#12` |
| 测试用例 | 是 | `TC-NNN` 列表 | 至少一条；无用例时说明原因 | `TC-001` |
| 发布版本 | 否 | `vX.Y.Z` | 与 tag 一致 | `v1.0.0` |
| 状态 | 是 | 枚举 | 七态之一，仅前进，废弃除外 | `已验证` |
| 变更记录.影响范围 | 是 | 文本 | 列出受影响的 ADR、PR、TC | `ADR-0002, TC-001` |

## 6. 填写说明

1. **编号一致**：矩阵中的需求 ID、ADR 编号、TC 编号必须与源文档逐字一致；禁止使用简称或别名。
2. **空值规范**：不适用写「—」，未产生写「待补」；两者含义不同，不得混用。
3. **反向索引**：每次更新正向矩阵后同步更新反向索引；两者不一致时以正向矩阵为准并立即修正。
4. **变更留痕**：修改任何字段前先在变更记录中追加一行，写明原值与新值；禁止直接覆盖。
5. **发布核对**：发布前逐条检查「必须」级需求是否具备测试用例与发布版本；缺任一项即阻断发布。
6. **已废弃需求**：保留行不删除，状态改为「已废弃」，并在变更记录中写明废弃原因。

常见错误：

| 错误写法 | 问题 | 修正方式 |
| --- | --- | --- |
| 测试用例字段留空 | 覆盖缺口不可见 | 填「待补」并在发布前清零 |
| PR 字段填提交哈希 | 无法定位审查记录 | 改用 PR 编号 |
| 变更时直接改值 | 影响不可追溯 | 先追加变更记录 |
| 状态从「已验证」回退到「已实现」 | 违反仅前进原则 | 新开缺陷并另起追踪行 |
| 正向与反向索引不一致 | 引用失配 | 发布前以正向为准同步 |
