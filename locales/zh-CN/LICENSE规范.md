# LICENSE规范

> 本文件解决什么问题：定义项目许可证的 SPDX 标注、LICENSE 全文要求、版权行位置与多许可证说明，以及未经确认不得写入的规则。

## LICENSE 规则

1. 项目许可证须以 SPDX 标识符在 README 中明确写出，并提供对应 LICENSE 文件。
2. LICENSE 文件须为该许可证官方英文全文，不得删改条款。
3. 版权行置于文件头部或 README 第 19 章，格式见 [README章节规范](./README章节规范.md)。
4. 采用双许可证或多许可证时，须说明适用条件与选择方式。
5. 许可证选择未经用户确认时，不得直接写入文档，仅提供候选方案与差异说明。
