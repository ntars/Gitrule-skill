# 术语表

> 本文件解决什么问题：集中定义项目全篇使用的专业术语与缩写，保证中英版本术语一一对应、全文表述一致。

## 1. 维护规则

1. 术语首次出现时须给出定义，格式为「中文术语（English Term，缩写）」。
2. 同一概念全文只用一种表述；中英版本术语一一对应，共用本表。
3. 新增术语须同步写入本表，并同步到英文版本对应位置。
4. 缩写首次出现须展开全称，之后可直接使用缩写。

## 2. 术语对照表

| 中文 | English | 缩写 | 说明 |
| --- | --- | --- | --- |
| 软件物料清单 | Software Bill of Materials | SBOM | 项目依赖与组件的完整清单 |
| 语义化版本 | Semantic Versioning | SemVer | 版本号格式 `MAJOR.MINOR.PATCH` |
| 架构决策记录 | Architecture Decision Record | ADR | 记录重要架构决策及其背景与后果 |
| 行为准则 | Code of Conduct | CoC | 社区参与者行为规范 |
| 持续集成 / 持续交付 | Continuous Integration / Continuous Delivery | CI/CD | 自动化构建、测试与交付流程 |
| 软件许可证标识符 | Software Package Data Exchange | SPDX | 许可证的标准标识符体系 |
| 最小可行产品 | Minimum Viable Product | MVP | 可验证核心假设的最小版本 |
| 自然语言处理器 | Natural Language Processing | NLP | 文本处理相关技术 |
| 大模型 | Large Language Model | LLM | 大规模预训练语言模型 |
| 模型上下文协议 | Model Context Protocol | MCP | 连接模型与外部工具的协议 |
| 待补充 | To Be Determined | TBD | 信息尚未确认的占位标记 |

> 表中条目为通用示例，使用前须按项目实际术语增删。
