# MCP工具规范

> 本文件解决什么问题：定义将规范集通过模型上下文协议（MCP）暴露为工具时的接口设计与描述规则，保证工具可被模型正确发现与调用。

## 1. 工具设计原则

1. 单一职责：一个工具做一件事，避免大而全的接口。
2. 描述清晰：工具描述说明用途与适用场景，便于模型判断何时调用。
3. 参数明确：每个参数有类型、是否必填、取值范围与说明。
4. 输出结构化：返回结构化数据，避免长篇散文。

## 2. 必含字段

| 字段 | 要求 |
| --- | --- |
| name | 唯一标识，小写 kebab-case |
| description | 用途与触发条件，具体可判断 |
| inputSchema | 参数类型、必填项、约束 |
| 返回值 | 结构化格式与字段说明 |
| 错误 | 失败时的返回格式，不得编造结果 |

## 3. 规范集相关工具

1. 文档检索类：按语言码 + 标识返回规范内容（标识见 [机器可读元数据规范](./机器可读元数据规范.md)）。
2. 清单类：返回可用文档列表及其语言映射。
3. 校验类：检查文档矩阵完整性（见 [文档矩阵](./文档矩阵.md)）与门禁状态（见 [质量门禁](./质量门禁.md)）。

## 4. 强制规则

1. 工具不得返回无法检查的结果为 PASS，须标注 SKIP 与原因（见 [禁止事项](./禁止事项.md)）。
2. 输出须可被程序解析，不含内部思考过程。
3. 安全相关内容不得通过工具泄露（见 [安全与隐私规范](./安全与隐私规范.md)）。
