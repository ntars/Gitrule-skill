## 阅读路径

- **确定选用范围**：规范选用指南 → 生命周期映射表 → 对应阶段的规范文件。
- **贯穿生命周期**：生命周期映射表 → 项目立项与需求规范 → 需求追踪矩阵规范 → 架构设计文档规范 → 测试规范 → 部署与回滚规范 → 可观测性规范 → 迭代回顾规范。
- **快速推送**：硬规则 → 质量门禁 → 推送与发布规范 → 审核报告格式。
- **从零生成文档**：角色与职责 → 执行流程 → 信息采集与模板 → 文档矩阵 → README章节规范 → 开源合规规范 → 质量门禁。
- **编写 README**：README模板调研报告 → README视觉排版规范 → 徽章规范 → README分类适配指南 → README标准模板。
- **完整审核**：审核维度矩阵 → 子Agent分派契约 → 硬规则 → 质量门禁 → 审核报告格式。
- **程序化接入**：机器可读元数据规范 → Skill编写规范 / MCP工具规范 / Agent调用与提示词规范。
- **风险与责任边界**：免责声明 → 免责声明模板 → SECURITY模板 → 安全与隐私规范 → 开源合规规范。
- **生成社区治理文件**：贡献指南模板 → 行为准则模板 → SECURITY模板 → 免责声明模板。

## 用语约定

- **必须 / 不得**：强制要求。
- **应当 / 不应**：推荐或禁止，偏离时须说明理由。
- **可以**：可选。
- **P0 / P1 / P2**：P0 阻断推送；P1 推送前应修或必须登记待办；P2 建议优化。
