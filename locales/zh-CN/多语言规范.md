# 多语言规范

> 本文件解决什么问题：定义按语言码分目录的文件布局、语言切换、翻译一致性、代码一致性与单侧修改同步规则。

## 1. 目录布局

1. 仓库根目录的 `README.md` 仅承担项目首页与语言导航，不承载具体规范正文。
2. 具体规范按语言码平铺在 `locales/<language-code>/` 目录，例如 `locales/zh-CN/角色与职责.md`。
3. 语言码采用 BCP 47 风格，例如 `zh-CN`、`en-US`、`ja-JP`、`ko-KR`；语言码只出现在目录名，不写在文件名里。
4. **文件名须使用该语言本身**：中文目录用中文文件名（`角色与职责.md`），英文目录用英文小写连字符文件名（`roles-and-responsibilities.md`），其他语言同理，禁止在非中文目录沿用中文文件名。
5. 各语言目录的文件名互不要求逐字对应，但必须做到一一映射：同一篇规范在各语言目录中内容职责相同，映射关系登记在清单文件的 `paths` 字段（见 [机器可读元数据规范](./机器可读元数据规范.md)）。
6. 简体中文与英语为首批完成版本；其他语言在根 `README.md` 的语言表中标注「待补充」或「已完成」，未建立目录的语言不得提供空链接。
7. 新增语言只新建对应语言目录并逐篇翻译，不改动已有语言文件；仅在源语言修订需要同步时更新其他已完成语言。

## 2. 语言切换

1. 每个语言目录的 `README.md` 顶部须提供语言切换链接。
2. 链接使用相对于当前语言目录的路径，例如简体中文目录中的写法：
   `[English](../en-US/README.md) | [简体中文](./README.md)`。
3. 链接文本使用目标语言的自称，例如 `English`、`简体中文`、`日本語`，不写 `CN`、`EN` 等缩写。
4. 切换链接只指向已建立的语言目录；未建立的语言目录由根 `README.md` 的语言表统一标注，不在正文中留下断链。

## 3. 翻译一致性

1. 译文须为完整翻译，章节数量、章节顺序、表格列数、代码块数量与源语言一致；不得提供摘要式或未经校对的机翻式产出。
2. 代码块内的命令、路径、配置键名、占位符名称与参数值保持不变，仅注释与说明文字翻译。
3. 术语按 [信息采集与模板](./信息采集与模板.md) 的中英术语对照表统一；同一概念在所有语言中使用同一组对应关系。
4. 任何单侧修改须同步全部已完成语言，并在更新日志中记录同步的语言码与版本；未完成同步不得判定该次修订完成。
5. 一致性校验属于门禁 G10，见 [质量门禁](./质量门禁.md)。

## 4. 法律文本

1. NOTICE 默认提供中文版本；涉及许可证原文、版权声明与免责声明的法律文本保留英文原文，不翻译、不改写。
2. 需要中英对照的法律文本须并列展示原文与译文，并标明「译文仅供参考，以原文为准」。
3. 法律文本的语种处理见 [NOTICE规范](./NOTICE规范.md) 与 [免责声明](./免责声明.md)。
