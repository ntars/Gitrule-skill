# 质量门禁

> 本文件解决什么问题：定义三层门禁的放行条件、判定清单模板与字段，保证推送放行判定统一、可执行、可复核。

## 1. 三层门禁

| 层级 | 含义 | 放行条件 |
| --- | --- | --- |
| Gate A · 安全门 | 密钥、隐私、许可证、大文件 | 零 P0 |
| Gate B · 质量门 | 构建、测试、lint、提交规范、分支保护 | 零 P0，P1 已记录待办 |
| Gate C · 门面门 | README、元数据、文档矩阵、徽章、链接 | 零 P0，P1 ≤ 3 且已排期 |

只有 A、B、C 全绿，才输出 `✅ ALLOW PUSH`。未通过项须修正或标注原因，结果写入 [审核报告格式](./审核报告格式.md)。

## 2. 交付前 14 项判定

文档交付前逐项判定，未通过项须修正或标注原因。

| 编号 | 检查项 | 判定标准 |
| --- | --- | --- |
| G1 | 口语化与歧义 | 全文检索口语词与模糊指代，命中数为 0 |
| G2 | 章节完整性 | 中英版本均为 20 章，顺序一致 |
| G3 | 功能与目录一致性 | README 描述的功能均可在目录结构中找到对应模块 |
| G4 | 亮点证据 | 每条亮点均有证据或已标注待补充 |
| G5 | 设计细节覆盖 | 第 8 节 10 类均有条目或注明不适用 |
| G6 | 依赖完整性 | 直接与间接依赖数量与依赖树一致 |
| G7 | 许可证准确性 | 每个依赖的 SPDX 标识符与官方声明一致 |
| G8 | 许可证原文 | 要求附全文的许可证均已附上英文原文 |
| G9 | 版权声明 | 项目自身与他人版权声明均完整 |
| G10 | 双语同步 | 章节、表格、术语、代码块双侧一致 |
| G11 | 命令可执行性 | 安装、快速开始、推送命令均可直接执行 |
| G12 | 待确认汇总 | 所有待确认项已汇总且位置可定位 |
| G13 | 素材来源 | 所有素材均有来源与许可证记录 |
| G14 | 敏感信息 | 无密钥、令牌、内网地址、个人隐私信息 |

## 4. 字段定义

| 字段 | 必填 | 类型 | 填写要点 | 示例 |
| --- | --- | --- | --- | --- |
| 判定人 | 是 | 文本 | 唯一，禁止「团队」 | `王五` |
| 结论 | 是 | 枚举 | PASS / FAIL / SKIP | `PASS` |
| 证据 | 是 | 文本 | 路径 + 行号或命令输出，禁止无证据判定 | `gitleaks: 0 findings` |
| 等级 | 条件必填 | 枚举 | FAIL 时必填 P0 / P1 / P2 | `P0` |
| 处置 | 条件必填 | 文本 | FAIL 时必填具体动作与责任人 | `轮换密钥并清理历史` |
| SKIP 原因 | 条件必填 | 文本 | SKIP 时必填，禁止无理由跳过 | `无构建脚本` |
| 放行结论 | 是 | 枚举 | ALLOW PUSH / BLOCK PUSH | `BLOCK PUSH` |
| 阻断原因 | 条件必填 | 文本 | BLOCK 时必填，列出 P0 | `A2 历史密钥命中` |

## 5. 填写说明

1. **证据强制**：每条判定须有证据；无证据的 PASS 视为无效，应改为 SKIP 并说明原因。
2. **等级对应**：FAIL 须标等级；P0 直接阻断放行，P1 须登记待办，P2 记入建议。
3. **Gate C 门槛**：P1 ≤ 3 且已排期方可 PASS；超出须降级处理或阻断。
4. **SKIP 使用**：无法检查时标 SKIP + 原因，不得写 PASS；待条件具备后补检。
5. **一致性**：门禁判定须与 [审核维度矩阵](./审核维度矩阵.md) 的 P0/P1/P2 等级、[硬规则](./硬规则.md) 的阻断规则一致。
6. **放行**：三项全绿方可输出 `✅ ALLOW PUSH`；任一 FAIL 输出 `⛔ BLOCK PUSH`，并列出阻断原因。
7. **交付格式**：判定结果按 [审核报告格式](./审核报告格式.md) 输出；通过后执行 [推送与发布规范](./推送与发布规范.md)。

常见错误：

| 错误写法 | 问题 | 修正方式 |
| --- | --- | --- |
| 结论 PASS 但证据为空 | 判定无效 | 补证据或改 SKIP |
| P0 未清零仍写 ALLOW PUSH | 违反硬规则 | 改为 BLOCK PUSH |
| SKIP 无原因 | 疑似漏检 | 补原因 |
| Gate C 有 5 项 P1 仍 PASS | 超门槛 | 降级或阻断 |
| 判定结果只写文字无清单 | 不可复核 | 用模板逐项填写 |

## 6. 完整示例

```markdown
# 门禁判定：markdown-lint-cli v1.0.0

判定日期：2026-11-20 ｜ 判定人：王五 ｜ 仓库：example/markdown-lint-cli

## Gate A · 安全门
| 编号 | 检查项 | 结论 | 证据 | 等级 | 处置 |
| --- | --- | --- | --- | --- | --- |
| A1 | 工作区密钥 | PASS | gitleaks detect: 0 findings | — | — |
| A2 | 历史密钥 | PASS | gitleaks --log-opts=--all: 0 findings | — | — |
| A4 | LICENSE 存在与类型 | PASS | LICENSE 第 1 行 MIT | — | — |
| A5 | 大文件与 LFS | PASS | find -size +50M: 无 | — | — |

结论：PASS，未决项：无

## Gate B · 质量门
| 编号 | 检查项 | 结论 | 证据 | 等级 | 处置 |
| --- | --- | --- | --- | --- | --- |
| B1 | 构建通过 | PASS | run #128 | — | — |
| B2 | 测试通过 | PASS | 132/132 passed | — | — |
| B4 | 提交信息规范 | PASS | git log --oneline 全部合规 | — | — |

结论：PASS，未决项：无

## 总判定
- A：PASS ｜ B：PASS ｜ C：PASS

- 阻断原因：无
```
