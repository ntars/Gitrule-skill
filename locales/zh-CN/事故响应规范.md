# 事故响应规范

> 本文件解决什么问题：定义事故报告模板、时间线记录、沟通模板与复盘字段，保证故障可控、信息同步、经验可沉淀。

## 1. 规范条文

1. 事故分级：P0 核心功能不可用或数据损坏；P1 严重功能受损影响多数用户；P2 局部问题、影响有限。
2. 响应流程：发现 → 定级 → 止血 → 定位 → 修复 → 公告；止血优先于定位。
3. 每次 P0/P1 事故须复盘，记录时间线、根因、影响、处置与改进项。
4. 改进项须纳入 [路线图规范](./路线图规范.md) 跟踪闭环。
5. 复盘聚焦系统改进，不追究个人责任。
6. 密钥泄漏：立即轮换 → 清理历史 → 公告，不得只做删除提交（见 [安全与隐私规范](./安全与隐私规范.md)）。
7. 误推大文件：LFS 迁移或历史重写（见 [推送与发布规范](./推送与发布规范.md)）。

## 3. 沟通模板

```markdown
## 事故通报（首次）

- 时间：{{YYYY-MM-DD HH:MM}}
- 级别：{{P0 / P1 / P2}}
- 现象：{{用户可感知的现象，不写内部细节}}
- 影响：{{受影响范围}}
- 当前措施：{{正在做什么}}
- 下次更新时间：{{HH:MM}}

## 事故通报（恢复）

- 恢复时间：{{HH:MM}}
- 恢复确认：{{验证方式与结果}}
- 剩余影响：{{无 / 描述}}
- 后续：{{复盘安排}}
```

## 4. 字段定义

| 字段 | 必填 | 类型 | 填写要点 | 示例 |
| --- | --- | --- | --- | --- |
| 事故编号 | 是 | `INC-YYYYMMDD-NN` | 当日序号，连续不复用 | `INC-20261118-01` |
| 事故级别 | 是 | 枚举 | P0 / P1 / P2 | `P1` |
| 持续时长 | 是 | 时长 | 发现到恢复的分钟数 | `42 分钟` |
| 指挥人 | 是 | 文本 | 唯一，负责决策与同步 | `李四` |
| 受影响用户比例 | 是 | 文本 | 须给估算依据 | `约 8%，依据错误日志计数` |
| 时间线 | 是 | 表格 | 每节点含时间与来源 | 见模板 |
| 根本原因 | 是 | 文本 | 区分直接原因与根本原因 | `缺少回滚演练` |
| 改进项.验证方式 | 是 | 文本 | 可判定，含阈值 | `下次演练回滚 <5 分钟` |
| 下次更新时间 | 是 | 时刻 | 处理中必填，禁止「随时更新」 | `18:30` |

## 5. 填写说明

1. **定级**：按影响范围与严重程度定级；不确定时从高定级，后续调整并记录原因。
2. **止血优先**：先恢复服务（回滚、降级、限流），再定位根因；定位不得延误止血。
3. **时间线**：按发生时间顺序记录，来源须可查（告警 ID、命令、日志片段）；禁止事后凭记忆补写。
4. **根因**：直接原因是触发事件，根本原因是体系缺陷；两者均须填写。
5. **沟通**：首次通报须给出下次更新时间；恢复通报须说明验证方式与剩余影响。
6. **改进项**：最多三条，纳入路线图跟踪；无负责人的改进项不得进入报告。
7. **复盘**：聚焦系统与流程改进，不评价个人；不追究责任与写「某人不慎」类表述。
8. **特殊事故**：密钥泄漏按 H12 处理；误推大文件按 LFS 迁移处理，均须单独留痕。

常见错误：

| 错误写法 | 问题 | 修正方式 |
| --- | --- | --- |
| 先定位根因再止血 | 延长故障时长 | 先回滚恢复 |
| 时间线事后补写 | 事实不可信 | 处理中即时记录 |
| 根因写「某人不小心」 | 归责个人、无改进价值 | 追问到流程或工具层面 |
| 通报写「尽快修复」 | 无下次更新时间 | 给具体时刻 |
| 改进项无验证方式 | 闭环不可判定 | 补阈值与检查时机 |

## 6. 完整示例

```markdown
# 事故报告：INC-20261118-01

- 事故级别：P1
- 发现时间：2026-11-18 10:12
- 恢复时间：2026-11-18 10:54
- 持续时长：42 分钟
- 指挥人：李四
- 当前状态：已复盘

## 影响范围
| 维度 | 说明 |
| --- | --- |
| 受影响功能 | 规则检查接口返回 5xx |
| 受影响用户比例 | 约 8%，依据 5xx 日志计数 |
| 数据影响 | 无 |
| 业务影响 | 42 分钟内无法提交检查任务 |

## 根因
- 直接原因：规则插件加载路径被新配置覆盖，导致启动失败。
- 根本原因：配置变更未纳入预发布验证。

## 改进项
| 编号 | 动作 | 负责人 | 截止日期 | 验证方式 | 状态 |
| --- | --- | --- | --- | --- | --- |
| A-01 | 将配置变更纳入预发布检查清单 | 王五 | 2026-11-25 | 下轮 5 次变更均含检查记录 | 待开始 |
```
