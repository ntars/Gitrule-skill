# 质量度量指标规范

> 本文件解决什么问题：定义可跟踪的质量指标及其口径，避免用无依据的数字评价项目质量。

## 1. 指标原则

1. 指标须可测量、可复现，写明采集方式与统计口径。
2. 指标用于改进，不用于简单排名或制造压力。
3. 每个指标须标注目标值与当前值，并定期回顾。

## 2. 建议指标

| 类别 | 指标 | 口径说明 |
| --- | --- | --- |
| 测试 | 测试覆盖率 | 被测代码行占比，注明统计工具 |
| 测试 | 测试通过率 | 通过用例数 / 总用例数 |
| 构建 | 构建成功率 | 成功构建次数 / 总构建次数 |
| 缺陷 | 缺陷密度 | 单位规模代码发现的缺陷数 |
| 缺陷 | 平均修复时长 | 从发现到修复完成的平均耗时 |
| 性能 | 响应时间 | 明确场景与分位值（如 P95） |
| 依赖 | 高危漏洞数 | 未修复的高危依赖漏洞数量 |

## 3. 强制规则

1. 性能指标须注明测试环境与方法，禁止无条件的数字（对应 [通用写作规范](./通用写作规范.md)）。
2. 指标数据采集须自动化，减少人工统计偏差。
3. 指标异常须有跟进记录，纳入 [路线图规范](./路线图规范.md) 或问题跟踪。
