# 免责声明模板

> 本文件解决什么问题：提供一份可直接复制、按占位符替换即可套用的通用免责声明模板，使任何项目都能以最小成本界定自身的内容性质、责任边界与使用者义务；配套的填写说明与场景变体覆盖个人、企业、开源与闭源项目。

## 1. 使用说明

1. 复制第 3 节「模板正文」的全部内容，新建为项目根目录的 `DISCLAIMER.md`，或并入 `README.md` 的独立章节。
2. 按第 4 节占位符对照表逐个替换 `{{...}}`；未使用的整节须删除，不留空占位符。
3. 按第 5 节场景变体裁剪条款：闭源软件侧重第 3.5 节，开源项目须保留第 3.6 节与许可证的关系说明。
4. 本模板为通用参考文本，不构成法律意见。涉及正式对外发布、跨境分发或受监管行业时，须经法务审定后使用，依据见 [免责声明](./免责声明.md) 第 2 节。
5. 提交前核对：占位符已全部替换、联系方式真实可达、与 [LICENSE](../../LICENSE) 条款无冲突。

## 2. 定制原则

- **合法优先**：所有免责条款仅在适用法律允许的范围内生效，禁止写「无条件免除一切责任」等绝对化表述，避免整条失效。
- **不越界**：不得撤销、缩减许可证授予的权利；冲突时以许可证正文为准，原则见 [LICENSE规范](./LICENSE规范.md)。
- **可验证**：联系方式、生效日期、主体名称须为真实信息，禁止保留示例值。
- **独立性**：各条款相互独立，单条无效不影响其余条款效力。

## 4. 占位符对照表与字段定义

| 占位符 | 必填 | 字段定义 | 填写示例 |
| --- | --- | --- | --- |
| `{{项目名称}}` | 是 | 项目对外名称，与 README 首行一致 | `FooBar` |
| `{{主体名称}}` | 是 | 承担或放弃责任的主体全称，个人项目写姓名，企业项目写法定名称 | `某某科技有限公司` |
| `{{维护主体}}` | 是 | 负责修订声明的组织或个人 | `FooBar 维护团队` |
| `{{更新日期}}` | 是 | 本声明最近一次修订的日期，格式统一为 YYYY-MM-DD | `2026-11-18` |
| `{{生效日期}}` | 是 | 本声明开始生效的日期，可与更新日期相同 | `2026-11-18` |
| `{{内容性质描述}}` | 是 | 一句话说明项目是什么、处于何种成熟度 | `供开发者参考的示例实现，非生产级组件` |
| `{{数据或示例的时点与范围说明}}` | 否 | 示例中数据或参数的采集时点与适用范围 | `2026 年 10 月对 120 个样本的统计` |
| `{{许可证名称及 SPDX 标识符}}` | 是 | 项目许可证全称与 SPDX 标识 | `MIT 许可证（MIT）` |
| `{{仓库地址或发布渠道}}` | 是 | 声明最新版本的权威发布位置 | `https://github.com/owner/repo` |
| `{{真实可达的联系邮箱或渠道}}` | 是 | 使用者可触达维护者的真实地址 | `security@example.com` |

## 5. 填写说明与场景变体

| 场景 | 必留条款 | 可裁剪条款 | 调整要点 |
| --- | --- | --- | --- |
| 个人项目 | 3.1 / 3.2 / 3.3 / 3.5 / 3.7 | 3.4 可精简 | 主体名称写真实姓名；联系方式用可长期持有的邮箱 |
| 企业项目 | 全部条款 | 无 | 主体名称写营业执照法定名称；法务审定后方可发布 |
| 开源项目 | 全部条款，尤其 3.6 | 无 | 保留与许可证的关系说明；不得缩减许可证授予的权利 |
| 闭源软件 | 3.1 / 3.2 / 3.3 / 3.4 / 3.5 / 3.7 | 3.6 第 2–4 段可删 | 删除开源许可证相关表述，改为引用最终用户许可协议 |
| 实验性原型 | 3.1 / 3.2 / 3.3 / 3.7 | 3.5 可精简 | 在内容性质中显式标注「原型」，避免被当作稳定版本 |
| 涉及个人信息处理 | 全部条款 | 无 | 增补数据处理角色、留存期限与主体权利渠道，另见 [安全与隐私规范](./安全与隐私规范.md) |

常见错误对照：

| 错误写法 | 后果 | 正确写法 |
| --- | --- | --- |
| 「本项目不承担任何责任」 | 表述绝对，易被认定无效 | 「在法律允许的最大范围内，不承担……」 |
| 「最终解释权归作者所有」 | 与许可证授权冲突，引发争议 | 「冲突时以许可证正文为准」 |
| 联系方式留 `test@example.com` | 不可达，失去沟通渠道 | 填写真实且长期有效的邮箱 |
| 照抄其他项目声明未改主体 | 主体错配，声明失去意义 | 逐个替换占位符并核对主体一致性 |
