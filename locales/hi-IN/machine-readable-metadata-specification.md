# मशीन-पठनीय मेटाडेटा विनिर्देश

> यह फ़ाइल कौन-सी समस्या हल करती है: एजेंट, Skill, MCP, कमांड लाइन आदि द्वारा प्रोग्रामेटिक रूप से उपभोग हेतु मेटाडेटा सूची की संरचना परिभाषित करना, ताकि मशीन द्वारा उपयोग स्थिर और खोजने योग्य बना रहे।

## 1. डिज़ाइन लक्ष्य

1. स्थिर पहचानकर्ता: प्रत्येक दस्तावेज़ का एक अद्वितीय और अपरिवर्तनीय पहचानकर्ता हो, जिसे प्रोग्राम संदर्भित कर सकें।
2. भाषा-निरपेक्ष: पहचानकर्ता भाषा के साथ नहीं बदलता, भाषा केवल पथ में प्रकट होती है।
3. खोजने योग्य: सूची में सभी दस्तावेज़ों का प्रकार, पथ, भाषा और सारांश सूचीबद्ध हों।

## 2. सूची की संरचना

मशीन सूची (manifest) में अवश्य शामिल हों:

| फ़ील्ड | आवश्यकता |
| --- | --- |
| id | स्थिर अद्वितीय पहचानकर्ता, लोअरकेस kebab-case, भाषा और संस्करण रहित |
| title | दस्तावेज़ का शीर्षक |
| summary | एक वाक्य में बताएँ कि कौन-सी समस्या हल होती है |
| domain | संबंधित क्षेत्र (सात प्रमुख क्षेत्रों में से एक) |
| paths | भाषा कोड से सापेक्ष पथ का मानचित्रण, जैसे `zh-CN`: `./locales/zh-CN/角色与职责.md` |
| version | विनिर्देश-संग्रह का संस्करण |

## 3. अनिवार्य नियम

1. नई भाषा जोड़ते समय केवल `paths` में मानचित्रण जोड़ें, `id` और अन्य भाषाओं के पथ न बदलें।
2. दस्तावेज़ का नाम बदलते समय `id` अपरिवर्तित रखें, केवल `paths` अद्यतन करें।
3. पहचानकर्ता और पथ वास्तविक फ़ाइलों से मेल खाने चाहिए, CI सूची की वैधता का सत्यापन करता है।
4. यह विनिर्देश प्रतिलिपि-योग्य सूची उदाहरण प्रदान करता है; लक्ष्य परियोजना को अनुभाग 2 के फ़ील्ड अनुसार वास्तविक सूची उदाहरण बनाना चाहिए और सुनिश्चित करना चाहिए कि `paths` डिस्क की फ़ाइलों से मेल खाते हों।

## 4. सूची उदाहरण (प्रतिलिपि-योग्य)

निम्नलिखित उदाहरण में तीन दस्तावेज़ प्रविष्टियाँ सूचीबद्ध हैं। वास्तविक सूची में लक्ष्य भाषा निर्देशिका के सभी विनिर्देश समाहित होने चाहिए; `id` भाषा के साथ नहीं बदलता, `paths` में भाषा कोड अनुसार मानचित्रण जोड़ा जाता है।

```json
{
  "version": "1.0.0",
  "entries": [
    {
      "id": "role-and-responsibility",
      "title": "角色与职责",
      "summary": "定义执行者身份、职责边界、触发条件、适用范围与硬性约束",
      "domain": "总纲与治理",
      "paths": {
        "zh-CN": "./locales/zh-CN/角色与职责.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "readme-standard-template",
      "title": "README标准模板",
      "summary": "提供可直接套用的通用 README 模板与占位符对照表",
      "domain": "命名与文档",
      "paths": {
        "zh-CN": "./locales/zh-CN/README标准模板.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "machine-readable-metadata",
      "title": "机器可读元数据规范",
      "summary": "定义供专家、Skill、MCP、命令行消费的元数据清单结构",
      "domain": "AI 与机器适配",
      "paths": {
        "zh-CN": "./locales/zh-CN/机器可读元数据规范.md"
      },
      "version": "1.0.0"
    }
  ]
}
```

नई भाषा जोड़ते समय केवल संबंधित प्रविष्टि के `paths` में मानचित्रण जोड़ें, जैसे `"en-US": "./locales/en-US/role-and-responsibility.md"` जोड़ना; `id` को संशोधित नहीं करना है।
