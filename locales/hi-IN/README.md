> यह फ़ाइल कौन-सी समस्या हल करती है: यह हिन्दी विनिर्देश-संग्रह का नेविगेशन है, जो सभी 68 विनिर्देशों का दायित्व, संबंधित क्षेत्र और पठन-पथ सूचीबद्ध करती है, ताकि आवश्यकता अनुसार उपयोग किया जा सके।

## पठन-पथ

- **चयन-क्षेत्र निर्धारित करें**: विनिर्देश चयन मार्गदर्शिका → जीवनचक्र मानचित्रण तालिका → संबंधित चरण की विनिर्देश फ़ाइलें।
- **पूरे जीवनचक्र में**: जीवनचक्र मानचित्रण तालिका → परियोजना प्रारंभ और आवश्यकता विनिर्देश → आवश्यकता अनुरेखण मैट्रिक्स विनिर्देश → संरचना डिज़ाइन दस्तावेज़ विनिर्देश → परीक्षण विनिर्देश → तैनाती और वापसी विनिर्देश → अवलोकनीयता विनिर्देश → पुनरावृत्ति पुनरावलोकन विनिर्देश।
- **त्वरित पुश**: पूर्ण नियम → गुणवत्ता द्वार → पुश और रिलीज़ विनिर्देश → समीक्षा रिपोर्ट प्रारूप।
- **शून्य से दस्तावेज़ बनाएँ**: भूमिकाएँ और दायित्व → निष्पादन प्रक्रिया → सूचना संग्रह और टेम्पलेट → दस्तावेज़ मैट्रिक्स → README अनुभाग विनिर्देश → ओपन-सोर्स अनुपालन विनिर्देश → गुणवत्ता द्वार।
- **README लिखें**: README टेम्पलेट अनुसंधान रिपोर्ट → README दृश्य संरचना विनिर्देश → बैज विनिर्देश → README श्रेणी-अनुकूलन मार्गदर्शिका → README मानक टेम्पलेट।
- **पूर्ण समीक्षा**: समीक्षा आयाम मैट्रिक्स → उप-एजेंट प्रेषण अनुबंध → पूर्ण नियम → गुणवत्ता द्वार → समीक्षा रिपोर्ट प्रारूप।
- **प्रोग्रामेटिक एकीकरण**: मशीन-पठनीय मेटाडेटा विनिर्देश → Skill लेखन विनिर्देश / MCP उपकरण विनिर्देश / एजेंट आह्वान और प्रॉम्प्ट विनिर्देश।
- **जोखिम और दायित्व-सीमा**: दायित्व-त्याग → दायित्व-त्याग टेम्पलेट → SECURITY टेम्पलेट → सुरक्षा और गोपनीयता विनिर्देश → ओपन-सोर्स अनुपालन विनिर्देश।
- **सामुदायिक शासन दस्तावेज़ बनाएँ**: योगदान मार्गदर्शिका टेम्पलेट → आचरण संहिता टेम्पलेट → SECURITY टेम्पलेट → दायित्व-त्याग टेम्पलेट।

## पारिभाषिक परिपाटियाँ

- **अवश्य / अवश्य नहीं**: अनिवार्य आवश्यकता।
- **चाहिए / नहीं चाहिए**: सिफ़ारिश या निषेध; विचलन का कारण बताना अनिवार्य है।
- **सकता है**: वैकल्पिक।
- **P0 / P1 / P2**: P0 पुश को अवरुद्ध करता है; P1 पुश से पहले सुधारना या अनिवार्य रूप से कार्य-सूची में दर्ज करना होता है; P2 सुझाया गया अनुकूलन।
