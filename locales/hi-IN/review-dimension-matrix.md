# समीक्षा आयाम मैट्रिक्स

> यह फ़ाइल कौन-सी समस्या हल करती है: Phase 2 की समानांतर समीक्षा के 14 आयाम, प्रत्येक के जाँच-बिंदु, सुझाए गए agent और विफलता स्तर परिभाषित करना, ताकि यह आवंटन और निर्णय का आधार बने।

## समीक्षा आयाम मैट्रिक्स

| # | आयाम | जाँच-बिंदु (कीवर्ड; विस्तृत विवरण उप-agent विस्तारित करेगा) | सुझाया गया agent | विफलता स्तर |
|---|---|---|---|---|
| D1 | सुरक्षा और गोपनीयता | कुंजी स्कैनिंग, `.env`, निजी कुंजियाँ, आंतरिक डोमेन/IP, व्यक्तिगत जानकारी, लॉग अवशेष | security-auditor | P0 |
| D2 | लाइसेंस और कानूनी | LICENSE की उपस्थिति और प्रकार, निर्भरता लाइसेंस संगतता, NOTICE, तृतीय-पक्ष घोषणाएँ | license-checker | P0 |
| D3 | भंडार स्वच्छता | .gitignore कवरेज, आर्टिफ़ैक्ट और निर्भरता निर्देशिकाएँ, .gitattributes, पंक्ति-अंत LF, निष्पादन योग्य बिट, फ़ाइल नाम केस टकराव | repo-hygienist | P0/P1 |
| D4 | आकार और बाइनरी | >50MB फ़ाइलें, छवि संपीड़न, LFS कॉन्फ़िगरेशन, इतिहास विस्तार | repo-hygienist | P1 |
| D5 | पुनरुत्पादनीय निर्माण | lockfile कमिट, इंजन संस्करण घोषणा, निर्माण स्क्रिप्ट, स्वच्छ वातावरण में निर्माण उत्तीर्ण | build-verifier | P0 |
| D6 | परीक्षण और स्थिर विश्लेषण | यूनिट परीक्षण उत्तीर्ण, कवरेज, lint, format, प्रकार जाँच | ci-runner | P0/P1 |
| D7 | कमिट इतिहास | Conventional Commits, परमाणुता, WIP रहित, लेखक जानकारी, संवेदनशील कमिट संदेश रहित | commit-reviewer | P1 |
| D8 | शाखा और रिलीज़ | main सुरक्षा, शाखा नामकरण, tag SemVer, annotated tag, Release Notes | release-manager | P1 |
| D9 | स्वचालन | CI वर्कफ़्लो चलने योग्य, स्थिति बैज, dependabot, CODEOWNERS, issue/PR टेम्पलेट | ci-runner | P1 |
| D10 | भंडार मेटाडेटा | description (`देश की भाषा \| अंग्रेज़ी` द्विभाषी संयुक्त प्रारूप, दोनों भाषाओं में प्रत्येक ≤120 अक्षर), topics (अधिकतम 20 भरें, केवल अंग्रेज़ी, पूर्णतः लोअरकेस), डिफ़ॉल्ट शाखा, About लिंक, social preview | metadata-agent | P1 |
| D11 | दस्तावेज़ीकरण की पूर्णता | दस्तावेज़ मैट्रिक्स की मद-दर-मद उपस्थिति जाँच | docs-orchestrator | P0/P1 |
| D12 | दस्तावेज़ीकरण की गुणवत्ता | शीर्षक पदानुक्रम, कोड ब्लॉक भाषा टैग, लिंक वैधता, छवि alt, चीनी-अंग्रेज़ी रिक्ति, प्लेसहोल्डर रहित | docs-orchestrator | P1/P2 |
| D13 | README मुखपृष्ठ | एक-वाक्य स्थिति, इंस्टॉलेशन, त्वरित प्रारंभ, बैज ≤4, स्क्रीनशॉट, स्थानीय निरपेक्ष पथ रहित | readme-writer | P1 |
| D14 | सामुदायिक शासन | CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, Issue टेम्पलेट, सहायता चैनल | docs-orchestrator | P2 |

## स्तरों का अर्थ

- **P0**: पुश को अवरुद्ध करता है।
- **P1**: पुश से पहले सुधारना चाहिए या अनिवार्य रूप से कार्य-सूची में दर्ज करना होगा।
- **P2**: अनुकूलन का सुझाव है।

## आवंटन और संकलन

- प्रत्येक आयाम की आवंटन विधि देखें [उप-agent आवंटन अनुबंध](./sub-agent-dispatch-contract.md)।
- निर्णय परिणाम [समीक्षा रिपोर्ट प्रारूप](./audit-report-format.md) की समस्या-सूची में संकलित किए जाएँ; प्रत्येक मद के साथ प्रमाण अवश्य हो।
- D11/D12 के सत्यापन का आधार देखें [दस्तावेज़ मैट्रिक्स](./document-matrix.md) और [गुणवत्ता द्वार](./quality-gate.md)।

## संबंधित फ़ाइलें

- द्वार पार करने की शर्तें देखें [गुणवत्ता द्वार](./quality-gate.md)
