# README अनुभाग विनिर्देश

> यह फ़ाइल कौन-सी समस्या हल करती है: प्रत्येक भाषा निर्देशिका के README में अनिवार्य 20 अनुभाग, प्रत्येक अनुभाग में क्या शामिल होना चाहिए तथा क्या नहीं होना चाहिए, और कॉपीराइट पंक्ति का मानक प्रारूप परिभाषित करना।

## 1.1 प्रथम पृष्ठ के चार प्रश्न और एक-पंक्ति पाठ

README की पहली स्क्रीन को चार प्रश्नों का उत्तर देना चाहिए, क्रम निश्चित है:

1. परियोजना क्या करती है;
2. परियोजना कौन-सी समस्या हल करती है;
3. परियोजना में कौन-सी विशेषताएँ हैं;
4. न्यूनतम hello world उदाहरण।

जिसमें प्रश्न 1 “एक-पंक्ति स्थिति” के अनुरूप है, तथा उसे एक साथ तीन बातें पूरी करनी चाहिए: परियोजना का प्रकार स्पष्ट करे, विशेषक सटीक हो, और सीधे दोहराया जा सके। परिपक्व परियोजनाओं के सार्वजनिक पाठ संदर्भ के रूप में लिए जा सकते हैं:

| परियोजना | एक-पंक्ति पाठ | संरचना विश्लेषण |
| --- | --- | --- |
| Angular | One framework. Mobile & desktop. | श्रेणी + कवरेज |
| React | A declarative, efficient, and flexible JavaScript library for building user interfaces. | तीन विशेषक + श्रेणी + उपयोग |
| Vue | A progressive, incrementally-adoptable JavaScript framework for building UI on the web. | दो विशेषताएँ + श्रेणी + उपयोग |

लेखन बाध्यताएँ:

- “शक्तिशाली”, “उत्कृष्ट”, “क्रांतिकारी” जैसे सूचना-रहित विशेषणों का प्रयोग न करें;
- श्रेणी शब्द (लाइब्रेरी, फ़्रेमवर्क, टूल, एप्लिकेशन) अवश्य दें, ताकि पाठक एक नज़र में वर्गीकृत कर सके;
- विशेषक विशेषण तीन से अधिक न हों, ढेर लगाने से बचें;
- चीनी संस्करण 60 अक्षरों के भीतर, अंग्रेज़ी संस्करण 25 शब्दों के भीतर रखना चाहिए।

प्रश्न 3 “कौन-सी विशेषताएँ हैं” के साथ अनुपयुक्त परिदृश्य भी प्रकट करने चाहिए। प्रभावी लेखन का उदाहरण: किसी संदेश मिडलवेयर को “केवल QoS स्तर 0 का समर्थन करता है, स्तर 1 आवश्यक होने वाले परिदृश्यों के लिए अनुपयुक्त है” बताना; अप्रभावी लेखन केवल गुणों की सूची देना है। विशेषता तुलना सत्यापन-योग्य तथ्यों पर आधारित होनी चाहिए, तथा समान परियोजनाओं का अपमान नहीं किया जा सकता।

प्रश्न 4 के hello world उदाहरण में स्थापना और चलाना दो चरणों के भीतर पूरा होना चाहिए; जिन परियोजनाओं के स्थापना चरण जटिल हैं, उन्हें कंटेनर इमेज या ऑनलाइन डेमो परिवेश देना चाहिए, ताकि पाठक README पूरा पढ़कर हार न मानें।
