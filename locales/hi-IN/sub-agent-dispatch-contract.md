# उप-एजेंट प्रेषण अनुबंध

> यह फ़ाइल कौन-सी समस्या हल करती है: उप-एजेंट को कार्य प्रेषित करते समय अनिवार्य रूप से स्पष्ट लिखे जाने वाले चार तत्वों और सहयोग-बाध्यताओं को परिभाषित करती है, ताकि निष्कर्ष संरचित, सत्यापन-योग्य और नियम-विचलन से मुक्त रहें।

## 1. प्रेषण के चार तत्व

प्रत्येक प्रेषण में चार तत्व स्पष्ट रूप से लिखे जाने चाहिए:

```text
TASK:    <एक वाक्य में कार्य>
INPUT:   <आवश्यक फ़ाइलें/संदर्भ, केवल अनिवार्य भाग>
OUTPUT:  <संरचित प्रारूप, तालिका या JSON, गद्य निषिद्ध>
FAIL:    <न कर पाने पर क्या लौटाएँ, मनगढ़ंत उत्तर के बजाय>
```

## 2. बाध्यताएँ

- एक उप-एजेंट एक बार में केवल एक ही कार्य करता है; «साथ ही README भी लिख दें» निषिद्ध है।
- उप-एजेंट केवल पढ़ सकता है और केवल प्रस्ताव दे सकता है; **फ़ाइल लेखन तथा git संचालन एकरूपता से मुख्य नियंत्रक द्वारा किए जाते हैं**।
- उप-एजेंट के निष्कर्ष के साथ प्रमाण होना अनिवार्य है (फ़ाइल पथ + पंक्ति संख्या / कमांड आउटपुट); प्रमाण-रहित निष्कर्ष अमान्य माने जाते हैं।
- उप-एजेंट आपस में सीधे संवाद नहीं करते; सब कुछ मुख्य नियंत्रक के माध्यम से संकलित होता है, जिससे नियम-विचलन टलता है।
