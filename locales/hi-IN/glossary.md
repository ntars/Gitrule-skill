# शब्दावली सूची

> यह फ़ाइल कौन-सी समस्या हल करती है: परियोजना के पूरे पाठ में प्रयुक्त तकनीकी पदों और संक्षेपणों को केंद्रीय रूप से परिभाषित करना, ताकि चीनी और अंग्रेज़ी संस्करणों के पद एक-दूसरे से मेल खाएँ और पूरे पाठ में एकरूपता बनी रहे।

## 1. रखरखाव नियम

1. पद के पहली बार आने पर उसकी परिभाषा देनी चाहिए, प्रारूप “चीनी पद (English Term, संक्षेपण)” है।
2. एक ही अवधारणा के लिए पूरे पाठ में केवल एक ही अभिव्यक्ति प्रयोग करें; चीनी और अंग्रेज़ी संस्करणों के पद एक-दूसरे से मेल खाएँ और यही सूची साझा करें।
3. नया पद जोड़ने पर उसे इस सूची में तथा अंग्रेज़ी संस्करण के संगत स्थान पर भी अवश्य लिखें।
4. संक्षेपण के पहली बार आने पर उसका पूर्ण रूप अवश्य लिखें, उसके बाद सीधे संक्षेपण का प्रयोग किया जा सकता है।

## 2. पद-सूची तालिका

| चीनी | अंग्रेज़ी | संक्षेपण | विवरण |
| --- | --- | --- | --- |
| 软件物料清单 | Software Bill of Materials | SBOM | परियोजना की निर्भरताओं और घटकों की पूर्ण सूची |
| 语义化版本 | Semantic Versioning | SemVer | संस्करण संख्या का प्रारूप `MAJOR.MINOR.PATCH` |
| 架构决策记录 | Architecture Decision Record | ADR | महत्वपूर्ण संरचना निर्णयों तथा उनकी पृष्ठभूमि और परिणामों का अभिलेखन |
| 行为准则 | Code of Conduct | CoC | समुदाय के सहभागियों के आचरण के नियम |
| 持续集成 / 持续交付 | Continuous Integration / Continuous Delivery | CI/CD | स्वचालित निर्माण, परीक्षण और परिदान की प्रक्रिया |
| 软件许可证标识符 | Software Package Data Exchange | SPDX | लाइसेंस के मानक पहचानकर्ताओं की प्रणाली |
| 最小可行产品 | Minimum Viable Product | MVP | मुख्य परिकल्पना को सत्यापित करने योग्य न्यूनतम संस्करण |
| 自然语言处理器 | Natural Language Processing | NLP | पाठ प्रसंस्करण से संबंधित तकनीकें |
| 大模型 | Large Language Model | LLM | बड़े पैमाने पर पूर्व-प्रशिक्षित भाषा मॉडल |
| 模型上下文协议 | Model Context Protocol | MCP | मॉडल को बाहरी उपकरणों से जोड़ने वाला प्रोटोकॉल |
| 待补充 | To Be Determined | TBD | वह प्लेसहोल्डर चिह्न जिसकी जानकारी अभी पुष्टि नहीं हुई |

> सूची की प्रविष्टियाँ सामान्य उदाहरण हैं; उपयोग से पहले परियोजना के वास्तविक पदों के अनुसार उन्हें जोड़ें या हटाएँ।
