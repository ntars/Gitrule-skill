## Reading Paths

- **Determining the selection scope**: Specification Selection Guide → Lifecycle Mapping Table → the specification files for the corresponding phase.
- **Throughout the lifecycle**: Lifecycle Mapping Table → Project Initiation and Requirements Specification → Requirements Traceability Matrix Specification → Architecture Design Document Specification → Testing Specification → Deployment and Rollback Specification → Observability Specification → Iteration Retrospective Specification.
- **Quick push**: Hard Rules → Quality Gates → Push and Release Specification → Audit Report Format.
- **Generating documents from scratch**: Roles and Responsibilities → Execution Process → Information Collection and Templates → Document Matrix → README Sections Specification → Open Source Compliance Specification → Quality Gates.
- **Writing a README**: README Template Research Report → README Visual Layout Specification → Badge Specification → README Category Adaptation Guide → README Standard Template.
- **Full audit**: Audit Dimension Matrix → Sub-Agent Dispatch Contract → Hard Rules → Quality Gates → Audit Report Format.
- **Programmatic integration**: Machine-Readable Metadata Specification → Skill Authoring Specification / MCP Tool Specification / Agent Invocation and Prompt Specification.
- **Risk and liability boundaries**: Disclaimer → Disclaimer Template → SECURITY Template → Security and Privacy Specification → Open Source Compliance Specification.
- **Generating community governance files**: Contribution Guide Template → Code of Conduct Template → SECURITY Template → Disclaimer Template.

## Terminology Conventions

- **Must / Must not**: Mandatory requirement.
- **Should / Should not**: Recommended or prohibited; a deviation must be justified.
- **May**: Optional.
- **P0 / P1 / P2**: P0 blocks push; P1 must be fixed before push or registered as a to-do; P2 is a suggested optimization.
