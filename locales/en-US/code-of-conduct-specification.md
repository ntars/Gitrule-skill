# Code of Conduct Specification

> What this file solves: Defines the standard structure and enforcement mechanism of a community code of conduct, serving as the writing basis for CODE_OF_CONDUCT.md.

## 1. Standard Structure

The code of conduct must contain the following sections:

1. **Our pledge**: Foster an open, friendly, and harassment-free participation environment.
2. **Scope**: Project spaces, issues, pull requests, social channels, and occasions where individuals appear in a project-representative capacity.
3. **Expected behavior**: Respect differing viewpoints, communicate in good faith, accept constructive feedback, and focus on the overall interests of the community.
4. **Unacceptable behavior**: Personal attacks, discriminatory speech, harassment, disclosing others' privacy, and posting inappropriate content.
5. **Enforcement responsibilities**: Maintainers are responsible for clarification and adjudication, and have the authority to delete, edit, or reject content that does not conform to the code.
6. **Enforcement measures within scope**: Graded handling from warning to temporary ban up to permanent ban.
7. **Reporting channel**: Provide contact information that reaches maintainers directly and pledge confidentiality of reporter information.
8. **Attribution and source**: When adopting or adapting from a known code, the source and license must be indicated (see [Open Source Compliance Specification](./open-source-compliance-specification.md)).

## 2. Writing Requirements

1. Use formal written language with no technical content (corresponds to the boundary in [Document Matrix](./document-matrix.md)).
2. The reporting channel must be a real, reachable address; do not leave placeholders.
3. When using a general code template, declare its version and source.
