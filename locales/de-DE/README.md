## Lesepfade

- **Anwendungsbereich festlegen**: Leitfaden zur Spezifikationsauswahl → Lebenszyklus-Zuordnungstabelle → Spezifikationsdateien der jeweiligen Phase.
- **Über den gesamten Lebenszyklus**: Lebenszyklus-Zuordnungstabelle → Projektstart- und Anforderungsspezifikation → Spezifikation für die Anforderungs-Verfolgungsmatrix → Spezifikation für Architekturdokumentation → Test-Spezifikation → Bereitstellungs- und Rollback-Spezifikation → Observability-Spezifikation → Iterationsretrospektiven-Spezifikation.
- **Schneller Push**: Harte Regeln → Qualitätstor → Push- und Veröffentlichungsspezifikation → Review-Berichtsformat.
- **Dokumentation von Grund auf erstellen**: Rollen und Verantwortlichkeiten → Ausführungsprozess → Informationserhebung und Vorlagen → Dokumentationsmatrix → README-Abschnittsspezifikation → Open-Source-Konformitätsspezifikation → Qualitätstor.
- **README verfassen**: README-Vorlagen-Recherchebericht → README-Spezifikation für visuelles Layout → Badge-Spezifikation → README-Leitfaden zur Kategorieanpassung → README-Standardvorlage.
- **Vollständiges Review**: Review-Dimensionsmatrix → Sub-Agent-Dispositionsvertrag → Harte Regeln → Qualitätstor → Review-Berichtsformat.
- **Programmatische Anbindung**: Spezifikation für maschinenlesbare Metadaten → Skill-Erstellungsspezifikation / MCP-Werkzeugspezifikation / Agent-Aufruf- und Prompt-Spezifikation.
- **Risiko- und Verantwortungsgrenzen**: Haftungsausschluss → Haftungsausschluss-Vorlage → SECURITY-Vorlage → Sicherheits- und Datenschutzspezifikation → Open-Source-Konformitätsspezifikation.
- **Dateien der Community-Governance erstellen**: Beitragsleitfaden-Vorlage → Verhaltenskodex-Vorlage → SECURITY-Vorlage → Haftungsausschluss-Vorlage.

## Sprachliche Konventionen

- **muss / darf nicht**: verbindliche Anforderung.
- **sollte / sollte nicht**: Empfehlung oder Verbot; bei Abweichung ist eine Begründung erforderlich.
- **kann**: optional.
- **P0 / P1 / P2**: P0 blockiert den Push; P1 ist vor dem Push zu beheben oder zwingend als Aufgabe zu erfassen; P2 ist eine empfohlene Optimierung.
