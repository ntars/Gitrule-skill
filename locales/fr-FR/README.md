## Parcours de lecture

- **Déterminer le périmètre retenu** : Guide de sélection des spécifications → Matrice de correspondance du cycle de vie → fichiers de spécification de la phase correspondante.
- **Tout au long du cycle de vie** : Matrice de correspondance du cycle de vie → Spécification du lancement de projet et des exigences → Spécification de la matrice de traçabilité des exigences → Spécification des documents de conception d'architecture → Spécification des tests → Spécification du déploiement et de la restauration → Spécification d'observabilité → Spécification de la rétrospective d'itération.
- **Push rapide** : Règles absolues → Porte qualité → Spécification du push et de la publication → Format du rapport d'audit.
- **Générer la documentation de zéro** : Rôles et responsabilités → Processus d'exécution → Collecte d'informations et gabarits → Matrice documentaire → Spécification des sections du README → Spécification de conformité open source → Porte qualité.
- **Rédiger un README** : Rapport d'étude sur les gabarits de README → Spécification de mise en page visuelle du README → Spécification des badges → Guide d'adaptation du README par catégorie → Gabarit standard de README.
- **Audit complet** : Matrice des dimensions d'audit → Contrat de dispatch des sous-agents → Règles absolues → Porte qualité → Format du rapport d'audit.
- **Intégration programmatique** : Spécification des métadonnées lisibles par machine → Spécification de rédaction des Skills / Spécification des outils MCP / Spécification de l'invocation d'agent et des invites.
- **Limites de risque et de responsabilité** : Clause de non-responsabilité → Gabarit de clause de non-responsabilité → Gabarit SECURITY → Spécification de sécurité et de confidentialité → Spécification de conformité open source.
- **Générer les fichiers de gouvernance communautaire** : Gabarit de guide de contribution → Gabarit de code de conduite → Gabarit SECURITY → Gabarit de clause de non-responsabilité.

## Conventions terminologiques

- **Doit / ne doit pas** : exigence impérative.
- **Devrait / ne devrait pas** : recommandation ou interdiction ; tout écart doit être justifié.
- **Peut** : facultatif.
- **P0 / P1 / P2** : P0 bloque le push ; P1 doit être corrigé avant le push ou consigné comme tâche à traiter ; P2 est une optimisation suggérée.
