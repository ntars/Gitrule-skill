## مسارات القراءة

- **تحديد نطاق الاختيار**: دليل اختيار المواصفات ← جدول مطابقة دورة الحياة ← ملفات المواصفات الخاصة بالمرحلة المقابلة.
- **عبر دورة الحياة كاملة**: جدول مطابقة دورة الحياة ← مواصفة انطلاق المشروع والمتطلبات ← مواصفة مصفوفة تتبع المتطلبات ← مواصفة وثيقة تصميم المعمارية ← مواصفة الاختبارات ← مواصفة النشر والتراجع ← مواصفة قابلية الرصد ← مواصفة المراجعة الاسترجاعية للدورة.
- **الدفع السريع**: القواعد المطلقة ← بوابة الجودة ← مواصفة الدفع والإصدار ← صيغة تقرير المراجعة.
- **توليد الوثائق من الصفر**: الأدوار والمسؤوليات ← مسار التنفيذ ← جمع المعلومات والقوالب ← مصفوفة الوثائق ← مواصفة أقسام README ← مواصفة الامتثال للمصادر المفتوحة ← بوابة الجودة.
- **كتابة README**: تقرير بحث قوالب README ← مواصفة التنسيق البصري لـ README ← مواصفة الشارات ← دليل تكييف README حسب الفئة ← القالب القياسي لـ README.
- **المراجعة الكاملة**: مصفوفة أبعاد المراجعة ← عقد إسناد الوكيل الفرعي ← القواعد المطلقة ← بوابة الجودة ← صيغة تقرير المراجعة.
- **التكامل البرمجي**: مواصفة البيانات الوصفية القابلة للقراءة آلياً ← مواصفة كتابة Skill / مواصفة أدوات MCP / مواصفة استدعاء الوكيل والصياغة التوجيهية.
- **حدود المخاطر والمسؤولية**: إخلاء المسؤولية ← قالب إخلاء المسؤولية ← قالب SECURITY ← مواصفة الأمان والخصوصية ← مواصفة الامتثال للمصادر المفتوحة.
- **توليد وثائق حوكمة المجتمع**: قالب دليل المساهمة ← قالب مدونة السلوك ← قالب SECURITY ← قالب إخلاء المسؤولية.

## اتفاقيات الصياغة

- **يجب / لا يجوز**: متطلب إلزامي.
- **ينبغي / لا ينبغي**: توصية أو نهي، ويجب تبرير أي انحراف عنهما.
- **يجوز**: اختياري.
- **P0 / P1 / P2**: P0 يوقف الدفع؛ P1 يجب إصلاحه قبل الدفع أو تسجيله إلزامياً كمهمة معلقة؛ P2 تحسين مقترح.
