## 1.1 الأسئلة الأربعة للصفحة الأولى والنص في جملة واحدة

يجب أن تجيب الشاشة الأولى من README عن أربعة أسئلة، بترتيب ثابت:

1. ماذا يفعل المشروع؛
2. أي مشكلة يحل المشروع؛
3. ما ميزات المشروع؛
4. أصغر مثال hello world.

السؤال 1 يقابل «تحديد الموقع في جملة واحدة»، ويجب أن يستوفي ثلاثة شروط معاً: بيان نوع المشروع، ودقة المحدِّدات، وقابلية النص لإعادة التلاوة مباشرةً. ويمكن الاستئناس بالنصوص المعلنة لمشاريع ناضجة:

| المشروع | النص في جملة واحدة | تحليل البنية |
| --- | --- | --- |
| Angular | One framework. Mobile & desktop. | الفئة + نطاق التغطية |
| React | A declarative, efficient, and flexible JavaScript library for building user interfaces. | ثلاثة محدِّدات + الفئة + الغرض |
| Vue | A progressive, incrementally-adoptable JavaScript framework for building UI on the web. | خاصيتان + الفئة + الغرض |

قيود الكتابة:

- يُمنع استخدام نعوت بلا معلومات مثل «قوي» و«متميّز» و«ثوري»؛
- يجب ذكر كلمة الفئة (مكتبة، إطار، أداة، تطبيق) ليصنّف القارئ المشروع من أول نظرة؛
- لا تتجاوز المحددات ثلاثة، تجنباً للتكديس؛
- يجب أن تبقى النسخة العربية في حدود 60 كلمة، والإنجليزية في حدود 25 كلمة.

السؤال 3 «ما الميزات» يجب أن يكشف أيضاً سيناريوهات عدم الملاءمة. ومن الكتابة الفعّالة: بيان أن برمجية وسيطة للرسائل «تدعم مستوى QoS 0 فقط، والسيناريوهات التي تحتاج المستوى 1 غير ملائمة»؛ والكتابة غير الفعّالة هي سرد المزايا وحدها. ويجب أن تستند مقارنة الميزات إلى وقائع قابلة للتحقق، دون ازدراء مشاريع مماثلة.

يجب أن يُنجَز تثبيت مثال hello world في السؤال 4 وتشغيله في خطوتين؛ والمشاريع التي تتشعب خطوات تثبيتها ينبغي أن توفر صورة حاوية أو بيئة عرض تجريبية عبر الإنترنت، تفادياً لتخلّي القارئ عن المشروع بعد قراءة README.
