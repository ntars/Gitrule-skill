# معجم المصطلحات

> المشكلة التي يحلها هذا الملف: تعريف المصطلحات المهنية والاختصارات المستخدمة في المشروع بأكمله تعريفًا مركزيًا، بما يضمن التقابل الواحد لواحد بين مصطلحات النسختين الصينية والإنجليزية واتساق الصياغة في النص كله.

## 1. قواعد الصيانة

1. يجب إيراد تعريف المصطلح عند ظهوره الأول، بصيغة «المصطلح الصيني (English Term، الاختصار)».
2. يُستخدم للمفهوم الواحد تعبير واحد في النص كله؛ وتتقابل مصطلحات النسختين الصينية والإنجليزية تقابلًا واحدًا لواحد، وتشترك في هذا الجدول.
3. يجب إدراج المصطلح الجديد في هذا الجدول في الوقت نفسه، ومزامنته مع الموضع المقابل في النسخة الإنجليزية.
4. يجب عند ظهور الاختصار الأول إيراد اسمه الكامل، ويجوز بعد ذلك استخدام الاختصار مباشرة.

## 2. جدول مقابلة المصطلحات

| 中文 | English | الاختصار | الوصف |
| --- | --- | --- | --- |
| 软件物料清单 | Software Bill of Materials | SBOM | قائمة كاملة بتبعيات المشروع ومكوّناته |
| 语义化版本 | Semantic Versioning | SemVer | صيغة رقم الإصدار `MAJOR.MINOR.PATCH` |
| 架构决策记录 | Architecture Decision Record | ADR | توثيق قرارات المعمارية المهمة وخلفياتها ونتائجها |
| 行为准则 | Code of Conduct | CoC | قواعد سلوك المشاركين في المجتمع |
| 持续集成 / 持续交付 | Continuous Integration / Continuous Delivery | CI/CD | مسار آلي للبناء والاختبارات والتسليم |
| 软件许可证标识符 | Software Package Data Exchange | SPDX | منظومة معرّفات قياسية للرخص |
| 最小可行产品 | Minimum Viable Product | MVP | أدنى إصدار يسمح بالتحقق من الفرضية الأساسية |
| 自然语言处理器 | Natural Language Processing | NLP | تقنيات معالجة النصوص |
| 大模型 | Large Language Model | LLM | نموذج لغوي كبير مدرَّب مسبقًا على نطاق واسع |
| 模型上下文协议 | Model Context Protocol | MCP | بروتوكول يربط النماذج بالأدوات الخارجية |
| 待补充 | To Be Determined | TBD | علامة عنصر نائب لم تُؤكَّد معلوماتها بعد |

> البنود الواردة في الجدول أمثلة عامة، ويجب إضافة ما يلزم منها أو حذفه وفق مصطلحات المشروع الفعلية قبل الاستخدام.

## ملفات ذات صلة

- تُرجع متطلبات اتساق المصطلحات إلى [مواصفة الكتابة العامة](./general-writing-specification.md)
- تُرجع قواعد الاستخدام المشترك للمصطلحات ثنائية اللغة إلى [مواصفة تعدد اللغات](./multilingual-specification.md)
- يُرجع قالب جدول المقابلة إلى [جمع المعلومات والقوالب](./information-collection-and-templates.md)
