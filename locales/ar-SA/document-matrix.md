# مصفوفة الوثائق

> المشكلة التي يحلها هذا الملف: يحدد المسؤولية الوحيدة لكل وثيقة تُسلَّم، والمحتوى الممنوع فيها منعاً باتاً، وقيود التقسيم، بما يضمن مبدأ «ملف واحد مسؤولية واحدة» ومنع الدمج.

## 1. الملفات والمسؤوليات

| الملف | المسؤولية الوحيدة | ممنوع منعاً باتاً |
|---|---|---|
| `README.md` | الصفحة الرئيسية: ما هذا، وكيف يُثبَّت، وكيف يعمل، وأين تُطلب التفاصيل | API كامل، مسار المساهمة، سجل التحديثات |
| `LICENSE` | النص الكامل للرخصة | أي نص توضيحي |
| `CHANGELOG.md` | تغيرات الإصدارات الموجهة للمستخدم | تفاصيل إعادة الهيكلة الداخلية، خطط التطوير |
| `CONTRIBUTING.md` | مسار المساهمين الخارجيين وإطارهم التنظيمي | شرح وظائف المشروع |
| `CODE_OF_CONDUCT.md` | مدونة السلوك | محتوى تقني |
| `SECURITY.md` | قناة الإبلاغ عن الثغرات واستراتيجية الاستجابة | قائمة الثغرات المعروفة |
| `docs/api.md` | مرجع API الكامل | دروس تعليمية |
| `docs/architecture.md` | المعمارية وحدود الوحدات | أمثلة استخدام |
| `docs/naming.md` | إطار التسمية | مواصفات أخرى |
| `docs/release.md` | مسار الإصدار واستراتيجية الإصدارات | سجلات التغييرات |
| `.github/PULL_REQUEST_TEMPLATE.md` | قائمة الفحص الذاتي لطلب السحب | تعريف المشروع |
| `.github/ISSUE_TEMPLATE/*.yml` | نماذج issue منظمة | نص حر |
| `.github/workflows/*.yml` | CI/CD | وثائق توضيحية |

> توضيح: نص مواصفة `docs/naming.md` في [مواصفة تسمية المشاريع](./project-naming-specification.md)؛ ونص مواصفة `docs/release.md` في [مواصفة الدفع والإصدار](./push-and-release-specification.md).

## 2. القيود

- الملف الذي يتجاوز 300 سطر يجب تقسيمه إلى `docs/`، ولا يبقى في README سوى ملخص + رابط.
- أسماء الملفات ثابتة بأحرف كبيرة، والمسارات ثابتة، ولا يجوز ابتداع مستويات مجلدات.
- تبدأ كل وثيقة بجملة واحدة توضح «المشكلة التي يحلها هذا الملف»، وتنتهي بروابط متقاطعة إلى الملفات ذات الصلة.

## ملفات ذات صلة

- بنية README من 20 قسماً في [مواصفة أقسام README](./readme-sections-specification.md)
- المواصفة المستقلة لـ NOTICE في [مواصفة NOTICE](./notice-specification.md)
- المواصفة المستقلة لـ LICENSE في [مواصفة LICENSE](./license-specification.md)
- اكتمال الوثائق وجودتها يندرجان تحت البُعدين D11/D12، انظر [مصفوفة أبعاد المراجعة](./review-dimension-matrix.md)
