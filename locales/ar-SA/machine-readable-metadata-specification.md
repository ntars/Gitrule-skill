# مواصفة البيانات الوصفية القابلة للقراءة آلياً

> المشكلة التي يحلها هذا الملف: تحديد بنية قائمة البيانات الوصفية التي تستهلكها البرامج مثل الخبراء وSkill وMCP وسطر الأوامر، بما يضمن استقرار الاستدعاء الآلي وقابلية الاكتشاف.

## 1. أهداف التصميم

1. معرّف مستقر: لكل وثيقة معرّف فريد لا يتغير، تستخدمه البرامج للإحالة إليها.
2. استقلال عن اللغة: لا يتغير المعرّف بتغير اللغة، ولا تظهر اللغة إلا في المسار.
3. قابلية الاكتشاف: تسرد القائمة نوع كل وثيقة ومسارها ولغتها وملخصها.

## 2. بنية القائمة

يجب أن تتضمن قائمة البيانات الوصفية (manifest) ما يلي:

| الحقل | المتطلب |
| --- | --- |
| id | معرّف فريد مستقر، بأحرف لاتينية صغيرة بنمط kebab-case، لا يتضمن اللغة ولا الإصدار |
| title | عنوان الوثيقة |
| summary | جملة واحدة توضح المشكلة التي يحلها |
| domain | المجال التابع له (أحد المجالات السبعة) |
| paths | تعيين رمز اللغة إلى المسار النسبي، مثل `zh-CN`: `./locales/zh-CN/角色与职责.md` |
| version | إصدار مجموعة المواصفات |

## 3. قواعد إلزامية

1. عند إضافة لغة جديدة تُضاف التعيينات في `paths` فقط، دون تغيير `id` أو مسارات اللغات الأخرى.
2. عند إعادة تسمية وثيقة يجب الإبقاء على `id` دون تغيير، ويُحدَّث `paths` فقط.
3. يجب أن يتطابق المعرّف والمسار مع الملف الفعلي، ويتحقق CI من صلاحية القائمة.
4. توفر هذه المواصفة نموذج قائمة قابلًا للنسخ؛ وينبغي أن ينشئ المشروع المستهدف نسخة قائمة فعلية وفق حقول القسم 2، مع ضمان تطابق `paths` مع الملفات على القرص.

## 4. نموذج القائمة (قابل للنسخ)

يسرد النموذج التالي ثلاثة بنود وثائق. يجب أن تغطي القائمة الفعلية جميع مواصفات دليل اللغة المستهدف؛ ولا يتغير `id` بتغير اللغة، وتُضاف التعيينات في `paths` حسب رمز اللغة.

```json
{
  "version": "1.0.0",
  "entries": [
    {
      "id": "role-and-responsibility",
      "title": "角色与职责",
      "summary": "定义执行者身份、职责边界、触发条件、适用范围与硬性约束",
      "domain": "总纲与治理",
      "paths": {
        "zh-CN": "./locales/zh-CN/角色与职责.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "readme-standard-template",
      "title": "README标准模板",
      "summary": "提供可直接套用的通用 README 模板与占位符对照表",
      "domain": "命名与文档",
      "paths": {
        "zh-CN": "./locales/zh-CN/README标准模板.md"
      },
      "version": "1.0.0"
    },
    {
      "id": "machine-readable-metadata",
      "title": "机器可读元数据规范",
      "summary": "定义供专家、Skill、MCP、命令行消费的元数据清单结构",
      "domain": "AI 与机器适配",
      "paths": {
        "zh-CN": "./locales/zh-CN/机器可读元数据规范.md"
      },
      "version": "1.0.0"
    }
  ]
}
```

عند إضافة لغة جديدة، تُضاف التعيينات في `paths` للبند المقابل فقط، مثل إضافة `"en-US": "./locales/en-US/role-and-responsibility.md"`؛ ولا يجوز تعديل `id`.
