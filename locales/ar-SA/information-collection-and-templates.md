# جمع المعلومات والقوالب

> المشكلة التي يحلها هذا الملف: يحدد حقول معلومات المشروع التي يجب جمعها قبل كتابة الوثائق، وقواعد وسم المعلومات غير المؤكدة، ويوفر فهرس العناصر النائبة وقالب مقابلة المصطلحات وقالب قائمة التبعيات ونص جمع معلومات المشروع القابل للنسخ المباشر.

## 1. الحقول الإلزامية (النقص فيها مانع)

| الحقل | الوصف | القسم المتأثر |
| --- | --- | --- |

| التوصيف في جملة واحدة | بما لا يتجاوز 60 حرفاً، ويوضح ما هو المشروع ولمن يحل أي مشكلة | القسم 1 |
| وصف المستودع (اللغة الوطنية والإنجليزية) | بما لا يتجاوز 120 حرفاً لكل لغة، ويوضح كل منهما نوع المشروع واستخدامه الأساسي | القسم 1 |
| وسوم المواضيع | 20 كلمة إنجليزية بأحرف صغيرة موصولة بـ `-`؛ ويُعدّ الخلط بين حالة الأحرف أو غير الإنجليزية نقصاً | القسم 1 |

## 2. الحقول الاختيارية

قائمة بنود الإعداد، وتعريف API، وبنية المجلدات، وبيانات اختبار الأداء، ومصفوفة التوافق، والمشكلات المعروفة، وسجل التحديثات، وخطة التطوير، ومسار المساهمة، وسياسة الأمان، ولقطات الشاشة وعنوان العرض التوضيحي، ومصادر المواد الخارجية.

## 3. تعليمات تعبئة الحقول والأمثلة

| الحقل | تعليمات التعبئة | مثال |
| --- | --- | --- |
| اسم المشروع | يستخدم اسم المستودع أحرفاً صغيرة وأرقاماً و`-`؛ ويجوز أن يأتي الاسم المعروض بصيغة علامة تجارية، مع بيان السبب عند عدم التطابق | اسم المستودع `markdown-lint-cli`، والاسم المعروض `Markdown Lint CLI` |
| التوصيف في جملة واحدة | يتضمن كلمة الفئة وكلمة التحديد، دون حشد الصفات، وبما لا يتجاوز 60 حرفاً | `أداة سطر أوامر لفحص وثائق Markdown وفق المواصفة، موجهة إلى فرق التوثيق التقني` |
| وصف المستودع (اللغة الوطنية والإنجليزية) | جملة مستقلة لكل من اللغة الوطنية والإنجليزية، بما لا يتجاوز 120 حرفاً لكل منهما، ولا يُستبدل الوصف بشعار | `الصينية: أداة سطر أوامر لفحص بنية وثائق Markdown` / `English: A CLI tool for checking Markdown document structure` |
| وسوم المواضيع | جميعها إنجليزية بأحرف صغيرة، موصولة بـ `-`، بعدد 20 وسمًا كاملًا، تغطي اللغة والشكل والاستخدام والمنظومة والسياق تغطية كاملة | `go cli markdown linter developer-tools` |
| المكدس التقني | تُذكر اللغة الرئيسية وإطار العمل وقيود إصدار بيئة التشغيل، ولا يُكتب «أحدث إصدار» | `Go >= 1.22؛ Cobra v1.8.x` |
| قائمة التبعيات | يتضمن كل بند الإصدار والرخصة وصاحب حقوق النشر والعنوان الرسمي؛ ويُوسم مجهول المصدر بأنه قيد التأكيد | انظر قالب جدول قائمة التبعيات في الملحق ج |
| نوع الرخصة | يُستخدم معرّف SPDX، ولا تُستخدم عبارات غامضة مثل «مفتوحة المصدر» أو «قابلة للاستخدام بحرية» | `MIT` |
| طريقة التثبيت والتشغيل | يُذكر دليل العمل الحالي والأمر الكامل والخرج المتوقع القابل للتحقق | نفّذ `go install ./cmd/mdlint` في جذر المستودع، وأخرج رقم الإصدار |
| البنود قيد التأكيد | تُستخدم علامة ثابتة، ويُكتب المحتوى الناقص والمسؤول عن الاستكمال، ولا تُستخدم «مبدئي» بديلاً | `【قيد التأكيد: نوع رخصة التبعية foo، المسؤول: زانغ سان】` |

## 4. قواعد وسم المعلومات غير المؤكدة

1. الصيغة الموحدة: `【قيد التأكيد: ما هو الناقص تحديداً】`، ولا يجوز استبدالها بعبارات غامضة مثل «مبدئي» أو «تقريباً» أو «محتمل».
2. موضع الوسم: موضع واحد مقابل في متن الوثيقة، ثم يُدرج مرة أخرى في «ملخص البنود قيد التأكيد» في نهاية الوثيقة.
3. البنود غير المؤكدة المتعلقة بالرخصة وحقوق النشر ومصدر التبعيات يجب وسمها صراحةً في NOTICE، ولا يجوز حذف البند كاملاً.
4. يجب أن يتضمن ملخص البنود قيد التأكيد الرقم والحقل والمحتوى الناقص والمسؤول عن الاستكمال والموعد المخطط للاستكمال؛ ولا يجوز أن يدخل بند بلا مسؤول أو موعد إلى المرحلة 0 (انظر [مسار التنفيذ](./execution-process.md)).

## 5. الملحق أ · فهرس العناصر النائبة

`{{项目名称}}`، `{{一句话定位}}`، `{{当前版本}}`، `{{维护状态}}`، `{{许可证 SPDX}}`، `{{著作权人}}`، `{{年份}}`، `{{分支名}}`، `{{仓库地址}}`، `{{最低运行时版本}}`

قواعد الاستخدام:

1. يسرد هذا الفهرس الحقول الأساسية في مرحلة الجمع فقط؛ أما العناصر النائبة الكاملة في README وشرحها فمرجعهما جدول مقابلة العناصر النائبة في [قالب README القياسي](./readme-standard-template.md).
2. تُكتب العناصر النائبة الرسمية بصيغة `{{纯名}}`، ولا يجوز تضمين نص توضيحي أو علامات خلفية أو عنصر نائب ثانٍ داخل الأقواس المعقوفة؛ ولا تُعد محتويات الأقواس المعقوفة ذات اللغة الطبيعية في الأمثلة الموحدة عناصر نائبة رسمية.
3. لا تُستخدم العناصر النائبة مباشرةً في الحقول ذات اللغة الطبيعية في جدول الجمع؛ وعند توليد README تُقابل العناصر النائبة المقابلة وفق جدول المقابلة، ولا يجوز أن يبقى في الوثيقة النهائية أي محتوى تفسيري بين أقواس معقوفة.

## 9. الملحق د · نص جمع معلومات المشروع القابل للنسخ
