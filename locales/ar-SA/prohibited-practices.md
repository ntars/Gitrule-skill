# الممارسات المحظورة

> المشكلة التي يحلها هذا الملف: تجميع كل السلوكيات المحظورة غير القابلة للخرق، لتكون قائمة الخطوط الحمراء النهائية عند المراجعة والكتابة.

## I. الخطوط الحمراء للتحكم العام والدفع

1. يُحظر إخراج «يمكن الدفع الآن والاستكمال لاحقًا» قبل تصفير بنود P0.
2. يُحظر اختلاق نتائج الفحص؛ ويُوسم البند غير القابل للفحص بـ `SKIP + السبب`، ولا يجوز كتابة PASS.
3. يُحظر دمج عدة وثائق في ملف واحد عند التسليم.
4. يُحظر حشو README بواجهة API الكاملة ودليل المساهمة وسجل التغييرات.
5. يُحظر استخدام `--force` للدفع إلى فرع عام، في أي حال.
6. يُحظر الاكتفاء بـ «إيداع حذف» لمعالجة مفتاح سري مسرَّب.
7. يُحظر ابتداع اسم مستودع خارج [مواصفة تسمية المشاريع](./project-naming-specification.md).
8. يُحظر إدراج مسار التفكير الداخلي في وثائق التسليم.

## II. الخطوط الحمراء لكتابة الوثائق

1. لا يجوز اختلاق اسم المشروع أو وظائفه أو بيانات أدائه أو إصدارات تبعياته أو رخصته أو معلومات مؤلفه أو نتائج اختباراته.
2. لا يجوز نسخ README أو وثائق أو شيفرة أو صور أو نصوص مشاريع أخرى؛ وعند الحاجة الفعلية إلى الاقتباس يجب بيان المصدر والرخصة.
3. لا يجوز اختيار نوع الرخصة دون تأكيد.
4. لا يجوز إيراد أرقام أداء غير متحقق منها، ولا استنتاجات مقارنة بلا مصدر، ولا عبارات تعهدية (مثل «مضمون» أو «مجاني دائمًا»)، ولا أوصاف انتقاصية لمشاريع أخرى، ولا محتوى ترويجي غير متعلق بالمشروع.
5. لا يجوز استخدام مواد مجهولة المصدر؛ وعند غياب المصدر والرخصة للصور والأيقونات والخطوط يُوسم البند بأنه قيد التأكيد، ولا يجوز استخدامه مباشرة.
